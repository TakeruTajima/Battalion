# 実装依頼：大隊指揮RTS プロトタイプ P2c.2（意見具申）

## Git タグ

完了時に `proto-p2c2-requests` を打ち、push する。

## 背景

リポジトリ：`TakeruTajima/Battalion`（`proto-p2c.1.2-fix` まで完了）。

P2c で中隊長が自分で判断するようになった。次は、中隊長が本部へ伝令で報告・要請・宣言を送る「意見具申」。設計の原則は、大きな判断はプレイヤーが決め、中隊は伺いを立てること。届くまでの時間も読み合いになる（H4）。

P2c のプレイでは、崩れた中隊が再集結した後に命令待ちのまま黙って待っていた。意見具申の「命令を請う」で、これをプレイヤーに知らせる。

P2c の間、独断の宣言は出来事の欄に即座に出していた。この段から伝令に載せる。

- 仕様書：`docs/spec.md` の「P2c.2：意見具申（確定）」が正
- 関連：P2a（伝令）、P2b.1（命令待ち）、P2b.2（動揺で停止中）、P2c（独断と宣言）、P2c.1.2（気付いている敵）
- 仕様書には「検証の道具（V1・V2）」と「Battalion への課題」の節もあるが、今回は扱わない

## タスク

1. 中隊からの伝令
   - 準備 10秒・秒速 3m、経路と喪失は本部の伝令と同じ。片道
   - 判断枠を使わない
   - 1中隊に同時2人まで
   - 喪失の乱数は別の流れから引く
   - 赤は送らない
2. 送るもの
   - 報告7種：命令を終えた、目標崩壊、敵発見、損害大、攻撃頓挫、隣の崩壊、陣地完成
   - 要請3種：命令を請う、追撃の可否、後退の許可
   - 宣言（P2c の独断の宣言の載せ替え）
   - 送る時は仕様の表どおり。送った時点の中隊の様子を添える
3. 送りすぎを防ぐ
   - 報告と要請は 60秒でまとめる
   - 宣言は即座に送る
   - 同じ要請は状況が変わるまで繰り返さない（「命令を請う」の 10分ごとは除く）
4. 性格の差
   - 慎重：「後退の許可」を士気 60 未満から、「損害大」を 10% ごとに送る
   - 猪突・機敏：任せるのとき、独断できる場面では要請ではなく宣言を送る
5. 表示
   - 出来事の欄：届いた時に「[T+mm:ss 発] …」の形で出す。要請は目立つ色
   - 具申の箱：［許可］で命令書を起案の欄に作る。発令はプレイヤー。［消す］もつける
   - 中隊の伝令の点と点線（本部の伝令と色を分ける）
   - 左パネル：中隊ごとに「最後の報告 T+mm:ss」
   - 自動一時停止の選択肢「要請が届いた」（初めは切）
   - P2c の宣言の即座の表示を、届いた時の表示に置き換える

パラメータ：新しい値（中隊の伝令の準備時間、同時の数、まとめの間隔、報告の閾値など）は `sim_params.json` に置き、キーを設計で提案する

## テスト

- 単体テスト：
  - 各報告・要請・宣言が、仕様の時に送られる
  - 中隊の伝令が本部に着いて届く。倒れたら届かない
  - 判断枠を使わない
  - 60秒のまとめが効く。宣言はまとめずに即座に送られる
  - 同じ要請を繰り返さない
  - 「命令を請う」が命令待ち 5分で送られ、10分ごとに繰り返す
  - 慎重・猪突・機敏の性格の差が出る
  - 追撃の可否の［許可］で、追撃の攻撃の命令書が起案の欄にできる
- 戦闘の結果を変えない：中隊の伝令は情報だけで、喪失の乱数も別の流れなので、通し実行の勝率・損害・崩れ方は P2c.1.2 と完全に一致するはず。ログのハッシュは、新しい行の分だけ変わってよい（戦闘の行だけを比べる手段を用意する）
- **長い計算は回さない**：Claude Code が回すのは速いテストだけ。通し実行（一致の確かめ）は Takeru がローカルで回すので、回し方（コマンドと所要の目安）を報告に書いて止まる

## 完了基準

- .NET の速いテストが全て通る。Unity でコンパイルが通り、EditMode のテストが通る
- 報告に、通し実行の回し方、人が触って確かめる項目の一覧、変わった操作の早見表がある

## スコープ

- 含める：上のタスクのみ
- 含めない：霧と報告（P2d。地図上の敵は今どおり全て見える）、赤の本部の振る舞い（P4）、増援の要請、規則の課題（「Battalion への課題」）、V1・V2
- 地図データとリファレンス実装は変更しない

## 方針

- **着手前に設計を短くまとめて報告し、返答があるまで実装に入らないこと。** 特に次を書く
  - 中隊の伝令の持ち方（P2a の伝令との共通化）
  - 報告の判定の置き場所
  - まとめの間隔と宣言の扱い
  - 具申の箱の画面と操作
  - 戦闘の結果を変えないことの確かめ方
  - パラメータのキー
- 仕様の解釈で迷ったら一覧に残し、もっとも素直な解釈を提案に含める
- Unity は 6.3 LTS（6000.3.11f1）で開く
- 完了したら止まって報告する。P2d には進まない
