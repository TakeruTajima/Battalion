# 実装依頼：大隊指揮RTS プロトタイプ R2.1（伏せた味方の超越と、効いている倍率の表示）

## Git タグ

完了時に `proto-r2.1-fix` を打ち、push する。

## 背景

リポジトリ：`TakeruTajima/Battalion`（`proto-r2-fortification` まで完了）。

R1・R2 を遊んだ所見。側面・背面への攻撃はよく効くようになり、好感触。気になる点が2つ出た。

- 拘束されている味方が邪魔で、後ろの中隊が前進できない時がある。原因は R1 の取りこぼし：伏せて止まった中隊は、命令の上では「動いている」ので、超越の対象にならない（`IsStationaryFriend`）
- 移動中に撃たれても止まらない場面で、損害が増えているのか分からない。規則はあるが（被弾 ×3.0、撃つ力 ×0.5）、画面に出ていない

- 仕様書：`docs/spec.md` の「R2.1：伏せた味方の超越と、効いている倍率の表示（確定）」が正

## タスク

1. 制圧下で伏せて止まっている中隊を、止まっている味方に数える（超越、経路の味方を避けるコスト、味方の間隔の押し離し）。動揺で停止中の扱いも確かめる
2. 中隊の詳しい表示に「今効いている倍率」（被弾・撃つ力・移動）を出す。R1・R2 で入れた表示（受けている火力、陣地の向き）と並べ、読みやすく整理する
3. 駒の上に、開けた所を移動中（被弾 ×3.0）の小さな印

## テスト

- 単体テスト：
  - 伏せて止まった味方を、後ろの中隊が超越して前へ出られる
  - 動いている味方（拘束で遅い味方を含む）は、今どおり抜けない
  - 倍率の表示のもとになる値（Sim の読み取りの口）が、損害の式で使っている値と一致する
- **速いテストは .NET と Unity（バッチモード）の両方を回す**。シナリオA の通し実行は Takeru がローカルで回すので、回し方を報告に書く（会戦が変わるのは 1 だけ）
