# 実装依頼：大隊指揮RTS プロトタイプ P2c（中隊長の自律行動）

## Git タグ

完了時に `proto-p2c-autonomy` を打ち、push する。

## 背景

リポジトリ：`TakeruTajima/Battalion`（`proto-p2b.2-fix` まで完了）。

段階つき命令と伝令が入り、プレイヤーは中隊に先の計画を渡せるようになった。次は、命令の届かない間・命令を終えた後に、中隊長が自分で何をするか。

設計で一番気を付けること：

- プレイヤーに「バカ！」と思われる判断をさせない。たとえば「目標が崩れたので中隊長の判断で追撃したが、結果として重要な拠点を放棄した」。原因は、プレイヤーの意図を踏みにじる判断と、理由の分からない判断
- 逆に「何もしていないように見える」のも同じくらい白ける

そこで、自律行動を2つに分ける。

- 全ての中隊長がする、持ち場の 100m 以内の小さな動き
- 性格ごとの「独断」。長所と短所が同じ性質の表と裏になっていて、命令の新しい項目「裁量」（任せる／厳命）で律せる

猪突が功を焦って突出するのは、短所であると同時に「味」として残す。プレイヤーがそれを読んで律することがゲームになる。

- 仕様書：`docs/spec.md` の「P2c：中隊長の自律行動（確定）」が正
- 意見具申（中隊から本部への伝令）は P2c.2。P2c の間、宣言・報告は出来事の欄に即座に出す

## タスク

1. 持ち場：中隊ごとに持ち場の地点を持つ（仕様の定義どおり）
2. 裁量：命令書の段ごとに「任せる（初めの値）／厳命」。会戦開始前の命令、通し実行の命令は「任せる」
3. 全ての中隊長の自律行動（仕様の表の4つ）
   - 撃てる目標がないときの向き
   - 開けた所で撃たれたときに物陰へ寄る（100m 以内）
   - 止まって静かなときの浅い掩体
   - 崩した敵の陣地（200m 以内）に入る
4. 性格の独断（仕様の表）
   - 猪突：確保でも追う、追撃の後に続けて攻めかかる、士気 40 まで拒まない、持ち場から 900m で止まる
   - 機敏：味方に正面から撃たれている敵の側面へ回り込む
   - 慎重：物陰を 200m まで探す、60 で止まる、追撃しない
   - 冷静：独断なし
5. 追撃の規則（P1d の 4）を、裁量と「追撃」の字面のときの限度に読み替える
6. 表示
   - 命令書の段の［任せる］［厳命］
   - 駒と左パネルの性格
   - 自律行動・独断の理由（駒の行動の印と出来事の欄）
   - 独断中の印の色
   - 宣言（「B1（猪突）独断で追撃」）

パラメータ：仕様の「初めの値」は全て `sim_params.json` に置く。キーは設計で提案する（仕様側で `sim_params.initial.json` に反映する）

## テスト

- 単体テスト（「バカ」と「無為」を防ぐ確かめ）：
  - 厳命の中隊は、自律行動で持ち場から 100m を越えない（どの性格でも）
  - 任せた冷静は独断しない（厳命と同じ動き）
  - 任せた猪突は「確保」でも追い、追撃の後に 400m 以内の動揺中の敵へ攻めかかり、持ち場から 900m で止まって命令待ちになる。厳命なら確保して留まる
  - 任せた機敏は、味方に正面から撃たれている 500m 以内の敵の側面の範囲へ回り込む。経路 600m を越える場合は回り込まない
  - 任せた慎重は「追撃」の字面でも追わない。厳命なら追う
  - 開けた所で 30秒撃たれた保持の中隊が、100m 以内の森へ寄る。物陰がなければ動かない
  - 120秒動かず静かな中隊が浅い掩体を掘り、300秒で被弾 ×0.6 になる。動くと失う
  - 崩した塹壕が 200m 以内なら入る。250m なら入らない
  - 撃てる目標がない中隊が、600m 以内の最も近い敵の方を向く
- S1〜S6 は ±15% 以内（平地で命令がない。浅い掩体と向きが効く可能性があるので確かめる。外れたら理由を報告する）
- 通し実行：規則が変わるので結果は動く。表を P2b.2 と並べ、大きく変わった作戦の理由を書く（回帰の指標。作り込みはしない）
  - 加えて、全中隊を厳命にした版を1通り（ステージ1・2、各20回）足し、任せた版と比べる

## 完了基準

- Unity 6.3 LTS（6000.3.11f1）と .NET でテストが全て通る
- 通し実行の表と、大きく変わった作戦の理由が報告にある
- `Sim` が UnityEngine を参照しない
- 報告に、人が触って確かめる項目の一覧と、変わった操作の早見表を含める

## スコープ

- 含める：上のタスクのみ
- 含めない：意見具申・通信途絶時の振る舞い（P2c.2）、霧と報告（P2d）、隊形、砲兵（P3）以降、赤の自律行動の作り込み（赤も同じ規則で動くが、台本の命令は今どおり）
- 地図データとリファレンス実装は変更しない

## 方針

- **着手前に設計を短くまとめて報告し、返答があるまで実装に入らないこと。** 特に次を書く
  - 持ち場と裁量の持ち方（命令書・段との関係）
  - 自律行動と独断の判断の置き場所と順番（今の P1d の追撃・向き直り、P1g の見える位置を探す動き、P2b.2 の動揺で停止中との優先の関係）
  - 物陰の探し方と重さ
  - 猪突の「続けて攻めかかる」と機敏の回り込みが、内部でどの命令（攻撃など）として動くか
  - 赤の中隊への効き方
  - パラメータのキー
- 仕様の解釈で迷ったら一覧に残し、もっとも素直な解釈を提案に含める
- Unity は 6.3 LTS（6000.3.11f1）で開く
- 完了したら止まって報告する。P2c.2 には進まない
