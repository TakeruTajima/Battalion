# 実装依頼：大隊指揮RTS プロトタイプ F1（隊形）と P2d（霧と報告）

## Git タグ

二つの段に分けて進める。F1 を終えて条件を満たしたら `proto-f1-formation` を打って push し、続けて P2d を終えて条件を満たしたら `proto-p2d-fog` を打って push する。

## 背景

リポジトリ：`TakeruTajima/Battalion`（`proto-r4-close-combat` まで完了。仕様側の記録の変更が作業ツリーにあれば、最初の commit に含める）。

Takeru と決めた：隊形（縦隊・横隊、展開・縮合）を霧と同時に入れる。展開・縮合は中隊長に任せる（プレイヤーは隊形を命じない）。霧は本部（プレイヤー）の知っていることの作りで、会戦の結果（Sim の戦闘）は変えない。

- 仕様書：`docs/spec.md` の「F1：隊形（縦隊と横隊、展開と縮合）（確定）」と「P2d：霧と報告（確定）」が正。上の「霧と報告」の節（地図の表示の決まり）は P2d の節で具体にした
- 「保留：R5 射撃の延伸」は入れない（ペンディング）

## タスク（F1）

1. 隊形の状態（横隊・縦隊・展開中・縮合中）と、矩形・撃つ力・被弾・速さ・向きの変え方（仕様の表）
2. 中隊長の判断（縮合・展開・揺れ止め）。展開の距離は性格による
3. 地図ファイルの配置の `formation`（書かなければ横隊）
4. 表示（細長い駒、進み具合、倍率、出来事）
5. 場面 S20〜S22 と期待のテスト。期待を外れたら仕様の掃き出し
6. 通し実行（シナリオA・教程1・教程2）を回し、R4 の値と並べる

パラメータ：`formation` の節（column_fire_mult 0.2、column_damage_mult 1.5、column_speed_mult 1.25、deploy_sec 150、form_column_sec 120、deploy_distance_m：慎重 1000・冷静 800・機敏 700・猪突 500）を `sim_params.json` と `docs/reference/sim_params.initial.json` の両方に足してよい

## タスク（P2d）

1. 本部の知っている敵（報告の駒）。報告は中隊の伝令（P2c.2）で届く。会戦の始めの敵情 `initial_intel` を地図ファイルに足す（シナリオA の2つ、教程1・2。中身は仕様のとおり）
2. 報告を送る時（発見・続報・変化）と中身（位置の誤差・規模・向きと動き・様子・時刻）
3. 報告の駒の紐付け（300m・10分）、表示（誤差の円、何分前、5分で薄く、10分で「?」、30分で消す）
4. 報告の駒への攻撃・拘束の命令（駒の位置の近くの気付いている敵を目標にする。いなければ保持して「敵を見ず」）
5. 「霧なし」の設定（検証用）と、戦闘詳報の重ね表示
6. 単体テスト・場面 S23。霧の入り切りで通し実行の結果が1つも変わらないことの確かめ

パラメータ：P2d で新しい値を足すなら（300m・10分・5分・10分・30分・規模の段の境目）、`fog` の節に置き、initial.json にも反映してよい

## テスト

- 速いテストは .NET と Unity（バッチモード）の両方を回す。ログの一致を見るテスト（規則を止めた値で前の版と一致）が通ること
- 通し実行（シナリオA・教程）は Claude Code が回す

## 完了基準と push の条件

- F1：速いテストが全て通り、S20〜S22 の期待（掃き出しで選んだ場合はその値）、S1〜S19 が期待を満たし続け、シナリオA の拘束＋迂回の良い方が両ステージ 0.6 以上、教程1・2 の線を保つ。満たせば `docs/reports/F1_report.md` を書いて commit・タグ・push。満たさなければ止めて報告（P2d には進まない）
- P2d：速いテストが全て通り、S23 の期待、霧の入り切りで通し実行の結果が変わらない。満たせば `docs/reports/P2d_report.md` を書いて commit・タグ・push。満たさなければ止めて報告
- 0.15 以上動いた作戦は、報告に会戦の経過で原因を書く（それだけでは止めない）

## スコープ

- 含める：上のタスクのみ
- 含めない：R5、プレイヤーが隊形を命じる操作、赤の霧（赤は今のまま、赤の中隊のどれかから見えている青で判断）、P3 砲兵、P4
- リファレンス実装は変更しない

## 方針

- 着手前の設計報告は不要。迷った点と自分で決めた点は報告に一覧で残す（特に：縦隊の矩形と押し離し・超越、展開の終わりの向き、報告の駒への命令の目標の決め方、中隊の詳しい表示に出す知っていること）
- 勝ち方・負け方が変わった作戦は、会戦の経過を少なくとも1件追って書く
- 返事と報告は日本語で書く
