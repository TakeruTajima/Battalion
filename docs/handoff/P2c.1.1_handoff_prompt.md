# 実装依頼：大隊指揮RTS プロトタイプ P2c.1.1（接触の距離の敵と「接敵中」）

## Git タグ

完了時に `proto-p2c.1.1-fix` を打ち、push する。

## 背景

リポジトリ：`TakeruTajima/Battalion`（`proto-p2c.1-fix` まで完了）。

P2c.1 の報告で、拘束の2作戦の負け方が分かった。稜線の陰で接触の距離にいる B2 が、見える位置を探して横へ動くときに、進む方へ向きを変える。そのため、視線を問わず撃てる R1 に脇と背を撃たれていた。

原因は、規則どうしの食い違い。撃ち合いでは、接触の距離の敵（隙間 50m 以内）を視線を問わずに数える（`SimulationSight.cs` の `SightForFire`）。ところが、動くときに向きを保つ「接敵中」（`SimulationMovement.cs` の `EnemyInContact`）は視線だけを見ている。撃たれうる相手を「接敵していない」と数えてしまっている。

- 仕様書：`docs/spec.md` の「P2c.1.1：接触の距離の敵と『接敵中』（確定）」が正
- `sim_params.initial.json` は、P2c.1 の3つのキーを反映済み

## タスク

1. 「接敵中」の判定（`EnemyInContact`）に、接触の距離（`InFireContact`。隙間 50m 以内）の指揮下の敵を、視線を問わずに含める
2. ほかに視線だけで敵の有無を見ていて、接触の敵を数えていない判定がないか確かめ、あれば報告に一覧で書く（直すのは 1 だけ。ほかは仕様側で決める）
