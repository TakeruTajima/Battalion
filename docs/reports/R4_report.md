## 4. 迷った点と、自分で決めた点

1. **`fortification_mult` を 0.6 にした**。1.0 では教程2 の総員突撃が 0.65（崩した 13/20、中央値 33.2分）で、線を外れた。総員突撃でも2個目以降の中隊が地峡の入口から詰め、接近戦に届いた中隊が塹壕の守りなしで R1 を削り切るため。0.6 なら 0.05 に戻る。
   - 1.0 のまま教程2 の制限時間を 30分にしても、線は満たす（総員突撃 0.05、抑えてから詰める 1.00）。ただし地図を直すことになり、仕様の R4 の節が示す手（1.0・0.6 を比べる）ではないので採らなかった。
   - 1.0 のときのシナリオA は、拘束＋迂回の良い方がステージ1 0.95、ステージ2 0.70 で満たし、ステージ1 の拘束＋猪突の攻撃（確保）が +0.20 動いた（原因は 0.6 と同じ）。
2. **0.6 の意味を「守りの上限」にした**。仕様は「置き換える」だが、正面の弧の外（もともと守りなし ×1.0）を 0.6 に置き換えると、接近戦の方が側面からの守りが増えてしまう。そこで「接近戦では陣地は fortification_mult より強く守らない」とした。1.0 なら仕様の「置き換え」と同じ。
3. **表示の文字は仕様のまま「接近戦で陣地の守りなし」**。0.6 では守りが弱まる（×0.3→×0.6）ので、文字の後ろに倍率（×0.6）が出る。文字を「弱まる」に変えるかは仕様側の判断。
4. **`docs/reference/sim_params.initial.json` も 0.6 にした**（R3 と同じく、両方に同じ値を入れた）。仕様の初めの案は 1.0。

## 6. 仕様側で見てほしいこと

1. **0.6 を選んだ**：1.0（初めの案）では教程2 の総員突撃が 0.65 になった。0.6 は「胸墻がもう守りにならない」より弱い効き方なので、狙いの「決着は数分」より長いかもしれない（教程2 で崩す時刻の中央値は 27.4分。R4 なしの会戦の経過では、B3 が接近戦に届くのは 19〜21分だった。R4 ありの届いた時刻は測っていない）。教程2 の地図（制限時間 30分）で 1.0 にする道もある（上の 4 の 1）。
2. **「置き換え」を「上限」と読んだ**（上の 4 の 2）。
3. **表示の文字**：0.6 では「守りなし」ではなく「弱まる」になる（上の 4 の 3）。
