## 4. 迷った点と、自分で決めた点

1. **移動中の旋回と「その場で」の旋回の区別**：
   - 接敵中の中隊は、今までも動いている間は向きを変えない（P1e の2。横歩き・後ろ歩き）。
   - 「接敵中に動きながら回る」のは、阻まれて向き直った中隊（P1e.2 の `FacingOverride`）だけ。この旋回も遅くした（規則1 の「移動中の旋回」）。ただ、その刻みは位置が動いていて、もう動いている扱いなので、「旋回中」の印は付けない。
   - 「その場で」は、その刻みに位置が動いていないこと、とした。
2. **20° の測り方**：その刻みに回り始めた時点での、向きと目標の向きの差で見る。回り終わりの 20° 以内に入ったら、動いている扱いを外す。
3. **塹壕での旋回**：仕様に書かれた3つ（撃つ力・開けた所の被弾・制圧のしきい値）だけを掛けた。塹壕の守り（×0.3）は外していない（今の規則では、塹壕の守りが外れるのは「移動中」）。陣地構築・浅い掩体の進みも止めない。
4. **伏せた中隊**：制圧下で伏せている中隊が撃ってくる敵の方へ向く旋回（R1）も、接敵中なら遅くした。伏せている間は「その場で」なので、20° を超えれば旋回中の扱いにもなる。
5. **自律の向きの直しが遅くなることの影響**：
   - 撃てる目標がない時に最も近い敵の方へ向く旋回（P2c）、撃てる目標が出たら命令の向きに戻る旋回（P2c.1）は、接敵中なら 90° に約 131秒かかる。その間に別の自律行動（物陰へ寄る等）が挟まり、さらに延びることがある（上の 3 の直したテスト）。
   - 向きの規則を止めた版の表（下の 5.6）は残した。
6. **接敵の判定を全中隊で行う**ことで、視線の計算が増える。速いテストの所要（約48秒）、通し実行の所要（25分21秒、E1 の区切りで 24分27秒）は、ほとんど変わらない。

## 6. 仕様側で見てほしいこと

1. **回り込む側も、着いた後の向き直りで同じ代償を払う**（5.3 の1）。
   - 今の作りでは、接敵中に動いている中隊は向きを変えない。回り込みの最後に、敵の 400m 以内に着いてから、その場で 90° 回ることになる。
   - 史実では、回り込む側も最後の展開（正面を変える）に時間がかかり、乱れる。ただ、普通は敵の射程の外で済ませる。
   - 考えられる道：
     - 回り込みの命令の作り（攻撃の側面の始点や両翼包囲の着く点で、向きを先に作る）
     - 接敵していない間の移動中の旋回（今は進む方角へ回るので、着いてから目標の方へ回り直す）
     - 着いた後の向きの指定の扱い（接敵中は遅い旋回の対象から外す）
2. **ステージ2 の拘束＋迂回 0.50**：完了基準を満たさない。掃き出しは S10〜S13 の期待を満たさない時のものなので、回していない。値の見直しか、上の1の作りの直しか、物差しの見直しかは、仕様側の判断。
3. ステージ2 の総員突撃（受け身の赤）は 0.65→0.15 に下がった。E1 では 1.00→0.90。

**読めること**：
1. **回り込みが着いた後の旋回は、速くなった**。
   - 初めの版で回り込み役が払っていた旋回中の秒は、大きく減った（ステージ1 の両翼包囲の B3 130→61秒、段階つきの B4 146→29秒など）。
   - 線を張る前の旋回（接敵中だが速いまま）は、1会戦あたり B1・B3 で 10〜60秒ほどあった。これが、初めの版で遅くなっていた分に当たる。
2. **ステージ1 の3つが上がったのは、守る赤の遅い向き直りが効いたため**。
   - 総員突撃では、村の守備 R2 が、近づく青へ向き直る間（旋回中 64秒）に撃つ力が落ちる。青は早く村を取り（E1 の 52.1分→30.2分）、青の崩れが減った（R3 なし→今で B2 11→0、B3 12→3）。
   - 両翼包囲では、R2 が脇から来る青へ向き直る間（旋回中 78秒）に崩れる回が増え（11→20）、青の崩れが減った（B1 13→2）。
   - 段階つきは、予備の R3 と R2 が回る間に崩れる回が増えた（R3 8→15）。
   - 仕様の狙い（守る側が回り込みに向き直れない）どおりの効き方と見る。
3. **ステージ2 の両翼包囲（0.35→0.05）は、村の手前で止まった青が線を張り、その後に脇から撃たれて遅く回るため**。シード 1・5・6 の経過（3つとも、今の版で負け、R3 なしで勝ち）：
   - 北の脇の B1 は、村へ前進する段（E1 の直しの「村へ入る段」）の途中、村の東（2170〜2193, 1148〜1221）で敵に塞がれて止まる。5分ほど止まっているので線を張る。
   - そこへ R3（予備）や R1 から撃たれ、B1 は 90〜190° 向き直る。線を張った後なので遅く、2〜3分（39.9〜43.1分、45.1〜48.4分、46.6〜49.3分）動いている扱いになる。どのシードでも、その直後に B1 が崩れた。
   - その前の 26〜29分にも違いが出る。赤の R2 が後退した先で向きを直す間と、R3 が止まった後に向き直る間が遅い。R3 は村の東（1909, 1004）で止まり、R3 なしのように西（1770, 1005）まで出ない。ここで B1 の道筋が分かれる。
   - 仕様の判断の1にある「保持している中隊が脇から撃たれて正面を変えるのは、線を張った後なので遅い」に当たる。青の側が線を張った後に脇を突かれる形で、規則の狙いどおりの効き方と見る。
4. **ステージ2 の拘束＋猪突の攻撃（0.65→0.50）も、同じ形**。シード 1・4・5 では、村の手前で止まった B1・B2・B4（1812〜2040, 1067〜1242）が、1〜3分遅く回る（57.1〜58.0分、48.6〜50.5分、63.1〜66.4分、54.4〜55.3分）。初めの版（0.40）よりは戻った。
5. **受け身の赤**：
   - ステージ2 の総員突撃は 0.75 に戻った（初めの版 0.15）。
   - 一方、ステージ2 の遠い拘束は 1.00→0.80、ステージ1 の近い拘束は 0.85→0.50 に下がった。経過は見ていない。E1 の赤（任せる版）では、ステージ2 の遠い拘束 0.65（E1 0.70）、ステージ1 の近い拘束 0.95（E1 0.95）。

### 8.6 仕様側で見てほしいこと

1. 線を張っている中隊は、青でも赤でも、止まって 60秒経つと遅くなる。ステージ2 の両翼包囲・猪突が下がったのは、村の手前で塞がれて止まった青がこれに当たるためと見る（上の 8.5 の 3・4）。狙いどおりと見るか、「敵に塞がれて止まっている」間は線を張らない扱いにするかは、仕様側の判断。
2. 会戦の始めに置かれた中隊を「線を張り終えている」扱いにした（8.3 の 1）。この読みでよいか。
