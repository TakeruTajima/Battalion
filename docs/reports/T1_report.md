**確保が 0 の作戦**：
- 総員突撃と拘束＋両脇は、20回とも勝ったが、確保した回が 0。R1 が盤上から消え（降伏か離脱）、その刻みで会戦が終わるため。シード1 の総員突撃では、R1 が 9.0分に降伏した。
- 正面火力戦は、保持の命令のまま 250m で撃ち続けるので、R1 が崩れても誰も塹壕に入らない。崩れた R1 が塹壕の外にいるまま、制限時間で勝ちになる。

### 原因（会戦の経過）

1. **総員突撃は、意図せず両翼包囲になる**（シード1 の経過）。
   - 塹壕の正面は 200m で、中隊の幅も 200m。味方の中心どうしは 200m 以上離れる（`movement.friendly_min_spacing_m`）ので、3個中隊は正面に並べない。
   - 北の B1 と南の B3 は、塹壕の両端の外へ回る。5.5分ごろには B1・B3 の射撃が R1 から見て側面（Flank）になる。7.5分には B3 が南 250m に着き、側面から毎分 3.4人の損害を与えている。
   - R1 は 9.0分に降伏した（兵 130、士気 22）。青の損害は小さい（B2 が開けた所で制圧されて伏せる程度）。
   - 目的地を塹壕の中（y 675・600・525）や、全て塹壕の中心にしても、勝率は 1.00 のまま（崩した時刻の中央値 11.8分・10.2分）。目的地の選び方の問題ではなく、正面の狭い塹壕に3個中隊が寄ると、両端の2個が脇に出てしまう。
2. **正面火力戦は、3対1 の正面射撃で 35分前後に崩す**。
   - 3個中隊を x 725 に南北 200m おきに置いた。R1 から見て、北と南の中隊も正面（±39°）。
   - S13（正面から2個中隊）は 30分で崩れないが、3個中隊だと赤の損害が 40分で 0.63 になり、中央値 34.9分で崩れる。青の損害は 0.05 と小さい。
3. **側面攻撃（拘束なし）は、R1 が接敵の前に向き直るので、側面にならない**（シード1 の経過）。
   - B1 が北の脇へ回る間（1〜5分）、R1 は 400m の外の B1 へ向きを変える（180°→119°、6分で 114°）。接敵していない間は、今の規則どおり毎秒 6° で回る。
   - B1 は 390m で R1 の正面（Front）に着き、制圧されて止まる。R1 に毎分 2.0人の損害を受け、崩れる（16/20）。
   - 拘束＋迂回では、R1 は拘束役の B2 と撃ち合っていて（接敵中・線を張っている）、B1 へ向き直るのが遅い。狙いどおり崩れる。

## 5. 迷った点と、自分で決めた点

1. **作戦の命令の作り方**（R1 は (975, 600) で西向き。北の脇は地図の方角 +90°、南の脇は −90°）：
   - 総員突撃：3個中隊が塹壕の位置へ前進。目的地は R1 の中心と、その南北 150m（(975, 750)・(975, 600)・(975, 450)）、着いたら東向き。シナリオA の総員突撃（村の中心と南北 150m）にならった。目的地を塹壕の中に寄せても結果は同じ（上の 3 の 1）。
   - 正面火力戦：3個中隊が塹壕の正面 250m（x 725）に、南北 200m おき（y 800・600・400）に前進して撃つ。
   - 側面攻撃（拘束なし）：B1 が北の脇から攻撃（地図の方角での攻撃 `AttackFrom`、+90°。発起点は R1 の北 250m）。B2・B3 は命令なし（初めの位置で保持）。
   - 拘束＋迂回：B2 が遠い（近い）拘束、B1 が北の脇から攻撃。B3 は「B1 に続く」を、2分後に同じ北の脇から攻撃とした（シナリオA の拘束＋迂回で、B4 が 2分後に続くのにならった）。
   - 拘束＋両脇：B2 が遠い拘束、B1 が北の脇、B3 が南の脇から、どちらも時刻 0 に攻撃。
   - 攻撃は全て「崩れたら確保」。確保すると、崩した敵の陣地が 200m 以内なら自律で入る（P2c の「崩した敵の陣地に入る」）。シナリオA のような「崩れたら村へ前進」の後の命令は足していない（仕様の表にないため）。
   - 時刻 0 の命令は伝令を使わずに届く（シナリオA と同じ）。2分後の B3 は、青の本部 (100, 600) から伝令で出す。
2. **確保の判定**：塹壕のマスに中心がある指揮下の青の中隊がいて、指揮下の赤の中隊がいないこと。勝ちの判定には入れていない（仕様の「勝ち」は、赤がいないことと青が残っていることだけ）。確保した時刻は、初めてそうなった刻み（その後に赤が戻っても消さない）。
3. **崩した時刻**：`trench_units` の中隊が全て、指揮下にないか盤上にいなくなった最初の刻み。再集結して戻っても消さない。
4. 塹壕のマスは、地図の全ての `T`。教程1 は塹壕が1本なので、これで足りる。
5. 通し実行は、シナリオA と同じく、赤か青が全て盤上から消えたらその刻みで終える。そのため、降伏で終わった会戦では確保の時刻が残らない（上の 3）。
6. 表示のステージの番号は、地図ファイルの `stage`（教程1 は 11）に合わせた。

   - B2 だけが正面 (599, 700) で阻まれて撃たれ（損害の多くは B2）、B1・B3 は約8分から脇射ちを続ける。R1・R2 は 11〜12分で動揺し、約14分に揃って壊走する。

2. **拘束＋迂回（遠い）は、R1 を崩しても R2 が崩れない**。

### 仕様側で見てほしいこと（追記）

1. **総員突撃の目的地**：y 900・500 は赤の線の両端と同じ南北の位置なので、両端の中隊は赤の脇に着く。例えば y 800・700・600（赤の中心と、その間）に寄せると、両端の中隊が着く点が赤の正面寄りになるかもしれない。ただし味方の間隔 200m のため、3個中隊が 400m の正面に重なると、どれかは押し出される。命令の決め方か配置の直しは仕様側の判断。
