## 変わったこと

- **阻まれた中隊も向き直りの対象**
  - 敵の矩形の手前で阻まれて止まっている中隊（`BlockedByEnemy`）は、P1d の5の向き直りの対象になる（条件・練度の遅れ・取り消しは保持と同じ）
  - 拘束の命令中と追撃中は、P1d と同じく対象外にした（P1d で「拘束の命令中の中隊は向き直らない」と決めているため）
  - 向き直った中隊は、命令の移動を続けるときも向き直った向きを保ち、その向きのまま動く（前進・横歩き・後ろ向きの規則。接敵中と同じ扱い）。新しい命令で解ける（P1d と同じ）
- **通し実行の「拘束＋迂回」**
  - R1 が指揮下でなくなったら、B1〜B4（拘束役の B2 を含む）が村の中心へ前進する。指揮下にない中隊への命令は Sim が受け付けない
- **テスト**（`P1eOrderTests` に2件）
  - 北を向いたまま東へ横歩きする中隊が東の敵に阻まれ、その敵に側面を撃たれると、練度の遅れの後にその敵の方へ向き直り、正面を向ける
  - 拘束の命令中は、阻まれていても向き直らない

### 読み方

- **5作戦は、ステージ2の総員突撃のほかは P1e.1 と同じ値**だった。阻まれて止まる中隊が出る作戦が少ないため
- **ステージ2の総員突撃（0.05→0.20）**：変更は阻まれた中隊の向き直りだけなので、阻まれていた中隊（P1e.1 で崩れていた B4 など）が撃ってきた敵へ正面を向けられるようになった分と読む。試行ごとの経過は追っていない
- **「拘束＋迂回」は、全中隊が村へ向かうようにしたことで、ステージ2では遠い・近いとも勝つようになった**（0.90・0.95）
  - 近い拘束の 0.95 は、R1 が崩れた後に、残った中隊が村のマスに入って勝っている。R2 は崩れていない（0/20）が、塹壕の位置（1725, 875）は村の中心から約 280m で、勝ちの判定（村の 250m 以内に指揮下の赤がいない）には掛からない。損害率 0.313、崩れた青 2.85 で、遠い拘束（0.208、0.80）よりずっと高くつく勝ち方
- **ステージ1は、村に籠った R2 を相手に勝てないまま**（遠い拘束で 0.05）。R1 が崩れた後に村へ向かう B4 が崩れる（18/20）。今回の取り決め（3）のとおり、台本の命令が状況に合わないことによるものとして、作戦の作り込みはしていない

## 触って確かめる項目

- [ ] 敵に阻まれて止まった中隊（状態の欄に「敵に阻まれて停止」）を脇から撃つと、正面が空いていれば、練度の遅れの後に撃ってきた方へ向き直る（駒の脇の弧）
- [ ] 向き直った後に道が空くと、向き直った向きのまま進む。新しい命令を出すと、その命令の向きの規則に戻る
- [ ] 拘束の命令中の中隊は、阻まれていても向き直らない

操作は P1e から変わっていない。
