## 変わったこと

### Sim
- **命令書**（`OrderSheet.cs`）：1〜3段の `Stage`（命令と、その段へ移る条件）。作ったら変えない
  - 移る条件：なし（第1段）・完了したら・時刻・信号弾（赤・緑・白）
  - 検査 `StageProblems`：第1段に条件、第2段・第3段に条件なし、保持・拘束の後に「完了したら」、段の数、宛先の違い
- **起案中の命令書**（`OrderSheetDraft.cs`）：段の追加・削除・入れ替え、命令と条件の変更。Unity に依存しないので .NET で試せる
  - 入れ替えで第1段になった段の条件は外し、第1段から下がった段は条件なしにする（条件を付けるまで発令できない）
  - 足した段の条件は、前の段が終わる命令なら「完了したら」、そうでなければ未設定
- **段の進行**（`SimulationStages.cs`）
  - 中隊は実行中の命令書と今の段を持つ。今の段が始まった後から、次の段の条件を毎刻み（刻みの終わり）調べる
  - 満たしたら、練度の遅れの後に次の段を始める（P2a の開始待ちを使う）
  - 完了：前進・後退は着いた（動揺で保持に変わった・阻まれて止まった場合は完了しない）、攻撃は目標が指揮下でなくなった刻み（練度の遅れの間は P1d どおり確保・追撃）、陣地構築は完成。保持・拘束は完了しない
  - 時刻：過ぎていれば満たす
  - 信号弾：上がったことが残る（命令書が届く前・今の段が始まる前に上がっていても、調べ始めた時点で満たす）
- **命令書の受け渡し**
  - `SendSheet`：会戦開始前（と本部のない陣営）は伝令なしで即座に届く。それ以外は伝令が命令書をまとめて運び、判断枠を1つ使う
  - 届いたら古い命令書を段ごと全て置き換え、第1段を練度の遅れの後に始める
  - `SendOrder`（1つの命令）・`Issue`・台本の命令は、1段の命令書として同じ道を通る
  - `ReviseSheet`・`CancelRunner`：準備中（本部を出る前）だけ。直しても準備の残りは数え直さない。取り消すと伝令は出ず、判断枠が空く
- **信号弾**：`FireFlare(side, color)`。各色1回、即座に、判断枠を使わない。上げた陣営の中隊の条件だけに効く（赤は使わない）
- **伝令の経路**（`SimulationRunners.cs`）
  - A*（`PathFinder`）で、伝令の陣営から見た敵の射界に脅威の重み 3.0 を掛けて避ける
  - **敵の駒の矩形に重なるマスは通れない**（回答7。P1d の 110m の規則は使わない）
  - 川は橋と浅瀬だけ
  - 速さは秒速 3m×マスの移動倍率
  - 10秒ごとに引き直す（往路は中隊の今の位置へ、帰路は本部へ）
  - 到着予定と受領の強制開放（往復予定の 1.5倍）も経路の時間で見積もる
  - 刻みの外（発令・表示）での見積もりは、露出の地図などの使い回しを作らずに計算する（作る時機で会戦の結果が変わらないように）
- **到着予定**（`PreviewSheet`）：段ごとに、前の段の行き先から下見し、経路の長さ÷（秒速 1.2m×マスの移動倍率）で着く時刻を見積もる
  - 次の段の開始：完了したら＝前の段の到着予定＋練度の遅れ、時刻＝（指定の時刻と前の段の開始の遅い方）＋練度の遅れ、信号弾＝「信号弾から N分」
  - 攻撃・陣地構築の完了の時刻は見積もれないので「完了しだい」
- **ログ**：`stage_advance`（段・理由）、`order_start` に段、`flare`、`runner_revised`、`runner_cancelled`、`runner_sent`・`runner_delivered` に段の数

### 表示（View）
- **命令の出し方が変わった**：命令を選んで地図をクリックすると、**起案中の命令書の段に書き込むだけ**。**「発令」（ボタンか Enter）で初めて出る**（1段だけの命令も同じ）
- **右パネルの「命令書」の欄**（幅を 300px→380px に広げ、スクロールできるようにした）
  - **起案中**（中隊ごとに1枚。選ぶ中隊を替えても残る）
    - ［白紙から］［実行中の写しから］
    - 段の行をクリックで「書き込む段」を選ぶ（▶）
    - 条件の切り替え［完了したら］［時刻］［赤］［緑］［白］。時刻は［−1分］［+1分］（初めは今から5分後の分の切り上げ）
    - ［↑］［↓］［×］、［段を足す］、［発令 (Enter)］、［起案の破棄］
    - 発令できない段には赤い「×」と理由。直すまで［発令］は押せない。判断枠がないときも押せず、理由が出る
  - **送付中**：準備中なら「準備中 あと N秒」と命令書、［直す］［取り消す］。出発後は「未着 あと N秒」と命令書（読むだけ）
  - **実行中**：命令書の全段。今の段を ▶ と太字、済んだ段は薄く。開始待ちなら「開始まで N秒」
- **［直す］と書きかけの起案**（追加の指示）：**書きかけの起案がある間は［直す］を押せなくする**方を選んだ。理由「書きかけの起案がある間は［直す］を押せない」を出す。確認の小窓を挟むより、IMGUI で状態が少なく、うっかり書きかけを失うことがない
- **地図の下見**：選んだ中隊の命令書の段ごとの経路と行き先に、「第2段　約 T+18:36」のように段の番号と到着予定を出す
  - 実行中は今の段を濃く、後の段を薄く
  - 送付中は薄く
  - 起案中は薄い破線
  - 同じ行き先に重なる段の文字は下へずらす
- **段の印**：駒の上と左パネル・右パネルの命令の欄に「2/3　次：信号弾 緑」（2段以上の命令書のとき）
- **信号弾**：上部バーに［赤 (F9)］［緑 (F10)］［白 (F11)］。使ったものは消える
  - **確認**（回答6）：1回目で「もう一度で打ち上げ（赤）」を3秒出し、3秒以内の2回目で打ち上げる。ボタンもキーも同じ
- **出来事の欄**：「信号弾 緑」「B2 第2段へ（信号弾 緑）」「B2 第2段へ（完了）」「B2 第3段へ（時刻）」。駒の上に「第2段へ」
- P2a の「未着の命令の下見」は、段ごとの下見に置き換えた

### テスト（`P2bStageTests`、14件）
- 3段の命令書が、完了→時刻で進み、移る時に練度の遅れが掛かる
- 信号弾で全中隊が次の刻みに進み、各色1回、判断枠を使わない
- 命令書が届く前に上がった信号弾でも進む
- 保持・拘束の後の「完了したら」は発令できない（2件）
- 入れ替えで第1段になった段の条件が外れ、条件のない第2段は発令できない（3段まで）
- 新しい命令書が届くと、古い命令書の残りの段が消える
- 準備中の取り消しで伝令が出ず、判断枠が空く
- 準備中に直すと直した内容が届き、準備の残り時間は変わらない。出発後は直せず、取り消せない
- 会戦開始前の段階つき命令が伝令なしで届く
- 伝令が射界を避けて回り込む（射界にいた時間がまっすぐより短い）
- 伝令が川を橋か浅瀬で渡る（ステージ1、川の南の中隊へ）
- 動く中隊を追って 10秒ごとに経路を引き直す
- 到着予定が実際の到着と ±10% 以内（平地、2段の前進）

### 直したテスト
- P2a の検算の3件（600m で 230秒、430秒で受領、一時停止中の命令）：伝令がマスの中心を通る経路をたどるので数秒長くなった。±5秒（受領は ±10秒）の幅を付けた

### 大きく変わった作戦と理由

1. **ステージ1の5作戦は変わらない**：命令は時刻 0（会戦開始前）のものだけで、赤の逆襲の伝令の経路も R3 までほぼまっすぐなので、結果は1つも変わらなかった
2. **ステージ2の「拘束＋迂回（近い拘束）」（0.05→1.00）：赤の伝令が経路をたどって少し遅れ、逆襲の時機がずれた**（シード1・2で、P2a の版と並べて確かめた）
   - 赤の本部から R3 への伝令が、マスの中心を通る経路の分だけ 17.5秒遅れて着く（P2a：1090秒、P2b：1107.5秒）
   - P2a では、シード1・2とも R1 が崩れず、村への前進の命令は出なかった
   - P2b では R1 が崩れ（シード1で約 33分）、全中隊への村への前進が伝令で届いて（B2・B3・B4 へは 8〜9分後。B1 へは判断枠が空くのを待って約 25分後）、勝つ
   - シード1・2では、青の伝令は1人も倒れていない
   - 逆襲の時機のわずかなずれで、R1 が崩れるかが変わる、振れやすい作戦と読む
3. **ステージ2の総員突撃（0.90→1.00）**：命令は時刻 0 のものだけなので、変わったのは赤の逆襲の伝令の時機だけ。試行ごとの経過は追っていない
4. **「拘束＋迂回（段階つき）」**
   - ステージ1：勝率 0.15。遠い拘束の1段の版（0.30）より低い。崩れた青 2.95（B1・B4 が R1 の側面で崩れる）。迂回役は時刻 0 から待機地点へ向かい、T+18:00 の緑で攻撃に移る。1段の版では B4 は2分後に直接攻撃に出ていた。段階つきでは待機地点で揃ってから攻めるので、R1 への攻撃の始まりが遅く、その間に R1 の側（R3 の逆襲）の準備が進む、と読む（試行ごとの経過は追っていない）
   - ステージ2：勝率 1.00、青の損害率 0.305。1段の版（遠い拘束 1.00、0.259）と同じく勝つが、損害はやや多い
   - 白（村への前進）は R1 が崩れた刻みに上がり、全中隊が伝令を待たずに村へ向かう。1段の版では、4つの命令が伝令で届くのに 8〜9分かかり、1つは判断枠が空くのを待って約 25分後になっていた（ステージ2の近い拘束・シード1）。段階つきの版では、この待ちがない
   - 取り決めのとおり、作戦の作り込み（待機地点・信号弾の時刻の調整）はしていない

## 迷った点と、自分で決めた点

1. **［直す］と書きかけの起案**：書きかけがある間は［直す］を押せなくする方を選んだ（上の「表示」）
2. **起案の始め方**：起案がない中隊で命令を選んで地図をクリックすると、白紙から第1段を作る。起案があれば、書き込む段（▶）の命令を置き換える。新しい段は［段を足す］で足す
3. **足した段の条件の初めの値**：前の段が終わる命令なら「完了したら」。保持・拘束の後は未設定（選ぶまで発令できない）
4. **時刻の条件の初めの値**：今から5分後の分の切り上げ
5. **段の条件を調べる中隊**：指揮下の中隊だけ（壊走中・再集結中は調べない。指揮下に戻ったら、そのときの今の段から調べ直す）
6. **送付中の命令書が複数あるとき**：全て並べる。［直す］［取り消す］は準備中のものだけ
7. **地図の下見を出す命令書**：選んだ中隊の、実行中（2段以上のとき、今の段から）・最新の送付中・起案中の3つ
8. **会戦開始前の命令書**：伝令なしで届いた後も、会戦が始まるまでは「実行中の写しから」直して出し直せる（伝令なし・判断枠なし）
9. **段の番号の表示**：地図の円の中の数字は小さくて読めなかったので、到着予定の文字の前に「第2段」と出す形にした

## 触って確かめる項目（チェックリスト）

Unity 6.3 LTS で `Assets/Scenes/Battle.unity` を開いて再生する。

**命令書を組む**
- [ ] 中隊を選び、Q で地図をクリックすると、右パネルの「起案中」に第1段が書き込まれる（まだ出ない）。Enter（または［発令］）で出る

- [ ] 地図に「第1段　約 T+…」「第2段　信号弾 緑から 約 N分」などの段ごとの下見が出る（起案中は破線）

**発令・直し・取り消し**
- [ ] 会戦開始前の命令書は伝令なしで届き、再開した最初の刻みから第1段が始まる
- [ ] 再開後に発令すると「送付中」に「準備中 あと N秒」。［直す］で起案の欄に写り、直して［差し替え］で出し直せる（準備の残りは変わらない）
- [ ] ［取り消す］で伝令は出ず、上部バーの判断枠が空く
- [ ] 書きかけの起案がある間は［直す］が押せない
- [ ] 伝令が出発すると［直す］［取り消す］が消え、「未着 あと N秒」になる

**段の進行と信号弾**
- [ ] 駒と左パネルに「1/3　次：信号弾 緑」。条件を満たすと、出来事の欄に「第2段へ（…）」、練度の遅れの後に次の段が始まる
- [ ] 上部バーの［緑 (F10)］を1回押すと「もう一度で打ち上げ（緑）」が3秒出る。3秒以内にもう一度で打ち上がり、ボタンが消える。全中隊の信号弾 緑の段が進む
- [ ] 3秒を過ぎると構えが解ける（打ち上がらない）

**伝令の経路**
- [ ] 伝令の点が、敵の射界（F5 の赤）を避けて回り込み、川は橋か浅瀬で渡る。敵の駒の中は通らない
- [ ] 「未着 あと N秒」が、回り込んだ経路の分だけ長い
