## 5. 会戦の経過（勝ち方は狙いどおりか）

連動の 20回は、全て同じ時刻に砲撃が止む。止んだ時に B2 は 161m で、止んでから 21秒で接近戦の距離に入る。

**縁へ飛び込むところまでは、20回とも狙いどおり**。
- 砲撃が止んで赤の制圧が解ける 60秒の間に、縁へ入っている。
- 詰めるまでの損害は平均 5.1 兵（砲撃してから詰めるの約7分の1）。

**崩せるかは、その後の接近戦の長さで決まる**。B2 が接近戦に入るのは 8.1分ごろ。R1 を崩すのは 16.6〜28.2分で、8〜20分かかる。

- 負けた6回は、全て「縁に入った後、1対1 の接近戦で B2 が先に崩れた」形。
- 塹壕の赤は、接近戦でも R4 の 0.6 の守りがある。5分の砲撃（塹壕で損害 9%、士気 約 −26）では、1対1 で必ず勝てるほどには弱っていない。
- **連動・二波**（B1 が 2分後に同じ道で続く）は、B1 が早く着いて 2対1 になるので 0.95。
  - 狙った連動の作戦では、B1 は「B2 が接近戦の距離に入ったら」390m から動き出す。慎重な B1 が着くのは数分後で、間に合わない会戦がある。

**読み取り**：「止んだ直後の隙に縁へ飛び込む」（T17 の核心）は効いている。ただ、教程3 の青は2個中隊なので、飛び込んだ1個中隊が独りで塹壕と撃ち合う時間が長く、そこで負ける。
- 線の 0.8 に届かせるには、連動の作戦の形か、ステージの作りを変える必要がある。
- 合わせてよい制限時間と弾数では届かない。

## 7. 迷った点と自分で決めた点

1. **止む時刻の合わせ方**：S28 と同じ手順にした。

   - その会戦で B2 が 150m に着いた時刻が 30秒を越えてずれれば、着いた時刻に止むよう撃ち直す。
   - 結果、止んだ時の距離は 161m。ずれは 30秒の内なので、撃ち直しはしていない。
2. **B1 の動き**：
   - 連動：北の撃つ位置（塹壕から 390m、教程2 と同じ (622, 890)）へ前進して撃つ。B2 が接近戦の距離に入ったら（緑の信号弾）、塹壕の位置へ前進する（第2段）。
   - 二波：2分後の命令を本部から伝令で出す（教程の走らせ方のとおり。時刻 0 以外は伝令）。
3. **砲撃してから詰める**：B2 はまず塹壕の 500m 手前 (475, 725) へ前進して待つ。砲撃が止んだら（緑）、塹壕の位置へ前進する。砲撃の初弾は 1分（会戦前の計画射撃点への要請の一番早い時刻）。
4. **抑えてから詰める**：B2 は保持して、R1 が伏せたら（緑）塹壕の位置へ前進する。R1 は一度も伏せなかった。
5. **詰めるまでの損害**：接近戦の距離（矩形の隙間 50m 以内）に入るまで。入らなければ終わりまで（S28 と同じ）。
6. **掃き出しの弾数**：作戦の砲撃は 5分のまま。弾数が 40発より少なければ、尽きた所で止む。
