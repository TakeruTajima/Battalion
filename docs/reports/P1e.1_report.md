- **止められた中隊は「着いた」扱いにしない（ア）**

### 総員突撃の勝率は戻ったか

- **ステージ1：戻った（0.00→0.90。P1d の 0.40 より高い）**
  - P1e で R1 の脇に止まったまま動かなくなっていた B2 が、止められても着いた扱いにならないので、R1 が降伏して道が空いた後に村へ進む
  - 避ける範囲が広がったので、R1 の角に引っかかること自体も減った
- **ステージ2：下がった（0.85→0.05。P1d の 0.55 より低い）**
  - 原因（シード1で確認）：
    - B4 の目的地（B2 の目的地から 200m 離すためにずらした点）は、塹壕の R1 と R2 の間にある。2個の矩形の間は約 50m しか空いていないので、避ける範囲の中で、届かない
    - P1e（避ける範囲 110m）では、B4 は届くところまでの経路で R1 の北へ回り、R1 の側面を撃って崩していた（シード1では 34分に R1 が壊走し、村への道が開いた）
    - P1e.1（113m）では、届くところまでの経路の終わりが変わり、B4 は R1 の北西の角（1576, 1265）で止められる。止められても着いた扱いにならないので、R1 に正面を向けられず（向き直りは止まっている中隊だけ）、R2 からも側面を撃たれて 42分に崩れる
    - R1 が崩れないので、村に向かう B2 は R3 に側面と背面を突かれて崩れる（35分）
  - 平均で見ても、崩れた赤 2.25→0.55、崩れた青 1.10→3.30
  - 塹壕の線へ正面から突っ込む作戦なので、届くところまでの経路の終わる場所という小さな差で、R1 の側面に出られるかどうかが変わり、結果が大きく振れている、と読む
  - 下の「判断を仰ぎたい点」の1

### 「拘束＋迂回」に村への前進を足した結果

- **ステージ2の遠い拘束：報われた**
  - 勝率 0.60、赤が全て崩れた割合 0.95、R1 は全て降伏
  - R1 が崩れた後（38.5分）に B3・B4 が村へ進み、R2 も崩れる（19/20、50.1分）。ステージ2では全作戦で最も良い
- **ステージ1：勝てない（遠い・近いとも 0.00）**
  - ステージ1の村には R2 が籠っている（村のマスは被弾が減る）。R1 が崩れた後（遠い拘束では 43分）に、B3・B4 の2個中隊だけで村へ正面から進むので、B4 が崩れる（18/20、71分）。R2 が崩れるのは 6/20 だけ
  - 村へ進む段を足した分、青の損害率は 0.091→0.165 に上がった
  - 近い拘束は、R1 が向き直るので、B4 が発起点に着けない（0/20）
- **近い拘束は、両ステージとも遠い拘束より悪い**（P1e と同じ傾向）

## 判断を仰ぎたい点

1. **止められている中隊は、向き直りができない**
   - P1e.1 で、止められた中隊は「着いた」扱いでなくなった。P1d の向き直り（側面・背面から撃たれたら撃ってきた方へ向き直る）は、止まっている中隊（保持・陣地構築・着いた後の移動や攻撃）だけが対象なので、止められた中隊は撃たれても向き直らない
   - ステージ2の総員突撃の B4 がこの形で崩れた
   - 対案：止められている間（`BlockedByEnemy`）は、向き直りの対象に含める。今回は仕様に書かれていないので入れていない
2. **ステージ1の「拘束＋迂回」の続き**：籠った R2 に2個中隊で向かうのは足りない。B1（迂回の後、確保で止まっている）と、拘束を終えた B2 も村へ向かわせるか。作戦の定義は仕様側で決めてほしい
