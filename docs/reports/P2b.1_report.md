## 変わったこと

### Sim
- **段の自動追加**（`OrderSheetDraft.Write`）：起案中の最後の段に命令を書き込んだら、その下に空の段を1つ足し、そこを書き込む段にする（3段まで）。足した段の条件の初めの値は今と同じ（前の段が終わる命令なら「完了したら」、保持・拘束の後は未設定）。途中の段を書き直したときは足さない
- **空の段を落として発令**（`OrderSheetDraft.Problems`・`IsValid`・`ToSheet`）
  - 命令の入っていない段は、条件が未設定でも問題にしない
  - 発令のときに空の段を落として詰める。詰めて第1段になった段の条件は外す
  - 命令の入った段が1つもなければ発令できない
  - 命令の入った段の条件がない、保持・拘束の後に「完了したら」は今どおり発令できない
- **使った色の信号弾**（`OrderSheet.StageProblems` に使用済みの色を渡す口）
  - 使用済みの色の信号弾を条件に持つ段は「信号弾 緑は使用済み（届いた瞬間に満たしてしまう）」として発令できない
  - `SendSheet` と `ReviseSheet` でも同じ検査をする（使用済みの色の条件が残っていれば、出せない・差し替えられない）
  - すでに出発した伝令の命令書は変えない（届けば、上がったことが残るので、その段はすぐ満たす。P2b の規則どおり）
- **命令待ち**（`Simulation.AwaitingOrders(c)`。読み取りだけ）
  - 指揮下の中隊で、命令書がない、または最後の段を終えた（「完了」の判定は段の表と同じ。保持・拘束は終わらない）
  - 会戦開始前は、命令書を受けていない中隊が全て命令待ち
  - 新しい命令書が**始まる**と解ける。届いてから練度の遅れの間は、届く前の状態（命令待ちだったか）を保つ（届いた時点の状態を中隊に覚えさせた。会戦の規則には使わない）
  - 壊走中・再集結中は命令待ちにしない（状態の表示が先）

### 表示（View）
- **起案**：命令を選んで地図をクリックすると、書き込んだ段の下に空の段が自動で足され、▶ がそこへ移る。続けて地図をクリックすれば次の段に書き込める。前の段を直すときは、その段の行をクリックしてから書き込む。［段を足す］は残した
- **空の段**：赤い印を出さない（発令を止めない）
- **信号弾の条件のボタン**：使った色は押せなくし、「赤済」のように出す
- **送付中の準備中の命令書**：使用済みの色の条件が残っていれば、その段に赤い「×」と理由を出す（［直す］で直すか［取り消す］）。起案中の段にも同じ印を出し、［発令］［差し替え］は押せない
- **命令待ち**
  - 駒の上に灰色の小さな札「命令待ち」。送付中の命令書があれば「命令待ち・未着 あと 65秒」
  - 左パネル・右パネルの状態に「命令待ち」（灰色）
  - 出来事の欄に「B2 命令を終えた（命令待ち）」。会戦の初めは全て命令待ちなので、そこからの変わり目だけを出す
  - 出来事は View の側で状態の変わり目を見て出す（Sim のログに足すと、通し実行のログが変わるため）
- 撮影：`docs/reports/P2b.1/awaiting_and_in_transit.png`（命令書のない B3 に「命令待ち・未着 あと 65秒」の札）

### テスト
- `P2b1Tests`（5件）
  - 最後の段に書き込むと空の段が下に足され、3段で止まる。途中の段の書き直しでは足さない
  - 空の段を含む命令書が、空の段を落として発令される（間の空の段も詰める。第1段が空なら、詰めて第1段になった段の条件は外れる。全て空なら発令できない）
  - 命令の入った段に条件がなければ、今どおり発令できない
  - 命令待ち：会戦開始前は全中隊。前進の最後の段に着くと命令待ち。保持・拘束では命令待ちにならない。新しい命令書は、届いても始まるまで命令待ちのままで、始まると解ける
  - 使った色を条件に持つ命令書は発令できず、準備中の差し替えもできない（直せば差し替えられる）。起案中の段にも印
- 直したテスト：P2b の「命令書が届く前に上がった信号弾でも進む」は、上げた後の色を条件にした命令書を出す形だったので、P2b.1 で発令できなくなった。命令書を出した後、届く前に上げる形に直した

## 迷った点と、自分で決めた点

1. **自動で足した後の書き込む段**：足した空の段へ移す（続けて地図をクリックすれば、第2段・第3段と順に書ける）。前の段を直したいときは、その段の行をクリックしてから書き込む
2. **使用済みの色の検査の置き場所**：View だけでなく Sim（`SendSheet`・`ReviseSheet`）でも止める。単体テストで確かめられ、画面の他の道から出しても止まる
3. **命令待ちの「新しい命令書が始まると解ける」**：届いた命令書の第1段の開始待ちの間は、届く前の状態のまま（命令待ちだったなら命令待ち）とした。命令待ちでない中隊に新しい命令書が届いても、命令待ちにはならない
4. **壊走中・再集結中の中隊**：命令待ちにしない（指揮下でないため）。再集結して指揮下に戻ると、その時の命令書の状態で判定する
5. **命令待ちの出来事の重要度**：重要（赤字）にはしない。自動一時停止にも足していない（仕様にないため）

## 触って確かめる項目（チェックリスト）

**起案**
- [ ] 命令を選んで地図をクリックすると、第1段に書き込まれ、下に空の第2段ができて ▶ が移る。続けてクリックすると第2段に書き込まれ、第3段ができる。3段で止まる
- [ ] 空の段が残ったままでも［発令］が押せ、空の段は落ちて届く（送付中・実行中の欄に空の段がない）
- [ ] 命令の入った段に条件がないと、今どおり赤い「×」が出て発令できない

**命令待ち**
- [ ] 会戦開始前は、全ての青の駒に灰色の「命令待ち」の札が出る。命令書を出すと消える
- [ ] 前進の最後の段に着くと、札が出て、出来事の欄に「B2 命令を終えた（命令待ち）」
- [ ] 保持・拘束の中隊には札が出ない
- [ ] 命令待ちの中隊に命令書を出すと「命令待ち・未着 あと N秒」になり、届いて練度の遅れの後に始まると札が消える

**使った色の信号弾**
- [ ] 信号弾を上げた色は、起案の条件のボタンが「赤済」のように押せなくなる
