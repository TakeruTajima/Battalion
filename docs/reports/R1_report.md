## v4 に要る点（Python で同じ規則を作るために）

設計報告の5 に、規則3 と、解けるまでの秒数・小銃の制圧下の撃つ力を足したもの。

1. **火力の量**（目標ごと、毎分）：その刻みの全ての射撃について、`k × 射手の兵数 × f_質 × f_距離 × f_向き × f_状態 × f_その他` を足す。
   - 損害の式から、守りの `f_地形`（地形・塹壕・陣地構築・浅い掩体・開けた所を動く倍率）だけを除いたもの。乱数は使わない（λ の期待値）。
   - `f_状態` は、射手の動揺 ×0.7、正面の弧の外の目標 ×0.5、隊形の乱れ、制圧下 ×`suppression.fire_mult`、動いた刻み ×`fire.moving_fire_mult` を含む。
   - `f_向き` は撃たれる側から見た向き（正面 1.0・側面 1.5・背面 2.0）。`f_その他` は追撃・離脱中の倍率。
2. **しきい値**：止まっている中隊は 3.5。動いている中隊（移動を伴う命令でまだ着いていない）は 1.5 × 性格の倍率。S1〜S6 は全て止まっているので、3.5 だけでよい。
3. **揺れ止め**（刻み 0.5秒）：
   - 制圧下でない中隊は、火力の量 ≥ しきい値の刻みが 20 続いたら（10秒）、その刻みの終わりに制圧下になる。
   - 制圧下の中隊は、火力の量 < しきい値 × 0.5 の刻みが 120 続いたら（60秒）解ける。
   - 条件が途切れたら、数え直す。指揮下でなくなったら（壊走など）、状態と数えを消す。
4. **効き目の順番**：
   1. その刻みの射撃を、刻みの初めの状態（射手の制圧下を含む）で計算し、火力の量を積む
   2. 損害と士気をまとめて適用する
   3. 制圧の状態を更新する
   4. 撃つ力 ×0.25 は、次の刻みの射撃から効く
5. **規則1・3、伏せて止まる**は、動く中隊がいない S1〜S6 では効かない。
6. 上の表の C# の値が、v4 と突き合わせる相手になる。

  - その代わり S7 では、真ん中の中隊も初めの 10秒で伏せて止まる。S7 の損害は 4〜5% と小さくなり、S8 の損害（約 6%）がその 2/3 を超える。

## 4. S7 を満たせない理由（仕様の初めの案、シード1 を 15秒ごとに見た）

1. **守備は一度に1個中隊しか撃てない**。正面の弧の中で一番近い B（真ん中）だけを撃つ。
   - B は 10秒で伏せて止まり、守備から 390m の所で 9分間伏せたままになる。伏せている間は規則1 の倍率が掛からず、受ける損害は毎分 1〜2人。
   - 守備が制圧下になって撃つ力が半分（約 1.0）になっても、解ける線（0.75）を下回らないので、B は伏せたまま。
2. **A・C は一度も撃たれない**（受けている火力は終わりまで 0）。
   - 経路の脅威の重みで守備の射界を避け、大きく回り込む（y が ±370m まで外へ）。そのまま守備の側面の位置（x=400、y=±200）に着く。
3. **守備は、側面から撃たれて崩れる**。
   - 4分24秒に、A・C（動きながら撃つ ×0.5、側面 ×1.5）と B（伏せたまま撃つ）の火力の量が 3.9 になり、守備は制圧下になる。
   - 守備は 9分に動揺し、10分12秒に壊走した。壊走時の士気の減りの内訳は、側面 −48、背面 −19.5、正面 −3.5。
4. **まっすぐ突撃させても変わらない**。A・C の脅威の重みを 0 にして（回り込まずに）4組で回した。
   - 守備は全て崩れ、S7 の損害は 7〜14%。
   - 攻め3個中隊の正面（600m）は守備（200m）の3倍あるので、A・C はどう進んでも守備の正面の弧の外（側面）に着く。

まとめると、制圧の規則は「撃たれた1個中隊が伏せて止まる」を出す。しかし守備が1個中隊しか撃てないので、残りの中隊は代償なしに詰められる。そのうえ伏せた中隊は止まって撃つ側に回り、守備を制圧する。S7 の期待（攻めが失敗する）は、この組み合わせでは出ない。

## 5. 判断を頼みたいこと（どれも実装していない）

1. **守備の射撃を、正面の弧の中の敵に分ける**：射界を進む全ての中隊が代償を払う形。
   - 1個中隊が撃つ総量は今と同じで、分ける。
   - S1〜S6（1対1、2対1）の結果も変わりうるので、v4 に入る。
2. **S7 の場面を変える**：たとえば守備の正面を攻めと同じ幅にする（塹壕の線に3個中隊）。または攻めを縦に重ねる（後ろの中隊は前が崩れたら出る）。
   - 今の正面 600m 対 200m では、規則によらず A・C が側面に着く。
3. **S7 の期待を見直す**：今のモデルの 3対1 では、守備は崩れる。「攻めの損害が大きい」「攻めが頓挫する（時間内に崩せない）」の、どちらで見るかを決め直す。

1 がもっとも効くと考えるが、規則の追加なので仕様の判断を待つ。値の掃き出しは、決まった後に同じ道具（`R1SceneTests.Sweep`）で回し直す。

## 6. 実装したもの（設計どおり）

**Sim**
- 火力の量（`Company.IncomingFirePerMin`）：`Resolve` で、損害の式から `f_地形` だけを除いた値を目標ごとに足す。一番多い射手（`MainShooterId`）も残す。
- 制圧（`SimulationSuppression.cs`）：始まりと終わりの揺れ止め、姿勢で変わるしきい値、性格の倍率（動いている間だけ）。
  - 伏せて止まる（`PinnedDown`／`LieDown`）。後退の命令は動ける。接触の距離では止まらない。
  - 指揮下でなくなったら消す。ログに `suppressed`／`suppression_end` を出す。
- 撃つ力：制圧下 ×`fire.suppressed_mult`、その刻みに動いた射手 ×`fire.moving_fire_mult`（規則3）。
- 制圧下は、移動を伴う自律行動（物陰へ寄る、陣地に入る、回り込みの待ち）をしない。向きの規則は今どおり。
- 検証の場面 S7〜S9（`Scenarios`）：塹壕のマスと、時刻つきの前進の命令。
- パラメータ（`sim_params.json`）：`fire.moving_fire_mult` と `suppression` の節（設計報告の6のキー）。値は仮（仕様の初めの案）。`terrain.moving_open_damage_mult` は 1.0 のまま。

## D. 理由（シード1 を 30秒ごとに見た、仕様の初めの案）

**S7：伏せる・進むを交互に繰り返して、安く詰める**
- 守備は一度に1個中隊しか撃てない。正面の弧の中で一番近い中隊を撃つ。
- A が撃たれて伏せると、守備は進んでくる C の方が近くなって C に替える。
- A への火力は 0 になり、20秒で制圧が解けて A が進む。すると今度は A が近くなり、守備は A に替える。
- この繰り返しで、前の2個中隊は交互に約 20m ずつ躍進する。
  - 撃たれながら動くのは、制圧が始まるまでの 10秒だけ。規則1 の倍率はほとんど掛からない。
  - 伏せている間も、規則3 の ×0.5 は掛からず、撃ち続ける。
- 約 14分で守備の線に着き、接近戦（×2.0）になる。
- 守備は、両脇が水で後ろへ下がる間も撃たれ続けるので、退路の見積もりで「包囲」になる（士気 −16）。17分で壊走し、降伏した。
- これは「火力と運動」（片方が伏せて撃つ間に片方が進む）が規則から出たもので、規則の誤りではない。ただ、解けるまでの 20秒が短いため、1回の躍進の代償が小さい。

**S8：1個中隊だけの突撃が、30分に間に合わない**
- 保持の A・C（300m）の火力の量は約 4.0 で、守備は制圧下になる（撃つ力 ×0.5）。ただし塹壕（×0.3）の守備には、ほとんど損害を与えない。
- B は 5分後に、止まっている A・C の間を抜ける（超越の ×0.5）。守備の線に着くのは約 16分。
- 守備の撃つ力は半分（約 1.0）なので、B は伏せずに着く。そこから先は、1個中隊どうしの接近戦。守備の士気は 30分までに崩れる所まで下がらない（シード1 は 30分で士気 37）。
- 攻めの損害は、主に B が接近戦で受けるもの。S7 のように2個中隊で交互に詰めないので、1個中隊に損害が集まる。

## D. 選んだ値と理由

**解けるまで 60秒の組を選んだ**。理由は次の2つ。
