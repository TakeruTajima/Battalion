# P2c 設計報告：中隊長の自律行動

仕様「P2c：中隊長の自律行動（確定）」の実装の設計。返答があるまで実装には入らない。

## 1. 持ち場と裁量の持ち方

### 持ち場
- 中隊に `PostPoint`（地点）を持たせる。会戦の規則が読むのはこの値だけ
- 決まる時と値
  | 時 | 持ち場 |
  | --- | --- |
  | 保持・陣地構築の命令を始めた | 目的地があればそこ、なければ今の位置 |
  | 前進・後退の命令を始めた | 目的地 |
  | 拘束の命令を始めた | 拘束点（詰める先の点。詰めないときは今の位置） |
  | 攻撃の命令を始めた | 未定（攻撃の途中は全ての中隊長の自律行動の対象にしないので使わない） |
  | 攻撃の目標を崩して確保した（追撃を終えて確保した、を含む） | 確保した位置。崩した敵の陣地に入ったら、入った位置 |
  | 再集結を終えて指揮下に戻った | 今の位置 |
  | 独断を限度で止めて命令待ちになった | 今の位置 |
- 独断の間は持ち場を動かさない（限度は独断を始める前の持ち場から測る）
- 物陰へ寄る・浅い掩体・向き直りでは持ち場を動かさない（持ち場から 100m の内で動くだけ）

### 裁量
- 命令書の段（`Stage`）に `Discretion`（`Delegate` 任せる／`Strict` 厳命）を足す。初めの値は任せる
  - `OrderSheet.Single(order)`（会戦開始前の命令、通し実行、台本の命令）は全て任せる
  - 起案（`OrderSheetDraft`）の段にも持たせ、`ToSheet` で写す。空の段を詰めても段の裁量はついていく
- 中隊は「今の段の裁量」を `Company.Discretion` に持つ。段の命令が始まった刻み（`ApplyOrders` で、その命令が今の命令書の今の段の命令と同じもの）に写す
- 命令書を終えた後（命令待ち）も、最後の段の裁量のままにする（迷った点 4）
- 命令（`Order`）には足さない。攻撃の「崩れたら：確保／追撃」は今どおり命令の字面

## 2. 判断の置き場所と順番

### 置き場所
`Step` の最後（`UpdateStages` の後）に `UpdateAutonomy` を足す。この刻みの射撃・向き直り・状態の変化・段の進みを全て見た上で決め、動きは次の刻みの `Move` から効く。

```
RebuildVisibility → 台本 → UpdateRunners → ApplyOrders → Move → UpdateFortified → SelectTargets → Resolve
→ UpdateFacingReaction → Transitions → UpdateStages → UpdateAutonomy（新）→ 記録
```

追撃（P1d の 4）と猪突の「確保でも追う」は今どおり `UpdateAttack`（目標が崩れた刻み）の中で決める。崩れた刻みに決めないと、1刻み確保してから追うことになるため。

### 対象から外す中隊（全ての中隊長の自律行動・機敏の独断で共通）
- 指揮下でない（壊走・再集結）
- 次の刻みに適用される命令がある（段が進んだ、伝令が届いた）
- 命令で動いている（着いていない。P1g の見える位置へ詰める動き、P1e.1 の阻まれての引き直しを含む）
- 追撃中、独断で攻撃中
- 攻撃の途中（発起点に着いて方角を固定した後も。攻撃の自分の規則で動くため）

動揺で停止中（P2b.2）は対象に含める（仕様どおり）。停止を解く再開の規則はそのまま。

### 中隊ごとの順番（上から、当てはまった1つだけをその刻みに始める）
1. **独断の続き**：猪突の追撃の後に続けて攻めかかる（追撃を終えた刻みに決める）
2. **崩した敵の陣地に入る**（確保した刻みに決める）
3. **物陰へ寄る**（慎重の任せるは 200m・後ろ向きも可。これが独断の後退）
4. **機敏の回り込み**（止まっていて、自分の撃てる目標がないとき）
5. **浅い掩体を掘る**（動かないので他と重なる。条件を満たす間は進める）
6. **撃てる目標がないときの向き**（一番下。他の動きを始めた刻みはしない）

向きの優先：P1d の向き直り（側面・後ろから撃たれた）＞ 攻撃・追撃の向き ＞ 自律行動の向き ＞ 命令の向き。自律行動の向きは `Company.AutoFacing` に持ち、`FacingOverride` がなく撃てる目標もないときだけ `Move` の向きの計算で使う。撃てる目標ができた、命令が来た、600m 以内に敵がいなくなった、で消す（命令の向きに戻る）。

### 自律行動の小さな動き（物陰へ寄る・陣地に入る）の作り
- 命令（`CurrentOrder`）は変えない。目的地（`MoveGoal`）と経路だけ引き、`Company.AutoMove`（種類：物陰／陣地）を立てる
- 段の完了（前進・後退の「着いた」）と命令待ちの判定は、`AutoMove` で動いている間も「命令の動きは終わった」と扱う（いまの `Arrived` のままだと、物陰へ寄るたびに完了が外れて命令待ちが点滅するため）
- 新しい命令が始まったら `AutoMove` は消える

## 3. 全ての中隊長の自律行動

### 撃てる目標がない → 最も近い既知の敵の方を向く
- 「既知の敵」：P2d の霧が入るまでは、その陣営から見えている指揮下の敵（`RebuildVisibility` の結果。View の見え方と同じ）
- 600m 以内で最も近い1つ。いなければ今の向き。回る速さは今どおり
- 保持の命令で向きを指定していても向く（迷った点 6）

### 開けた所で撃たれている → 物陰へ寄る
- 被弾の続き：`Company.UnderFireSince`。被弾倍率（今の `TerrainDamageMult`）が 1.0 以上の所で撃たれた刻みに、空なら今の時刻を入れる。`cover_fire_gap_sec`（10秒）撃たれなければ空に戻す
- 30秒続いたら探す。見つかったら練度の遅れ（`OrderStartSec`）の後に動き出す。その間に撃たれなくなったり命令が来たら取りやめ
- **探し方**：持ち場から半径 R（100m。慎重の任せるは 200m）の内のマスの中心（地図は 50m のマス。100m で約 13マス、200m で約 50マス）
  - 通れるマスで、マスの被弾倍率（止まっている時の値）が今の 0.7 倍以下
  - 慎重の任せる以外は、今の向きから 90°より後ろのマスを除く（「後ろ向きも可」は慎重の独断）
  - 並べ方：(1) 今の目標（撃っている敵）が射程内で見え続けるマス（`LineOfSight.Visible`）、(2) 被弾倍率の低いマス、(3) 今の位置から近いマス
  - 拘束の中隊は (1) を条件にする（見えなくなるマスには寄らない。拘束の目的を守る）
  - 見つからなければ動かず、`cover_retry_sec`（30秒）後にまた探す
- **重さ**：探すのは条件を満たした刻みだけ（中隊ごとに 30秒に1回まで）。1回あたり最大 50マス × 視線1本。今の P1g の見える位置を探す動きと同じくらい
- 「浅い掩体」は場所ではなく中隊が持つものなので、寄る先には数えない。掘ってある中隊は今の被弾倍率が 1.0 を下回り、「開けた所」でなくなる（迷った点 2）
- 慎重が任せるで 100m を越える、または後ろへ寄るときは独断として宣言する（「B1（慎重）独断で後退（物陰へ）」）。100m 以内で前・横なら全ての中隊長の動き（「物陰へ（開けた所で被弾）」）

### 止まって静か → 浅い掩体
- `Company.StillSince`（最後に動いた時刻）と最後に撃たれた時刻を持つ
- 120秒動かず、60秒撃たれていなければ掘り始める。`ScrapeProgress` を刻みごとに足す。掘り始めた後は撃たれても続ける（動かない限り。迷った点 3）
- 被弾倍率：開けた所（平地・砲撃痕）にいて止まっている間だけ、地形の値に 1.0 → 0.6 を進捗（300秒）で掛ける
- 動いたら 0 に戻す。陣地構築の命令中・陣地構築の進捗があるとき・塹壕と村の上では掘らない（重ねない）
- 籠城（士気の ×）には数えない。地図に塹壕は作らない

### 攻撃の目標を崩して確保した → 崩した敵の陣地に入る
- 目標が指揮下でなくなった刻みの、目標の中心の位置を覚える
- そのマスが塹壕・村で、確保した地点から 200m 以内なら、そこへ動いて固める（着いたら持ち場はそこ）。250m なら入らない
- 追撃・猪突の独断で追った場合は、追撃を終えて確保した地点から測る

## 4. 性格の独断（任せるのとき）

### 前進・攻撃を拒む士気（猪突 40・慎重 60）
- いまの「動揺中は前進・攻撃を拒む」（`ApplyOrders` の拒み、`Transitions` の動揺で前進を止める）を、士気の値で判定するように変える。値は性格と裁量で決める
  | | 任せる | 厳命 |
  | --- | --- | --- |
  | 猪突 | 40 以下で拒む | 50 以下 |
  | 慎重 | 60 未満で拒む | 50 以下 |
  | 冷静・機敏 | 50 以下 | 50 以下 |
- 状態（正常・動揺）は今どおり 50 で決める。猪突は「動揺していても進む」、慎重は「正常でも止まる」
- 止めた段は P2b.2 の「動揺で停止中」と同じ仕組み（`ShakenHalt`）で預かり、士気がその値を越えたら練度の遅れの後に再開する。表示は慎重のときだけ「士気低下で停止中（慎重）」
- **今のコードには慎重の 60 がない**（全ての性格が 50）。仕様は「今の表どおり」としているが、P2c で初めて入る（迷った点 1）

### 追撃の規則（P1d の 4 の読み替え）
`OnAttackTargetBroken` で決める。追えるのは目標が壊走中のときだけ（今どおり）。

| | 「確保」の字面 | 「追撃」の字面・任せる | 「追撃」の字面・厳命 |
| --- | --- | --- | --- |
| 猪突 | 任せるなら独断で追う（限度 900m、宣言）。厳命なら確保 | 追う（900m） | 追う（600m） |
| 機敏 | 確保 | 追う（600m） | 追う（600m） |
| 冷静 | 確保 | 追う（600m。400m 以内に指揮下の敵がいれば追わない・止める） | 同じ |
| 慎重 | 確保 | 追わない（独断。宣言なし、出来事の欄に理由） | 追う（600m） |

- 600m・900m は今の `behavior.pursuit_limit_m` と `pursuit_limit_mult`（猪突 1.5、慎重 0）をそのまま使う。厳命のときは倍率を 1.0 とする
- 限度は追い始めた地点（＝確保するはずだった地点＝持ち場）から測る（今どおり）

### 猪突：追撃の後に続けて攻めかかる
- 追撃を終えた刻み（限度・目標の降伏など）に、任せるの猪突なら、今の位置から 400m 以内の**動揺・壊走中**の敵で最も近いものを探す
- いれば、内部で**攻撃の命令**（`Order.Attack(目標, 範囲なし, 崩れたら：追撃)`）を自分に出す。伝令は使わず枠も使わない。`ApplyOrders` を通さずにその場で始める（練度の遅れなし。追撃の続きのため）
- `Company.Independent`（独断の種類：猪突の攻撃／機敏の回り込み）と `IndependentOrigin`（独断前の持ち場）を立てる
- 崩したらまた追い、また探す。どの時点でも `IndependentOrigin` から 900m を越えたら止まって保持し、独断を終える（持ち場は今の位置、命令書を終えていれば命令待ち）
- 壊走中の敵を「攻撃」の目標にすると、その刻みに「目標が指揮下でない」→ すぐ追撃に移る。結果として壊走中の敵には追撃、動揺中の敵には攻撃になる

### 機敏：味方に正面から撃たれている敵の側面へ
- 対象：任せるの機敏で、正常、止まっていて（命令待ち・保持・確保・拘束・着いた後）、自分の撃てる目標がない（迷った点 8）
- `agile_check_sec`（5秒）ごとに、この刻みの射撃の記録から「別の青の中隊に正面から撃たれた、500m 以内の指揮下の敵」を探す（近い順）
- その敵に側面の範囲（P1e の 4。発起点は今どおり 250m）で攻める方角と発起点を計算し、経路を引く（見積もり用、記録に残さない引き方）
  - 経路の長さ 600m 以内、発起点が持ち場から 600m 以内、の両方を満たせば、内部で**攻撃の命令**（`Order.Attack(目標, 側面, 崩れたら：確保)`）を自分に出す。練度の遅れの後に動き出す
  - 満たさなければ回り込まない
- 崩したらそこで確保（戻らない。持ち場はそこ）。崩す前に目標が別の味方に崩されても同じ
- 独断の攻撃の途中も 600m の限度は見ない（発起点で確かめ済み）

### 独断の攻撃と命令書の関係
- 独断の攻撃は命令書の段を変えない（`StageIndex` はそのまま）。目標を崩しても段の「完了したら」には数えない（`StageCompleted` を触らない）
- 次の段が時刻・信号弾・完了で始まったら、独断を捨ててその段を始める（プレイヤーの計画を先にする）。新しい命令書が届いたときも同じ
- 例：「攻撃（確保）→ 完了したら 前進」の命令書なら、猪突は目標を崩した刻みに第2段が始まるので追わない

### 慎重
- 物陰を探す範囲を 200m（後ろ向きも可）、拒む士気 60、「追撃」の字面でも追わない。厳命なら全て字面どおり（100m・前と横、50、追撃は 600m）

### 冷静
- 独断なし（任せるでも厳命と同じ動き）

## 5. 赤の中隊への効き方
- 赤も同じ規則で動く。台本の命令（`SendScriptOrder`・`Issue`）は全て任せる
- 今の赤は全て冷静（`MapScenario.PersonalityOf`）なので、独断は起きず、全ての中隊長の自律行動（向き・物陰・浅い掩体・陣地に入る）だけが効く
- 台本は今どおり（作り込みはしない）

## 7. パラメータのキー（提案）

`sim_params.json` に新しい節 `autonomy` を足す。追撃の限度は今の `behavior.pursuit_limit_m`・`pursuit_limit_mult` を使い直す（新しいキーは作らない）。

```json
"autonomy": {
  "post_radius_m": 100,
  "face_enemy_radius_m": 600,
  "cover_under_fire_sec": 30,
  "cover_open_mult": 1.0,
  "cover_mult_ratio": 0.7,
  "cover_fire_gap_sec": 10,
  "cover_retry_sec": 30,
  "scrape_still_sec": 120,
  "scrape_quiet_sec": 60,
  "scrape_dig_sec": 300,
  "scrape_damage_mult": 0.6,
  "enter_position_radius_m": 200,
  "advance_refuse_morale": { "cautious": 60, "calm": 50, "agile": 50, "reckless": 40 },
  "reckless_followup_radius_m": 400,
  "agile_watch_radius_m": 500,
  "agile_path_max_m": 600,
  "agile_post_limit_m": 600,
  "agile_check_sec": 5,
  "cautious_cover_radius_m": 200
}
```

- 仕様にない値：`cover_fire_gap_sec`（撃たれ「続けた」の途切れの幅）、`cover_retry_sec`（見つからなかったときの探し直し）、`agile_check_sec`（機敏の見回りの間隔）。いずれも重さと点滅を避けるための値

- 猪突の 900m は `behavior.pursuit_limit_m × pursuit_limit_mult.reckless` で、追撃と続けて攻めかかる独断の両方の限度に使う

## 9. 迷った点（素直な解釈を提案に入れた）

1. **慎重の「士気 60 未満で止める」が今のコードにない**：仕様は「今の表どおり」とあるが、今は全ての性格が 50 で拒む。P2c の任せるの慎重として入れる。通し実行の B1（慎重）の動きが変わる
2. **物陰の「または浅い掩体」**：浅い掩体は中隊が持つもので、寄る先の場所にはならない。掘ってある中隊は「開けた所」ではなくなる（物陰を探さない）、と読んだ
3. **浅い掩体を掘る場所と、撃たれたとき**：開けた所（平地・砲撃痕）だけで効かせる（森・村の上で ×0.6 を重ねると強すぎるため）。掘り始めたら撃たれても続ける（動かない限り）
4. **命令書を終えた後の裁量**：最後の段の裁量のまま。厳命で終えた中隊は命令待ちになっても独断しない
5. **既知の敵**：P2d までは、その陣営から見えている敵
6. **保持で向きを指定したとき**：撃てる目標がなく 600m 以内に敵がいれば、そちらを向く（敵がいなくなれば指定の向きへ戻る）
7. **猪突の厳命の「追撃」の字面**：限度 600m（900m は独断の限度）
8. **機敏が回り込む条件**：自分に撃てる目標があるときは回り込まない（いま撃ち合っている所を捨てない）。拘束・陣地構築の途中でも、撃てる目標がなければ回り込む（任せるの短所「持ち場や連携から外れる」）。動揺中は回り込まない（攻撃を拒む状態のため）
9. **「正面から撃たれている」**：射撃の記録の向き（`Aspect.Front`）で、撃った側が自分以外の味方であること。その刻みの記録だけで見る
10. **独断の攻撃と段**：独断で崩しても段の完了に数えない。次の段・新しい命令書が来たら独断は捨てる
11. **拒む士気の「以下」と「未満」**：猪突 40 以下、慎重 60 未満、ほか 50 以下と、仕様の書き方どおり分ける
12. **崩した敵の陣地**：「敵がいた位置」は、目標が指揮下でなくなった刻みの目標の中心。そのマスが塹壕・村なら入る
13. **物陰の「後ろ向き」**：今の向きから 90°より後ろのマス。慎重の任せるだけが選べる
14. **攻撃の途中の中隊**：発起点に着いて撃っている間も、物陰へは寄らない（攻撃の規則が位置を決めるため）。浅い掩体と向きも攻撃の規則に任せる
