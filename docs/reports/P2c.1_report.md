仕様「P2c.1：撃てる目標がないときの向きの直し（確定）」を実装した。変えたのは自律の向きの規則と、通し実行の作戦の追加だけ（表示は変えていない）。

## 変わったこと

### Sim（`SimulationAutonomy.cs` の `UpdateAutoFacing`）
- **向く相手**：次の順に、最初に当てはまったもの
  1. 直近 30秒に自分を撃った、今も指揮下の敵。複数いれば撃った刻みの数が一番多い敵（同じなら最後に撃った方、それも同じなら ID の小さい方）。視線は問わない
  2. 自分から視線の通る、400m 以内の指揮下の敵で、最も近いもの
  3. 同じく 600m 以内の最も近いもの
  4. いなければ今の向きのまま
- **自分から見える敵**：P2c の「陣営のどれかから見える敵」（`KnownTo`）はやめた
- **向き直らない**：今の正面の弧（±60°）の 400m 以内に、自分から見える指揮下の敵がいれば、自律の向きを変えない
- **撃てる目標ができたら**：自律の向きを解き、命令の向きに戻す。その後は今どおり、射撃の目標選びと P1d の向き直りに任せる
- 撃たれた記録：中隊ごとに、撃ってきた敵ごとの撃たれた時刻（`Company.ShotBy`。30秒より古いものは捨てる）。刻みの最後に、その刻みの射撃の記録から足す
- P1d の向き直り（脇・背から撃たれた）があれば、そちらが先なのは今どおり

### パラメータのキー（`sim_params.json` の `autonomy` に足した。仕様側で反映してほしい）

```json
"face_shooter_memory_sec": 30,
"face_near_radius_m": 400,
"face_front_hold_m": 400,
```

600m は今の `face_enemy_radius_m` を使う。

  - `PlansWithPinAndFlank` に入れたので、7作戦の表・回数の表・ログのハッシュにも入る
- 向きの規則を止めた版（向く相手の距離と記憶を 0）で、P2c で切り分けた3作戦を任せる・厳命で回すテスト（`ThreePlansWithoutAutoFacing`）を足した

### 大きく変わった作戦と理由

1. **ステージ2の総員突撃（任せる 0.50→0.80、厳命 0.70→0.85）：「危ない敵」を向くようにした分だけ戻った**
   - P2c で見た負け方（着いた B3 が撃てない最も近い敵の方を向き、R2 に背中を撃たれる）は、規則2・3が「自分から見える敵」だけになったことと、規則1（自分を撃った敵）が先に来ることで減った
   - 向きなしの版（1.00）までは戻らない。差の 0.15〜0.20 は、残った向き直り（自分から見える 400〜600m の敵の方を向く）で、射程の外の敵に正面を向けている間に別の敵に脇を撃たれる形が残るためと読む（試行ごとの経過は追っていない）
2. **ステージ1の拘束＋迂回（近い拘束 0.05→0.20、遠い拘束 0.10 のまま）：ほとんど戻らない。守る側の R1 が、撃ってきた拘束役 B2 の方を向き続けるのは新しい規則どおりで、そこから先は P1g の動きとの組み合わせで負ける**
   - 近い拘束（20回の合計、P2c.1／向きなし）：B2 が R1 から背面を撃たれた 20／0回、R2 が B1 から側面を撃たれた 20／0回、R1 の壊走 9／19回、B4 の向き直り 40／1回、R2 の向き直り 22／1回

## 迷った点と、自分で決めた点

1. **規則1の「一番多く撃った敵」**：直近 30秒に撃たれた刻みの数で数える（損害の多さではない）。同じなら最後に撃った方、それも同じなら ID の小さい方。視線は問わない（撃ってきた方向は分かるため）。今も指揮下の敵だけ（壊走した敵は危なくない）
2. **「いなければ今の向き」**：向く相手がいないときは、自律の向きをそのままにする（命令の向きへは戻さない）。命令の向きに戻すのは、撃てる目標ができたときだけ
3. **正面の弧の 400m 以内に見える敵がいるのに撃てる目標がない場面**：射程（400m）と視線が撃つときと同じなので、実戦ではほぼ起きない（兵が 0 の敵など）。単体テストは兵を 0 にした敵で確かめた。規則は仕様どおり入れてある
4. **見つけたこと（直していない）**：P1g の「見える位置を探す」の横への動きは、視線の通る敵がいないと「接敵中」にならないので、進む方へ向きを変える。接触の距離（隙間 50m 以内）にいる敵は視線を問わず撃てるので、その敵に脇・背を見せる。ステージ1の近い拘束の負け方の直接の形。P1e の動き方の規則（接敵の判定）を、接触の距離の敵も含めるように直すかは仕様側で決めてほしい
5. **新しい作戦で B3 に村への前進を出さない**：確保の字面での独断を見るため。B3 は、独断しなければ R1 の跡で確保して留まる
