## 変わったこと

### Sim（`SimulationRunners.cs` ほか）
- **本部**：`MapScenario` に青 (100, 800)、赤 (2700, 1000)。`Build` が `SetHeadquarters` で渡す。地図ファイルは変えていない
- **命令の口**
  - `SendOrder(order)`：会戦開始前（時刻 0 のまま、まだ一度も刻みを進めていない）と、本部のない陣営は、伝令を使わずに次の刻みで受け付ける（`Immediate`）。それ以外は本部から伝令を出す（`Sent`）。判断枠がなければ出さない（`NoSlot`）
  - `SendScriptOrder(order)`：台本の命令（判断枠を数えない）
  - `Issue(order)`：今までどおり伝令を使わない口（単体テストと本部のない場面）
- **伝令**（1つの命令に1人）
  - 準備 30秒 → 秒速 3m で中隊の今の位置へ（毎刻み向き直して追いかける）→ 中心に着いたら命令を渡す → 同じ速さで本部へ戻る → 受領で判断枠が空く
  - 渡した命令は、練度の遅れ（`order_start_sec`）の後に始まる。それまでは古い命令で動き続ける。始める時点で、今までの規則（動揺中の前進・攻撃の拒否、後退の離脱）を当てる
  - 上書きは出した順で決める。より新しい命令を受けている中隊に、古い命令の伝令が後から着いたら捨てる（ログに `stale`）
  - 射界（伝令の陣営から見た露出の地図。10秒ごとに作り直す、P1a と同じもの）のマスにいる刻みごとに、1−0.997^0.5 で倒れる。本部の上と地図の外は数えない
  - 喪失の乱数は、戦闘の乱数とは別の系列（同じシードの PCG32 の別ストリーム）から引く
  - 発令から往復予定（30秒＋本部から中隊までの距離÷3m×2）の 1.5倍が過ぎても受領が来なければ、判断枠を空ける（受領報告なし）。その後に伝令が戻れば「遅れて届いた報告」とだけ出す
  - 盤上にいない中隊（降伏・離脱）へは、渡さずに戻る
- **予備隊の台本**：引き金の刻みに、赤の本部から R3 へ攻撃の伝令（判断枠は数えない）。倒れたら逆襲は起きない
- **ログ**：`runner_sent`・`runner_delivered`・`order_start`・`runner_returned`・`runner_lost`・`receipt_overdue`・`runner_undeliverable`（いずれも `side` 付き）

### 表示（View）
- **本部**：竿と陣営の色の旗、「本部」の文字
- **伝令**：本部と向かう中隊を結ぶ点線と、その上を動く点（行きは黄、帰りは水色）。倒れた伝令は消える（回答3のとおり。P2b で本部の知っていることだけに揃える）
- **未着・開始待ち**：駒の上と左パネル・右パネルの命令の欄に「未着 あと 95秒」「受領 開始まで 20秒」。倒れた伝令の命令は、本部から中隊までの予定で数え、過ぎたら「未着（到着予定を過ぎた）」
- **未着の命令の下見**：未着・開始待ちの命令の下見（中隊の今の位置から）を薄く出す。今の命令の経路もそのまま出す（届くまでは古い命令で動く）
- **上部バー**：判断枠「伝令 ●●○」（使っている数だけ塗る。満ちたら橙）。会戦開始前は「開始前：命令は即座に届く」
- **判断枠がないとき**：命令のボタンを押せなくし、キーでも選べない。理由「伝令が出払っている（最初に戻る予定まで あと N 秒）」（戻ってくる予定と、受領報告なしの強制開放の早い方）
- **出来事の欄**：「B2 命令受領」「B2 受領報告なし（伝令が倒れた可能性）」（青だけ）。駒の上に「受領」「受領報告なし」
- **自動一時停止**：「受領報告なし」を足した
- **保持（E）の出し方を変えた**：今までは E を押した時点で保持を出し、ドラッグで向き付きの保持をもう1つ出していた。伝令を2人使ってしまうので、**地図をクリックでその場の保持、ドラッグで向き付きの保持を、1つだけ出す**形にした

### 通し実行
- 作戦の命令は全て `SendOrder` で出す。時刻 0 の命令は開始前の命令として伝令を使わずに届く（回答2の仕組み）
- 判断枠がなければ、空くまで毎刻み出し直す（通し実行の道具の側で待つ）

### テスト（`P2aRunnerTests`、11件）
- 検算：
  - 600m の中隊への命令が 230秒で届き、通常の練度の遅れ 25秒の後（255秒）に動き出す
  - 430秒で受領が戻り、判断枠が空く
  - 射界を 100秒通る伝令 2000人のうち届いた割合が 0.997^100（74%）の ±3% 以内
- そのほか：
  - 届いて始まるまで古い命令（前進）が続く
  - 後から出した命令が残り、古い命令の伝令が後から着いたら捨てる
  - 判断枠が3で止まる
  - 倒れた伝令の枠が往復予定の 1.5倍（645秒）で空く。それまでは本部にとって未着のまま
  - 動く中隊を伝令が追いかけて渡す
  - 一時停止中に出した命令も 230秒で届く
  - 会戦開始前の命令は伝令なしで届き、枠を使わない
  - 赤の逆襲が、赤の本部からの伝令が着いて練度の遅れの後に始まる

### 直したテスト
- P1a の「予備隊が最も近い攻撃側の側面へ逆襲する」：引き金の次の刻みに攻撃が始まることを見ていた。伝令が着いて始まるまで進めてから同じことを確かめる形にした

### 大きく変わった作戦と理由

結果を動かしているのは主に次の2つ。

- **赤の逆襲が遅れて始まる**：赤の本部から R3 まで、ステージ1は 250m（準備 30秒＋83秒＋練度の遅れ 25秒＝約 2.3分）、ステージ2は 725m（30＋242＋25＝約 5分）。ステージ2の方がずっと遅い
- **時刻 0 より後の青の命令が遅れる**：本部 (100, 800) から遠い中隊ほど遅い。例えば北へ回った B1（約 (1975, 1250)）へは片道 1,900m 余りで、準備を入れて約 11分かかる。判断枠は3つなので、「R1 が崩れたら全中隊が村へ」の4つの命令は、1つが枠の空くまで待つ

1. **ステージ1の総員突撃（0.95→0.60）：B2 が村の手前で動揺して止まる**（シード1〜6で確かめた。負けた 1・5・6 は同じ形）
   - 命令は時刻 0 のものだけなので、変わったのは赤の逆襲の時機だけ（シード1：引き金 19.9分、伝令が着いて 22.3分に開始）
   - 逆襲が遅れた分、戦いの順番が変わる。B2 は村へ進む途中で R1 から側面を撃たれ（23.7分）、27.5分に動揺する
   - 動揺した中隊は前進をやめてその場で保持する（P0 からの規則）。B2 は村のマス（y 900〜1100）の 14m 手前の (1930, 886) で止まり、士気が戻った後もそこで保持し続ける。赤は全て崩れているが、村に青がいないので勝ちにならない
   - 台本の命令が状況に合わない形（取り決め3）なので、作り込みはしていない
2. **ステージ2の総員突撃（0.05→0.90）、両翼包囲（赤が全て崩れた割合 0.25→0.95）：赤の逆襲が約 5分遅れる**
   - P1g.1 では、R3 がすぐに逆襲に出て、正面の青を崩していた（崩れた青 3.45）。P2a では逆襲が始まる前に R1・R2 が崩れ、村が空く（崩れた赤 0.50→2.15）
   - 試行ごとの経過は追っていない。遅れの大きさ（約 5分）から、逆襲の時機が変わった影響と読む
3. **「拘束＋迂回」（ステージ1の遠い拘束 0.00→0.35、近い拘束 0.85→0.45、ステージ2の近い拘束 0.70→0.05、遠い拘束の赤が全て崩れた割合 0.90→0.20）：後からの命令が遅れる**
   - B4 の2分後の攻撃と、R1 が崩れた後の村への前進は伝令で届く。遠くの中隊ほど遅れ、4つの村への前進は判断枠で1つ待たされる
   - 赤の逆襲も遅れるので、どちらに傾くかは場面による。試行ごとの経過は追っていない
4. 正面火力戦・側面攻撃は、命令が時刻 0 のものだけで、赤の逆襲の影響も小さく、ほぼ変わらない

## 迷った点と、自分で決めた点

1. **保持（E）の出し方**：伝令を2人使わないよう、クリックかドラッグで1つだけ出す形にした（上の「表示」）。E を押しただけでは出ない
2. **到着予定の見積もり**：生きている伝令は、準備の残り＋伝令の今の位置から中隊の今の位置までの距離÷3m。倒れた伝令（本部は知らない）は、発令＋準備＋本部から中隊の今の位置までの距離÷3m で数える
3. **判断枠がないときの「戻る予定」**：本部の知っていることだけで見積もる（戻る途中の伝令は本部までの距離、往路の伝令は中隊を経由した距離。受領報告なしの強制開放の時刻と早い方）
4. **命令の下見**：未着・開始待ちの命令の下見は、中隊の今の位置から引く（届いたときの位置ではない）
5. **赤の逆襲の出来事**：「R3（予備）が … の側面へ逆襲」は、今までどおり引き金の時点（赤の本部が発令した時点）で出る。P2a では敵が全て見えているので、そのままにした。P2b で見え方を揃えるときに見直す
6. **伝令の点の大きさと色**：行きは黄、帰りは水色の小さな点（駒の印より小さく、射撃線と区別できる色）

## 触って確かめる項目（チェックリスト）

Unity 6.3 LTS で `Assets/Scenes/Battle.unity` を開いて再生する。

**会戦開始前**
- [ ] 時刻 0 のまま（一度も再開していない間）は、上部バーに「開始前：命令は即座に届く」。出した命令は伝令なしで、再開した最初の刻みから始まる。判断枠は使わない

**伝令**
- [ ] 再開した後に命令を出すと、本部の旗から伝令（黄の点）が 30秒後に出て、点線の上を中隊へ向かう。中隊が動いていれば追いかける
- [ ] 届くまで、中隊の駒と左パネルに「未着 あと N秒」が出て、中隊は古い命令で動き続ける。新しい命令の経路の下見が薄く出る
- [ ] 届くと「受領 開始まで N秒」になり、練度の遅れ（通常 25秒）の後に動き出す
- [ ] 伝令が戻る（水色の点）と、出来事の欄に「命令受領」、上部バーの判断枠が1つ空く

**判断枠**
- [ ] 3人とも出ていると、上部バーが「伝令 ●●●」（橙）になり、命令のボタンが押せない。理由と「最初に戻る予定まで あと N 秒」が出る
- [ ] 同じ中隊への命令を届く前に出し直すと、新しい伝令が出て、後から出した命令が残る

**伝令の喪失**
- [ ] 敵の射界（F5 の露出の地図の赤）を通る伝令が、ときどき消える
- [ ] 消えた伝令の命令は届かず、しばらくして「受領報告なし（伝令が倒れた可能性）」が出る。自動一時停止が入なら止まる。判断枠が空く

**赤の予備隊**
- [ ] 予備隊の引き金を引くと、赤の本部から R3 へ伝令が走り、着いてしばらくしてから R3 が動き出す

**保持の出し方**
- [ ] E の後、地図をクリックでその場で保持、ドラッグで向きを付けて保持（どちらも伝令は1人）
