# P1d 設計報告：行動の規則（着手前）

依頼文に従い、実装に入る前に設計をまとめた。**返答があるまで実装には入らない。** 仕様は `docs/spec.md` の「P1d：行動の規則（確定）」。

## 1. 攻撃の側の選び直しと、着いた後の方角の固定

- **命令に「側を指定したか」を持たせる**：今の `Order.FlankSide`（+1・−1・0）に加えて `FlankSideLocked`（プレイヤーが端をクリックして指定したら true）。
  - 予備隊の台本は、最初の側を「R3 の側」にするが、固定しない（`Locked = false`）
  - 機敏が指定なしから側面を選んだ場合と、プレイヤーが駒の中央をクリックした場合も固定しない
- **発起点に着く前**：固定していない側面の攻撃は、経路を引き直すたび（30秒ごと）に、今の位置から左右の発起点への経路コストを比べる。もう一方が今の側の 0.8 倍未満のときだけ替える
- **発起点に着いた後**（「撃ち始めたら」を「発起点に着いたら」と読む）：着いた時点の、目標の中心から見た自分の方角（地図の方角）と、目標の中心の位置を覚える
  - 以後は、目標が向きを変えても動かない
  - 目標の中心が覚えた位置から 50m 以上動いたら、同じ方角の 250m の点へ動き直し、位置を覚え直す
  - 50m は既存の `map_rules.attack_reposition_m` を使う
- 正面・背面の攻撃も、着いた後は同じく方角を固定する（仕様の「発起点に着いて撃ち始めたら」は方向を問わないと読んだ）

## 2. 敵の中隊と重ならない

**当たり判定**：中隊は向きのある矩形（正面幅 200m×奥行 50m）なので、2つの矩形の隙間を次のように出す。

- 分離軸（4本の辺の向き）で重なりを調べる。重なっていれば隙間は 0
- 重なっていなければ、互いの頂点から相手の辺への最短距離の最小が隙間
- 7個中隊の総当たりでも1刻み数百回の計算で、重さは問題にならない

**動きの止め方**：

- 動く中隊（指揮下の移動、押し離し、壊走の逃走）は、1刻みの移動の後の矩形と、敵の矩形（降伏を除く。壊走中・再集結中の敵は含む）の隙間が 10m 未満になるなら、そこまでで止める
  - 動かす割合を二分法で縮め、隙間が 10m 以上の範囲で最も進んだ位置に置く
  - 隙間がすでに 10m 未満のときは、隙間が広がる動き（離れる動き）だけを許す
- 旋回で矩形の角が敵に近づくことは扱わない（位置の移動だけを止める）
- 止められた中隊は、その刻みは「動いていない」扱いになる（塹壕の被弾倍率、陣地構築の進捗、移動中の被弾倍率は、今の「位置が変わったか」の規則のまま）

**経路探索**：

- 敵の矩形（降伏を除く）が掛かるマスを通れないマスとして避ける。10秒ごとに、露出の地図と同じ時に作り直す
- 出発のマスと目的地のマスは除く
- 届かないときは、探索で訪れたマスのうち目的地に最も近いマス（直線距離）までの経路を引く。今の「避けると届かなければ避けずに引く」（止まっている味方の周り）は、その後に試す

**退路の見積もり**：各方位の各点で、逃げる中隊の矩形（逃げる向きを向く）と敵の矩形の隙間が 10m 未満になったら、その方位は逃げられない（損害 1.0。川と同じ扱い）。

## 3. 拘束

- 命令を受けたときの「目標の中心から自分への方角」を覚え、その方角の 125m の点へ経路で詰める。着いたら目標に正面を向けて撃ち続ける（今の P1a と同じ）
- 30秒ごとに、目標の今の位置から同じ方角の 125m の点を計算し直し、50m 以上ずれていれば動き直す（攻撃の「着いた後」と同じ扱い）
- すでに 125m より近いときは、下がらずにその場で撃つ
- 敵の矩形の手前で止まる規則（2）が先に効く。目標の側面の方角から詰めると、中心どうしは 125m より遠い所で止まることがある（正面幅が 200m あるため）
- 拘束の命令は移動を伴う命令になる（`Order.Moves` に入れる）

## 4. 追撃の許可

- 攻撃の命令に `OnBreak`（`Secure`＝確保、初期値／`Pursue`＝追撃可）を持たせる
- 目標が指揮下でなくなったときの判断：
  - 確保の場合、および追撃可でも次のときは確保：慎重、冷静で自分の 400m 以内に指揮下の敵がいるとき
  - 追う：冷静（400m 以内に指揮下の敵がいないとき）、機敏、猪突
  - 判断は崩れた時点の1回だけ（追っている間に敵が近づいても、限界までは追う）
- **追う動き**：
  - 5秒ごとに、壊走中の目標の中心から自分の方へ 100m の点を目的地にして経路を引く（30秒の引き直しでは、毎秒 1.8m で逃げる目標に置いていかれるため）
  - 撃つ目標は追っている中隊に固定する（射程内で見えていれば）
  - 追撃を始めた地点から 600m（猪突は 900m）を越えたら、止まって確保に移る
  - 目標が降伏・離脱・再集結に入ったら、止まって確保に移る
- **確保の向き**：下の「判断を仰ぎたい点」の1
- 自動一時停止に「攻撃の目標が崩れた」を足す（青の攻撃の目標が崩れたとき）

## 5. 向き直り（どの命令の中隊が向き直るか）

| 命令 | 向き直るか |
| --- | --- |
| 保持 | する |
| 陣地構築（その場で掘っている、または目的地に着いた後） | する。進捗は失わない（動いていないので） |
| 攻撃（発起点に着いた後） | する。向き直った後は、攻撃の目標への強制の射撃をやめ、通常の目標選択に戻す（正面に来た撃ってくる敵を撃つ） |
| 攻撃（移動中）、前進・後退（移動中・着いた後とも）、拘束 | しない |

前進・後退で着いた後の中隊は「保持」と同じ状態だが、命令の種類を変えずに扱うため対象外にした。対象に入れるか、下の「判断を仰ぎたい点」の3で伺う。

**流れ**：

1. その刻みの射撃の記録で、自分が側面か背面から指揮下の敵に撃たれていて、性格の条件を満たせば、待ちの時計を始める
   - 慎重・冷静：正面の弧（±60°）の 400m 以内に視線の通る指揮下の敵がいない
   - 機敏：正面の弧の 150m 以内に指揮下の敵がいない（視線は問わない）
   - 猪突：向き直らない
2. 待ちの間に条件が崩れたら（正面の弧に敵が現れた、10秒間側面・背面から撃たれなかった）、時計を止める
3. 待ちが練度の遅れ（新兵40秒・通常25秒・古参15秒。既存の `training.order_start_sec`）に達したら、その時点で最後に側面・背面から撃ってきた敵の方へ、旋回の速さ（毎秒6°）で向き直る
4. 向き直った向きは、新しい命令が出るまで保つ（保持の命令の向きを置き換える）

## 6. 壊走中の味方のすり抜けと、隊形の乱れ

- 壊走中の中隊は、味方の矩形と重なっている（分離軸で重なりあり）刻みは、速さ ×0.5
- 重なった指揮下の味方は、その壊走中の中隊ごとに一度だけ、士気 −5（練度の減りやすさを掛ける。P0 の判断6と同じ）と、30秒間の射撃効率 ×0.5（隊形の乱れ）
- 士気の要因別累計に「隊形の乱れ」（`disarray`）を足す。ログに `disarray` のイベントを出す

## 7. 逃げる方位の揺れ止めと、右往左往の原因の調査

- 5秒ごとの見積もりで、新しい最小の方位の損害が、今の方位の損害より 0.05 以上小さいときだけ替える。今の方位の添字を持つ
- **調査**：実装の最初に、P1c の5作戦の通し実行で壊走した中隊の方位の変化を記録し、右往左往（30秒以内に90°以上の向きの入れ替わりを繰り返す）と、再集結に移れない時間の長さを数える
  - 原因の候補：見積もりの同点・僅差による方位の振れ、600m の止まる規則との出入り、川で止まる、追ってくる敵が 400m 以内に残り続ける
  - 揺れ止めの前後で比べて報告する

## パラメータのキー（提案）

新しい区分 `behavior` を `sim_params.json` に足す。50m（動き直し）、30秒（引き直し）、練度の遅れは既存のキーを使う。

```json
"behavior": {
  "attack_side_switch_ratio": 0.8,
  "enemy_min_gap_m": 10,
  "pin_distance_m": 125,
  "pursuit_keep_distance_m": 100,
  "pursuit_limit_m": 600,
  "pursuit_limit_mult": { "cautious": 0, "calm": 1.0, "agile": 1.0, "reckless": 1.5 },
  "pursuit_calm_clear_radius_m": 400,
  "pursuit_replan_sec": 5,
  "turn_front_clear_m": { "cautious": 400, "calm": 400, "agile": 150, "reckless": -1 },
  "turn_front_needs_sight": { "cautious": true, "calm": true, "agile": false, "reckless": false },
  "turn_cancel_quiet_sec": 10,
  "rout_pass_speed_mult": 0.5,
  "rout_pass_morale_hit": 5,
  "disarray_sec": 30,
  "disarray_fire_mult": 0.5,
  "flee_switch_min_gain": 0.05
}
```

- `pursuit_limit_mult` の 0 は「追わない（確保）」
- `turn_front_clear_m` の −1 は「向き直らない」
- 冷静の追撃の条件（400m 以内に指揮下の敵がいない）は `pursuit_calm_clear_radius_m`

## S1〜S6 への影響の見込み

- **向き直り**：検算の配置の中隊は全て冷静・保持
  - S3（正面＋側面）と S4（正面＋背面）の R は、正面の 300m に視線の通る A がいるので、慎重・冷静の条件（正面の弧の 400m 以内に敵がいない）を満たさず、向き直らない
  - S6 も正面に A がいる。S1・S2・S5 は側面・背面から撃たれない
  - よって**向き直りは検算に影響しない見込み**。向き直らない設定に変える必要はないと考える
- **敵の矩形で止まる**：検算は全部隊が保持なので、動くのは壊走した後だけ。最初の壊走で打ち切る検算の値は変わらない
- **退路の見積もりで敵の矩形に掛かる方位をふさぐ**：ふさがるのは敵の方へ向かう方位で、もともと損害の大きい方位。最小の方位と包囲の判定は変わらない見込み。S6 は全方位が 0.2 以上のまま
- **揺れ止め**：壊走した後の動きだけが変わる。検算の値は変わらない
- 60分まで流すログの SHA256（P0.2 から一致させてきたもの）は、壊走した後の逃げ方が変わるので一致しなくなる見込み。最初の壊走までのログが一致することを確かめ、ハッシュの正解値は更新する

## 5作戦の通し実行の見込み

作戦は全て前進の命令なので、追撃・拘束の命令は使われない。効いてくるのは次の点。

- 向き直り：特にステージ1で、頂上の塹壕の R1 の正面（西の斜面）が死角なので、北から側面を突いても、R1 が冷静の条件で北へ向き直りうる。側面攻撃の効果が落ちる見込み
- 敵の矩形で止まる：総員突撃で村の中心を目指す B2 が、村にいる R2 の手前で止まる
- R3 の側の選び直し、壊走のすり抜けと揺れ止め

結果が大きく変わった作戦は、理由を調べて報告する。

## 表示（View）

- 攻撃の命令に「目標が崩れたら：確保／追撃可」。右パネルのボタンと、攻撃を選んでいる間の **C** キー（追撃＝Chase）で切り替える。初期は確保。選んだ値は次の攻撃にも引き継ぐ
- 印（P1c の行動の印と同じ系統）：
  - 追撃中：山形を赤くし、追っている目標への細い破線
  - 向き直り中：駒の脇に回る向きの弧の矢印（待ちの間は点線、旋回中は実線）
  - 隊形の乱れ：駒の枠をぎざぎざの破線にする（30秒）
- 自動一時停止に「攻撃の目標が崩れた」（青の攻撃の目標）

## 判断を仰ぎたい点

1. **確保の向き**：仕様は「目標が逃げた方角とは逆、つまり敵が来る方角を向いて固める」。目標は普通こちらから遠ざかる方へ逃げるので、「逃げた方角の逆」は自分の後ろ（味方の側）になり、「敵が来る方角」と合わない。案：**目標が逃げていった方角（敵の側）を向く**。または、近くに指揮下の敵がいればその方を向き、いなければ逃げた方角を向く
2. **動揺中の拘束**：動揺は前進・攻撃を拒む。拘束で詰める動きも前進にあたるので、案：**動揺中の拘束は詰めずに、その場で目標を向いて撃つ**
3. **前進・後退で着いた後の向き直り**：上の表では対象外にした。止まっている点は保持と同じなので、対象に入れる案もある。案：**対象に入れる**（プレイヤーから見ると、着いた中隊は保持と区別がつかないため）
4. **追撃中に敵が近づいたとき**：冷静の「400m 以内に指揮下の敵がいなければ追う」は、崩れた時点の1回だけの判断にした。追っている間も見続けて、敵が近づいたら止める案もある
5. **向き直りの待ちの取り消し**：「10秒間、側面・背面から撃たれなかったら取り消す」とした。仕様にはない
6. **退路の見積もりのふさがり**：逃げる中隊の矩形と敵の矩形の隙間で判定する（動きの止め方と同じ）。中心の点が敵の矩形に入ったら、という簡単な判定もある
