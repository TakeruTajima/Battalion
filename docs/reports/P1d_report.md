## S1〜S6

壊走までの中央値・p05・p95、各中隊の平均損害率、壊走した数が、6シナリオとも P1c と完全に同じだった（最大の差は v3 の正解値に対して 3.5% のまま）。

- **向き直り**：検算の中隊は全て冷静・保持。S3・S4・S6 の R は正面の 300m に視線の通る A がいるので、向き直りの条件（正面の弧の 400m 以内に敵がいない）を満たさない

- **60分まで流すログ**（P0.2 から一致させてきた `FlatMapLogMatchesP02`）：士気の要因別累計に足した「隊形の乱れ」（`"disarray":0`）の項目を取り除いて比べると、S1・S3・S4・接近戦の4つは **P0.2 と1バイトも違わなかった**（壊走した後の逃げ方・再集結まで含めて同じ）。S6 だけ1か所違う：67.5秒の「包囲された」に出る退路の見積もりの最小値（`escape_loss`）が 0.323 → 0.333。四方を囲まれた R の最も損害の少なかった方位が、青の矩形に詰まる方位として逃げられなくなり、次に少ない方位の値が出ているため。どちらも 0.2 以上なので包囲・降伏は同じで、ほかの行は全て同じ。テストは、この項目を取り除いて比べ、S6 の正解のハッシュをこの値に更新した

### 大きく変わった作戦と理由

試行の経過（シード1）を追って調べた。

1. **ステージ1の総員突撃（勝率 0.05→0.40）：敵と重ならない**
   - P1c では、村の中心を目指す B2・B4 が頂上の塹壕の R1 をすり抜け、通り過ぎた後に背後から撃たれて崩れていた（崩れた青 2.00）
   - P1d では、敵の矩形の手前で止まり、そこで撃ち合う。青の中隊が R1 の周り（北・南・西）で止まるので、R1 は逃げ道がなくなって包囲され、降伏する（降伏した赤 0.05→1.00）。その後、村の R2 も崩れ、村を確保できる試行が増えた（赤が全て崩れた割合 0.20→0.80）
2. **両翼包囲（ステージ1・2）、ステージ1の側面攻撃（2個中隊）：向き直り**
   - 側面に回った青（B1・B3）に撃たれた R1・R2（冷静）が、正面の弧が空いていると向き直る。向き直った後は側面ではなく正面で撃ち合うので、側面攻撃の効き目（損害×1.5、士気×2）が消える
   - ステージ1では、正面の B2 が R1 の目の前の死角（西の斜面）にいて視線が通らないので、R1 の「正面の弧の 400m 以内に見える敵」がいない。側面に来た青へ向き直る（シード1では T+22分に、村の R2 が南から来た B3 の方へ向き直った）
   - ステージ2では、B2 が崩れて正面が空いた後に R1・R2 が向き直る（シード1では T+31分）。赤が全て崩れた割合が 0.90→0.00 になったのはこのため
   - 教訓として、**正面を拘束する（視線の通る所に中隊を置く）と向き直れない**。仕様の「拘束と迂回が報われる」の形が出ている
3. **ステージ2の側面攻撃（2個中隊）（崩れた青 2.00→1.00、崩れた赤 1.00→2.00）：予備隊が挟まる**
   - 予備の R3 は、村から西へ逆襲に出ようとする。しかし、R1・R2 の周り（止まっている味方を避ける 200m）と、北に来た B1・B4 の周り（敵を避ける 110m）で道がふさがれ、R1・R2 の後ろからほとんど動けない（シード1では T+20〜36分）
   - その間に側面を撃たれた R1 が崩れ、R3・R2 をすり抜けて隊形の乱れを与え、赤が連鎖的に崩れる
   - 下の「判断を仰ぎたい点」の2
4. **青の損害率が全体に少し上がった**：向き直りで側面攻撃の効き目が下がったこと（上の2）と、敵の手前で止まって長く撃ち合うこと

## 右往左往の調査（7）

P1b で壊走した中隊が右往左往した件。5作戦×2ステージ×20回で、壊走中の中隊の逃げる方位の変化を数えた。

| | P1c（揺れ止めの前） | P1d |
| --- | --- | --- |
| 壊走の回数 | 550 | 500 |
| 方位の変化 | 2,521 | 114 |
| うち 90° を超える入れ替わり | 422 | 5 |
| うち見積もり損害の差が 0.05 未満の変化 | 2,279（差がちょうど 0 が 1,758） | 16（再集結から壊走に戻ったときは揺れ止めを掛けずに選び直すこと、また差は方位を替えた刻みの後の状態で見積もり直して測っているので、その分の誤差を含む） |
| 壊走から再集結までの時間（中央値・90%点） | 270秒・432秒 | 295秒・390秒 |

**原因**：逃げる方位の見積もり損害が全て 0 の同点になると、P0.2 の同点の規則（600m 以内の敵の平均位置から最も遠ざかる方位）で選ぶ。損害 0 の方位が真西を挟んで 202° と 338° のように並ぶと、中隊が動くにつれて平均位置から見た横の成分の符号が入れ替わり、5秒ごとに選ぶ方位が行ったり来たりしていた（例：ステージ1の総員突撃・シード3の B2 は、37〜38分に 202°↔338° を十数回）。**揺れ止め（0.05 以上小さいときだけ替える）で直った。**

再集結に移れない時間が長い理由は別にある：400m 以内に敵がいる間は再集結の時計が止まる（P0 の規則）。追ってくる敵や、近くで撃ち合いが続く場所に逃げた場合で、規則どおり。

## 変わったこと

### Sim
- **1. 攻撃の側と方角の固定**：`Order.Attack` に「側を指定したか」（`FlankSideLocked`）と「目標が崩れたら」（`OnBreak`）。固定していない側面の攻撃は、着くまで30秒ごとに安い側を選び直す（もう一方が 0.8 倍未満のときだけ）。発起点に着いたら、目標の中心から見た方角を固定し、目標の中心が 50m 以上動いたときだけ同じ方角の 250m の点へ動き直す
- **2. 敵の中隊と重ならない**：向きのある矩形どうしの隙間（`UnitRect`）。動く中隊（指揮下の移動、押し離し、壊走の逃走）は隙間が 10m 未満になる手前で止まる。全く進めなくなったら着いたことにする。経路探索は敵を避ける。退路の見積もりも、敵の矩形に詰まる方位は逃げられない（損害 1.0）
- **3. 拘束**：命令を受けたときの方角の 125m の点まで詰め、30秒ごとに同じ方角で動き直す（50m 以上ずれたら。125m より近ければ動かない）。動揺中は詰めない。拘束は移動を伴う命令になった
- **4. 追撃の許可**：目標が崩れたら、確保（その場で保持。400m 以内に指揮下の敵がいれば最も近い敵の方、いなければ目標が逃げた方角を向く）か、追撃（慎重は確保、冷静は 400m 以内に指揮下の敵がいなければ追い、追っている間に現れたら止まる、機敏は追う、猪突は限界 1.5 倍）。追う間は5秒ごとに目標の 100m 手前へ経路を引き、目標を撃ち続ける。限界・目標の降伏・離脱・再集結で確保に移る
- **5. 向き直り**：保持・陣地構築・攻撃（着いた後）・前進や後退（着いた後）の中隊が、側面・背面から指揮下の敵に撃たれ、正面の弧が空いていれば（慎重・冷静は 400m 以内に視線の通る敵がいない、機敏は 150m 以内に敵がいない、猪突は向き直らない）、練度の遅れの後に撃ってきた敵へ向き直る。10秒撃たれなければ待ちを取り消す。向き直った向きは新しい命令まで保ち、攻撃の目標への強制の射撃もやめる
- **6. すり抜けと隊形の乱れ**：壊走中の中隊は味方と重なっている間 ×0.5 の速さ。すり抜けられた指揮下の味方は、その壊走中の中隊ごとに一度だけ士気 −5（練度の減りやすさを掛ける）と、30秒間の射撃効率 ×0.5。士気の要因別累計に `disarray` を足した
- **7. 揺れ止め**：壊走中の方位は、新しい最小の方位の見積もり損害が今の方位より 0.05 以上小さいときだけ替える
- **ログ**：`target_broken`（判断が追撃か確保か）、`pursuit_end`、`turn_wait`、`turn_start`、`disarray`、`attack_side_change` を足した

### 表示（View）
- 攻撃の「目標が崩れたら：確保／追撃可」：右パネルのボタンと、攻撃を選んでいる間の **C** キー。初期は確保で、選んだ値は次の攻撃にも引き継ぐ。命令の欄に［崩れたら確保］などを出す
- 印：追撃中は赤い山形と目標への細い破線、向き直りは駒の脇の弧（待ちの間は点線、旋回中は矢じり付きの実線）、隊形の乱れは駒の外側のぎざぎざの線（30秒）。左右のパネルの状態にも「向き直り待ち・向き直り中・隊形の乱れ」、命令に「追撃中 → R1（始めた地点から …／600m）」
- ログと浮かぶ文字に「攻撃の目標が崩れた（追撃／確保）」「追撃やめ」「向き直る」「隊形の乱れ」
- 自動一時停止に「攻撃の目標が崩れた」（青の攻撃の目標）
- 攻撃で駒の端をクリックしたら側を固定、中央なら固定しない（着くまで選び直す）

## 実装中に見つけて直した誤り

1. **経路で避ける範囲が狭かった**：仕様の字面どおり「敵の矩形が掛かるマス」だけを避けると、動く中隊（幅 200m の矩形）が敵の脇を回るとき、中心は避けたマスを通っても横幅で敵の角をかすめ、そこで止まって「着いた」ことになった。**避ける範囲を、敵の矩形から「動く中隊の半幅＋隙間」（100＋10＝110m）以内のマスまで広げた**（下の「判断を仰ぎたい点」の1）
2. **攻撃の側を比べるのに、届かない側の経路コストを使っていた**：目的地に届かないときの「届くところまでの経路」のコストは安く見えるので、0.8 倍の揺れ止めを越えて側を替えていた。比べるときは届く経路のコストだけを使う（届かなければ無限大）ようにした
3. **届かない発起点の手前で止まっただけで「着いた」と扱っていた**：その場で方角を固定し、目標から遠い所に居続けた。方角を固定するのは、発起点に 1m 以内まで着いたときか、敵の手前で止められて接しているとき（隙間 11m 未満）だけにし、それ以外は30秒ごとに引き直し続けるようにした
4. **退路の見積もりが重かった**：16方位×277点の全てで矩形どうしの隙間を計算していた。5点おきに調べ、詰まった所から1点ずつ戻って最初の点を探すようにした（結果は変わらない）

## 判断を仰ぎたい点

1. **経路で敵を避ける範囲**（上の1）：仕様は「敵の矩形が掛かるマス」。中隊の幅の分だけ広げた（110m）。このままでよいか
2. **予備隊（R3）が挟まって逆襲に出られないことがある**：ステージ2では、R3 の西へ抜ける道が、R1・R2 の周り（止まっている味方を避ける 200m）と、側面に来た青の周り（敵を避ける 110m）でふさがれ、R3 が R1・R2 の後ろからほとんど動けない試行がある。どちらも確定した規則で、その組み合わせで起きる（側の選び直しが行ったり来たりするのも、塞がり方が刻々と変わるため）。対案は、例えば「味方の陣地の後ろからの出撃に限り、止まっている味方の周りを避ける範囲を狭める（100m）」など。P1e 以降で検討するか
3. **5作戦の結果の変化**（下の「大きく変わった作戦」）：規則どおりの変化と考えるが、遊びとして意図に合うかは確かめてほしい。特に、両翼包囲では向き直りが効いて側面攻撃の効き目が下がる。正面を拘束（または視線の通る所に置く）しないと向き直られる、という教訓が出ている

## 自分で決めた細部

1. **方角を固定する「撃ち始めたら」**を「発起点に着いたら（または敵の手前で止められて接したら）」と読んだ。正面・背面の攻撃も同じく固定する
2. **敵の矩形として数える中隊**：盤上にいる敵（降伏・離脱を除く）。壊走中・再集結中の敵も止まる相手・ふさぐ相手に含む
3. **重なりから抜け出す動き**：隙間がもう 10m 未満のときは、隙間が広がる動き（接していて 0 のままなら、中心が離れる動き）だけを許す。旋回で矩形の角が敵に近づくことは扱わない
4. **押し離し**でも敵に 10m より近づかない
5. **追撃の経路**：5秒ごとに引き直す（`pursuit_replan_sec`）。追撃中は通常の30秒の引き直しをしない
6. **向き直りの待ち**：側面・背面から撃たれた刻みに待ちを始め、正面の弧に敵が現れるか 10秒撃たれなければ取り消す。待ちの後に、最後に側面・背面から撃ってきた敵の今の位置の方へ向き直る
7. **陣地構築で目的地に着いた後の向き直り**：掘る向きを向き直った向きに置き換える（向き直っている間は掘らない。向き終えたら続きを掘る）
8. **すり抜け**：重なりは矩形どうしの分離軸で判定。士気 −5 には練度の減りやすさを掛ける（P0 の判断6と同じ）
9. **確保の向きで、目標が降伏・離脱していたとき**：目標の最後の位置の方を向く
10. **テストの所要時間**：S1〜S6 の検算は P1c より約3割遅くなった（S1 が約2分→約2分40秒）。遅くなった主な分は P1a（地図・視線）からのもので、P1d の追加分は退路のふさがりの判定（上の4で軽くした）

- [ ] 予備隊の逆襲が、目標の向きが変わった後に目標の中をすり抜けない

**敵と重ならない**
- [ ] 前進・攻撃で敵に向かうと、敵の矩形の手前（隙間 10m）で止まり、撃ち合いになる。敵の駒と重ならない
- [ ] 経路が敵を避けて回り込む
- [ ] 壊走した中隊も敵をすり抜けない

**拘束**
- [ ] 拘束（R）で目標から 125m まで詰め、目標に正面を向けて撃つ。回り込まない
- [ ] 目標が動いたら、30秒ごとに同じ方角で詰め直す
- [ ] 動揺中の拘束は詰めずに、その場で撃つ

**追撃の許可**
- [ ] 攻撃を選んで C（または右パネル）で「確保／追撃可」が切り替わる。命令の欄に出る
- [ ] 確保：目標が崩れると止まり、近くの敵か、目標が逃げた方を向いて固める
- [ ] 追撃可：慎重は確保、冷静は近く（400m）に敵がいなければ追う（追っている間に敵が現れたら止まる）、機敏は追う、猪突はさらに遠くまで追う
- [ ] 追撃中は赤い山形と目標への破線が出て、撃ち続ける（損害の数字が出る）。限界（600m）で止まって確保に移る
- [ ] 目標が崩れたとき、自動一時停止で止まる

**向き直り**
- [ ] 保持している中隊を側面・背面から撃つと、正面が空いていれば、練度の遅れ（新兵40秒・通常25秒・古参15秒）の後に撃ってきた方へ向き直る。待ちの間は点線の弧、旋回中は実線の弧の矢印
- [ ] 正面に敵がいると向き直らない（正面を拘束すれば、迂回が報われる）
- [ ] 猪突は向き直らない。拘束の命令中の中隊も向き直らない

**すり抜け**
- [ ] 前線の真後ろに置いた味方を、壊走した中隊がすり抜けると、すり抜けられた味方の枠がぎざぎざになり、「隊形の乱れ」が出る（30秒、射撃が弱くなる）
- [ ] 壊走した中隊が右往左往しない
