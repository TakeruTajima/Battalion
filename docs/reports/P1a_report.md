# P1a 報告：地図のロジック

タグ：`proto-p1a-terrain`

地図の読み込み、地形の効果、視線、経路探索、命令の挙動、重なりの禁止、予備隊の台本を `Sim` アセンブリに足した。設計は [P1a_design.md](P1a_design.md) と、仕様の「P1a の設計で確定した細則」のとおり。パラメータ（`sim_params.json`）、リファレンス実装、地図データは変更していない。

**設計からの追加が1点ある**（下の「判断を仰ぎたい点」の1）。5作戦の通し実行で、止まっている味方の間に挟まって動けなくなる中隊が見つかったため、経路探索が「止まっている味方の周り 200m」を避けるようにした。

### 概算と大きく違う点と、その原因

調べた結果、ずれの原因は次の3つだった。1と2は、仕様で確定した規則の違いがそのまま出たもの。3は概算にない規則（再集結）。どれも P1a の実装の誤りではないと判断した。

1. **止まっている中隊が押されないこと（両翼包囲のステージ1、総員突撃）**
   - 概算は、味方どうしの組を、動いているかどうかに関わらず半分ずつ押し離す。ステージ1の両翼包囲（シード1）では、R3 が逆襲で R2 の脇を通るときに R2 を西へ押し、R2 が R1 を押して、**R1 が頂上の塹壕（x 1800〜1850）から x 1750 の斜面へ押し出されていた**。塹壕の被弾倍率 0.3 を失った R1 はその後、退路なしで降伏している（概算の出力で、T+24〜30分に R1 が 1825→1750、R2 が 2025→1941 に動いている）
   - P1a では止まっている中隊は押されないので、R1 は塹壕に残る。B2 が崩れた後は、射程内で R1 を見通せる青がいない（B4 の (1450, 1200) は R1 から425m。B1・B3 は稜線の東で死角）。R1 は狙われなくなって士気を回復する
   - 総員突撃でも、青の4個中隊が村の付近へ押し合いながら入る形が成り立たない（次の2）
2. **目的地をずらすこと（総員突撃）**
   - 総員突撃では B2 と B4 の目的地が同じ (1975, 1000)、B1・B3 も 150m 離れているだけ。確定した規則では目的地が近すぎる中隊は200m以上離れた点へずらすので、村（200m四方）を目指す中隊は実質1個中隊になる。その中隊が崩れると、村に入る青がいなくなる
   - 概算では押し合いで2個中隊が村に入っていた
3. **再集結（全般）**
   - 概算には再集結がなく、壊走した中隊は戻らない。P1a は P0 の規則どおり、射程外で3分経つと再集結して指揮下に戻る
   - ステージ2の両翼包囲では、90% の試行で赤3個中隊が同時に崩れている（概算の勝ち方）。しかしこの作戦は村に入る命令を出さないので、赤が再集結して戻る90分の時点では勝ちにならない
   - 「崩れた赤」が多くても「終了時」がほぼ 0 なのも、同じ理由

**青の損害率が概算より 1.2〜2倍大きい**のも、主に3の結果。会戦が90分まで続き（概算は勝てばそこで終わる）、戻ってきた赤と撃ち合い続けるため。

### 調査中に見つけて直した実装の誤り（2件）

最初の通し実行では、ステージ1の総員突撃が勝率 0.05、ステージ2の両翼包囲で赤が全て崩れた割合が 0 だった。経過を追うと、中隊が「前進中」のまま何十分も動けなくなっていた。

1. **目的地のずらし先が、止まった味方の円の中に残る**：目的地は命令を受けたときに一度だけずらしていた。動いている味方は「その目的地」を基準にずらすので、その味方が途中で止まると（動揺して保持など）、ずらした先がその味方の200m以内に残る。止まっている味方は押されないので、永久に着けない
   - 直し方：経路を引き直すたび（30秒ごと）に、味方の今の状態で目的地をずらし直す。ずらす先の候補が同じ距離に複数あるときは、中隊の今の位置に近い点（手前の側）を選ぶ（以前は東を先に調べていたので、敵の側へずれていた）
2. **止まっている味方2個中隊の間に挟まる**：経路探索は味方を知らないので、止まっている味方の間（例：R1 と R2 の間は250m）を通る経路を引く。押し離しで止まっている側は動かないので、間に入った中隊は前後から押し戻され続けて動けない（ステージ2で、逆襲に出た R3 が R1・R2 の間で20分以上止まっていた）
   - 直し方：経路探索で、止まっている指揮下の味方の中心から200m未満のマスに入らない。避けると届かない場合は、避けずに引き直す。**これは仕様の経路のコストにない規則なので、判断を仰ぎたい（下の1）**

### 概算との違いで、結果がずれうる点（一覧）

- 止まっている中隊は押されない（概算は常に半分ずつ）。上の1
- 目的地が近すぎる場合はずらす（概算はずらさず、押し合いで解決）。上の2
- 経路が止まっている味方の周りを避ける（概算にはない。判断を仰ぎたい点の1）
- 再集結がある（概算はなし）。上の3
- 勝ちの判定で、壊走中の赤は盤上にいる扱い（概算は崩れた時点で勝ち）
- 旋回に時間がかかる（毎秒6°。概算は即座に向く）。各区間の向きへ旋回してから進む
- 射撃の目標の視線を毎刻み判定する（概算は2秒ごとにまとめて判定）
- 陣地構築がある（5作戦では使わない）
- 拘束中の移動×0.5は、150m以内から狙われているときだけ（概算は150m以内に敵がいれば）

### テスト

- **地図とリファレンス**：行の並び（北が先）、視線 L1〜L10、露出のマス数、経路の検証ケース12件、一直線の点の間引き、川は橋と浅瀬でだけ渡る
- **後退の向き**：背後の弧なら向きを変えずに×0.6で下がる。側面の向きなら旋回して前進と同じ速さで進む
- **陣地構築**：10分で完成し、向きに直交する5マスが塹壕になる。途中は被弾倍率が進捗に比例する。動くと進捗を失う。塹壕は止まっているときだけ 0.3。平地と砲撃痕だけが塹壕になり、村は変えない
- **重なりの禁止**：目的地をずらす。動いている中隊だけが押され、止まっている中隊は押されない。2個中隊がすれ違うと半分ずつ押される。止まっている味方の間（250m）は通らずに回る。初期配置は200m以上
- **攻撃**：発起点の位置。指定なしなら正面、機敏は安い側面を選ぶ。発起点に着いて敵に正面を向ける。動揺中は攻撃を拒む
- **拘束**：目標に正面を向け、近い敵がいても目標を撃つ
- **視線と地形**：稜線の向こうの敵は撃てない。村・森・塹壕の被弾倍率と籠城。森の中は秒速 0.6m
- **退路の見積もり**：川に突き当たる方位は 1.0。地図の外へ出る方位は出るまでで打ち切る（手計算と一致）。死角の斜面では見積もりが小さい。壊走中に川に突き当たると止まる
- **予備隊の台本**：引き金の円に入るまで動かない。入ったら最も近い青の、R3 の側の側面へ攻撃。脅威の重みは 0。R1・R2 は保持のまま
- **S1〜S6**：v3 の正解値との照合（従来どおり）と、P0.2 とのログの一致

## P1a で判断した箇所

1. **P1 の数値の置き場所**：露出の地図の間隔（10秒）、経路の引き直し（30秒）、発起点の距離（250m）、機敏の1.5倍、陣地構築（10分、0.3、左右2マス）、性格ごとの脅威の重みなどを `MapRules.cs` の定数にした。仕様の方針では JSON に外出しするが、`sim_params.json` は `sim_params.initial.json` とバイト単位で同一に保つ決まりで、その初期値は仕様側が持つため。キーを決めてもらえれば移す
2. **攻撃の目標が崩れたら**：目標が指揮下でなくなったら（壊走・再集結・降伏・離脱）、攻撃をやめてその場で保持する（追撃は性格の解釈で、P2 以降）
3. **攻撃で着いた後**：30秒ごとに発起点を計算し直し、今の位置から50mより離れたらまた動く
4. **撃つ目標**：拘束の命令中と、攻撃で発起点に着いた後は、命令の目標が射程内で見えていればその敵を撃つ。それ以外は P0 の目標選択（視線が通る敵だけ）
5. **目的地のずらし方**：引き直しのたびにずらし直す。同じ距離の候補は今の位置に近い点を選ぶ（上の「直した誤り」の1）
6. **後退の向きの判定**：命令を受けたときと、経路を引き直すときに、目的地が背後の弧にあるかで決める。後ろ向きのときは、経路の曲がり角でも向きを変えない
7. **届かない目的地**：経路がなければその場で止まる。目的地が川などの通れない場所なら、目的地のずらし方と同じ方法で通れる点へずらす
8. **露出の地図・退路の見積もりに数える敵**：指揮下（正常・動揺）の中隊だけ。壊走中・再集結中の中隊は撃たないため。リファレンスの検証ケースは初期配置の赤3個中隊（全て指揮下）なので一致する
9. **見える範囲の作り直し**：10秒ごとに指揮下の中隊全てについて作る。その間に指揮下へ戻った中隊は、必要になったときにその場で作る。退路の見積もりのために、半径は射程 400m にマスの半対角（約35m）を足した範囲まで作る（点が 400m 以内でも、そのマスの中心が 400m を少し超えることがあるため）
10. **籠城と地形の被弾倍率**：籠城は中心のマスが村か塹壕かで決め、動いているかは問わない。被弾倍率の塹壕 0.3 は止まっているときだけ
11. **通れないマスにいる中隊の速さ**：押し離しでは通れないマスへは押さないが、念のため川のマスにいる場合は浅瀬の速さ（×0.3）で動けるようにした
12. **経路の最後の点**：目的地のマスの中心ではなく、目的地そのもの
13. **追撃の射撃**：壊走中の敵を撃つときも視線が要る
14. **ログ**：`attack_plan`（攻撃の方向・側・発起点）、`entrench_complete`、`reserve_counterattack` を足した。`unit_snapshot` は変えていない（S1〜S6 のログを P0.2 と一致させるため）
15. **通し実行の打ち切り**：赤か青が全て盤上から消えたら打ち切る

## 判断を仰ぎたい点

1. **経路探索で、止まっている味方の周り（中心から200m未満）を避けること**：仕様の経路のコストにない規則。これがないと、止まっている味方は押されない規則と組み合わさって、2個中隊の間に挟まった中隊が動けなくなる。代わりの案は「挟まって動けなくなったときだけ、止まっている側も押す」など。このままでよいか
2. **5作戦の結果をどう読むか**：概算との差の大半は、確定した規則（止まっている中隊は押されない、目的地をずらす、再集結）の違い。特に「総員突撃」と「両翼包囲」の勝ちは、概算では押し離しと崩れた中隊が戻らないことに支えられていた。P1b で実際に触る前に、作戦の命令（村に入る中隊を決めるなど）や勝ちの判定を見直すかどうか
3. **再集結と勝ちの判定**：赤が全て崩れても、村に入っていなければ、赤が再集結して戻る。崩れた敵を追い払った後に村を取りに行くのはプレイヤーの仕事、と読めば今のままでよい
