タグ：`proto-p1c-feedback`

## 変わったこと

### 1. 射撃の見える化
- **射撃線**：直前の刻みに撃った組だけ。射手の正面の縁の中央から目標の中心へ。色は撃たれる側から見た向き（正面＝白、側面＝橙、背面＝赤）、太さは損害の期待値（毎分）。線の上を目標へ向かって破線が流れる（現実の時間で毎秒70画素。倍速を上げても速さは変わらない）
- **発砲の明滅**：撃った中隊の正面の辺に沿って、兵力÷15 個（1〜10）の明るい点をちらつかせる

### 2. 損害と士気の見える化
- **損害の数字**：中隊ごとに現実の1.5秒ぶんの損害をまとめて「−4」と浮かべて消す。主な向き（損害が最も多い向き）が側面・背面なら橙・赤にし、「側面」「背面」を添える
- **被弾の明滅**：撃たれた駒の枠の外を光らせる。正面からは細く白、側面・背面からは太く橙・赤
- **駒のバー**：駒のすぐ下に兵力（灰）と士気（緑・黄・赤。動揺と壊走の閾値で色が変わる）。士気が減ると、減った分を薄い赤で1.2秒残してから縮める
- **大きな出来事**：駒の上に大きめの文字で2.8秒。初めて側面・背面を撃たれた、包囲された（包囲の間は駒を囲む赤い輪が脈打つ）、壊走、降伏（白旗の図形が残る）、再集結の開始と復帰、予備隊の逆襲、陣地の完成

### 3. 行動の見える化（形で示す）

| 行動 | 印 |
| --- | --- |
| 移動中 | 進む向きに二重の山形（後ろ向きに下がるときは後ろへ） |
| 射撃中 | 発砲の明滅（印は付けない） |
| 保持（止まっている） | 駒の右に短い横棒 |
| 拘束（命令） | 目標へ向けた杭（T 字） |
| 拘束されている（150m 以内から撃たれている） | 駒を囲む細い点線の輪 |
| 陣地構築 | 正面の辺に沿って、進捗に比例して伸びる斜線の帯 |
| 籠城（塹壕・村の中） | 二重枠 |

### 4. 勝利条件の見える化
- **村の旗**：村の中心に旗。青が確保＝青、赤が確保＝橙、争奪中＝青と橙の縞、空き＝白。旗の下に「村：青が確保」などの文字。中心から250mの円を薄く描く
- **上部バーの2段目**：「勝利条件　村に青の中隊：○／×　250m以内の赤：○／×　→ 今終われば：勝ち／負け（村：…）」。判定は `MapScenario.BlueWins` と同じ（赤が全て盤上から消えた場合を含む）。1段目に90分までの残り時間

### 5. 時間
- 倍速を ×1／×2／×4／×8／×16 にした。**Z で遅く、X で速く**（上部バーのボタンでも選べる）。P1b の F1〜F3 はやめた
- ×16 は現実の1秒でゲーム内64秒＝128刻み。60fps なら1フレーム約2刻みで、上限の16刻みに当たるのは 8fps 程度まで落ちたときだけ。5作戦の通し実行は毎秒数千刻みで回るので、Sim の重さは問題にならない。**上限は見直さなかった**（テストで確認）
- **自動一時停止**（P で切り替え、初期は入）：味方が初めて側面・背面を撃たれた、誰か（敵味方とも）が包囲された、味方が壊走・降伏した、予備隊が逆襲に出た、村の目標の状態が変わった、で止まり、上部バーに「一時停止：T+23:41 B3 側面を突かれた／村：争奪中」のように出す。再開すると消える

### 6. 陣地構築の目的地
- Sim：`Order.Entrench(id, 目的地, 向き)`。目的地があれば前進と同じ経路で移動し、着いて向きを変え終えたら掘り始める（移動中と旋回中は進捗が増えない）。目的地がなければ今と同じ
- 動揺：移動中に動揺したら保持になる（掘り始めない）。動揺中に目的地のある陣地構築を出すと、前進と同じく保持になる（その場で掘る命令は受け付ける）
- 入力：**Y → 地図をクリックで掘る地点**（押したままドラッグで向き）。**その場で掘るなら、もう一度 Y を押すか、選んだ中隊の駒をクリック**
- 選んだ中隊の目的地に、着いた後の正面の辺に沿う斜線の帯（陣地構築の印と同じ形）を出す

### 7. 小さな直し
- `_note_moving_open` の注記に塹壕を足した（`sim_params.initial.json` と `Assets/StreamingAssets/sim_params.json`）

## 自分で決めた見た目と、迷った点

1. **地図の上の文字は世界座標の文字（TextMesh）で描いた**：損害の数字・出来事・村の状態。IMGUI だとバッチモードの画像に写らず、完了基準の確認ができないため。日本語は OS のフォント（Yu Gothic UI か Meiryo）。駒の名前・兵力・士気の文字は P1b のまま IMGUI
2. **射撃線の強弱**：中隊を選んでいるときは、その中隊が撃つ・撃たれる線を不透明に近く、それ以外を半透明に。選んでいなければ全て強く。線は薄い下地＋流れる破線の二重
3. **太さ**：1＋0.9×損害の期待値（毎分）画素、1〜8画素。正面の 300m で約3画素、接近戦や側面・背面で太くなる
4. **損害の数字のまとめ方**：中隊ごとに、最初の損害から現実の1.5秒でまとめる（倍速が上がるほど、1つの数字に入る時間は長くなる）。表示は1.6秒で上へ流れて消える
5. **士気の残像**：減ってから1.2秒止めて、毎秒12ずつ縮める
6. **行動の印**：射撃中は発砲の明滅だけ。保持の横棒は、保持の命令と、前進・後退で着いた後に出す。攻撃で発起点に着いた後は印なし（撃っていれば明滅で分かる）
7. **自動一時停止の「包囲された」**：依頼文どおり敵味方とも止める。「村の目標の状態が変わった」は4つの状態のどれへの変化でも止める（争奪中への変化を含む）
8. **自動一時停止の直後**：止めたフレームの残りの刻みは進めず、補間の起点を今の刻みにそろえて、止めた状態がそのまま見えるようにした
9. **目的地のある陣地構築と動揺**：依頼文は「移動中に動揺したら保持」。命令を出した時点ですでに動揺していた場合も、移動を伴うので前進と同じく保持にした（その場で掘る命令は動揺中でも受け付ける。P1b と同じ）
10. **射撃の記録の士気の値**：その射撃の損害による士気の減り（練度の減りやすさを掛ける前）。今の表示では使っていない（P5 の戦闘詳報で使える）
11. **見た目の乱数**：発砲の明滅の位置とちらつきは、表示側の `System.Random`（固定のシード）。Sim の乱数には触らない
