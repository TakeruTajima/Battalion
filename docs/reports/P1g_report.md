## 変わったこと

### Sim（`SimulationSight.cs` と、攻撃・拘束・射撃の接続）
- **攻撃**
  - 発起点に着いて方角を固定したとき、命令の目標と交戦できなければ（射程外か、視線が通らない）、固定した方角に沿って目標へ詰める
  - 今の距離から 10m 刻みで近づけて調べ、目標が見えて射程内になる最初の点へ動く。敵の矩形と隙間 10m が取れなくなるまでに見つからなければ、その手前の点まで詰める（接触の規則に任せる）
  - 着いた後も30秒ごとに調べ、交戦できなくなっていれば（目標が動いた等）また詰める
  - 向き直った（P1d の5）中隊は探さない（向き直った向きの敵と撃ち合っているため）
- **拘束**
  - 拘束点に着いた後、30秒ごとに調べる。交戦できなければ、目標からの今の距離を保ったまま、今の方角の左右 ±45°（5° 刻み、近い方から）で見える位置を探して移る
  - なければ今の方角に沿って詰め、見えて射程内になる最初の点へ。近い拘束の 125m より近くへは詰めず、それでも見えなければ 125m の点で止まる
  - 移った方角と距離はその後の拘束点になる（30秒ごとの詰め直しで元の点に戻らない）
  - 動揺中は探さない（「動揺中は詰めない」と同じ）
- **保持・陣地構築・前進・後退**：見えない敵には何もしない
- **接触中は視線を問わない**：互いの矩形の隙間が 50m 以内なら、視線の判定をせずに撃ち合える（目標の選択と、命令の目標の強制の射撃の両方）
- **ログ**：`seek_sight`（`how` は `advance`＝詰める、`side`＝横へ移る、と行き先）

### 表示（View）
- 下部の出来事の欄：「B2：目標 R1 が見えないため前進」「…見えないため見える位置へ移る」
- 駒の上の文字：「見える位置へ」。自動一時停止には足していない
- 印：見える位置を探して動いている間、進む向きの山形の先に**目の印**（白い横長の輪と黒目）
- 状態の欄：「見える位置を探して移動」
- P1f の「撃たない理由」の点線は、接触中（撃てる）の組には出さない

### パラメータ（提案。仮に `Assets/StreamingAssets/sim_params.json` の `behavior` に足した）

| キー | 値 | 意味 |
| --- | --- | --- |
| `sight_contact_gap_m` | 50 | 互いの矩形の隙間がこれ以内なら、視線を問わずに撃ち合える |
| `sight_seek_side_deg` | 45 | 拘束で見える位置を探す、今の方角の左右の範囲 |
| `sight_seek_side_step_deg` | 5 | その刻み |
| `sight_seek_step_m` | 10 | 見える位置を探して目標へ詰めるときに調べる距離の刻み（視線の刻みと同じ） |

`docs/reference/sim_params.initial.json` への反映をお願いしたい。反映されれば、同一性のテストは通る。

### テスト（`P1gSightTests`、6件）
- ステージ1で、R1 を正面から攻撃した中隊が、死角の発起点（R1 の 250m 西）に着くと、真西に沿って詰め、見えた所で R1 を撃ち始める（ログに `seek_sight`）
- 拘束の中隊が、森で見えない拘束点から、距離を保って横の見える位置へ移り、目標を撃つ
- 横のどこからも見えない（南北に長い森の壁）ときは、今の方角に沿って詰める（125m より近くへは詰めない）
- 隙間 50m では視線が通らなくても撃ち合い、70m では撃たない
- 保持の中隊は、死角の敵がいても動かない

### 大きく変わった作戦と理由（シード1で確認）

1. **ステージ1の「拘束＋迂回（近い拘束）」（勝率 0.00→1.00）：予備の R3 が死角の拘束役へ詰めて崩れる**
   - 見える位置を探して動いたのは、青ではなく予備の R3（台本の逆襲。側面の範囲で攻撃）だった
   - R3 の逆襲の目標は、R1 の目の前の死角（125m）にいる拘束役の B2。R3 の発起点から B2 が見えないので、R3 は方角に沿って B2 へ詰め（26分〜）、至近距離の撃ち合いになる
   - その間に B1・B4 に側面・背面を撃たれ、R3 が 45分に崩れる。R1（37分）、R2（61分）も崩れ、村が空く
   - P1f までは、R3 は死角の発起点で黙って立っていた
2. **ステージ1の「拘束＋迂回（遠い拘束）」（青の損害 0.186→0.252、崩れた青 1.50→2.50）：R3 が迂回の B1 へ詰める**
   - R3 の逆襲の目標は北から回った B1。R3 は B1 が見えるまで詰め、B1 の側面を撃って崩す（シード1では 39分。全20回で B1 が崩れた）
   - 同じ規則が、青に不利に働いた例
3. **ステージ1の総員突撃（0.90→0.95、崩れた青 0.25→0.05）**：攻撃・拘束の命令はないので探す動きは出ない。変わったのは、隙間 50m 以内なら視線を問わずに撃ち合える規則の分（R1 の脇で止まった青と R1 が、稜線の肩を挟んでも撃ち合う）
4. **ステージ2の「拘束＋迂回（近い拘束）」（0.95→0.75）**：同じく R3 の逆襲が、見えない目標へ詰めるようになった分。試行ごとの経過は追っていない
5. 5作戦のほかの作戦は変わらない（攻撃・拘束の命令がなく、接触の距離で稜線を挟む場面もない）

## 迷った点と、自分で決めた点

1. **接近戦の倍率の基準**：仕様は「隙間 50m 以内なら視線を問わずに撃ち合える（接近戦の倍率が掛かる）」。今の接近戦の倍率（×2.0）は、中心どうしの距離 50m 以内で掛かる（P0 からの規則）。隙間 50m の向かい合った中隊は中心どうし約 100m なので、基準が違う。**今回は「視線を問わない」だけを入れ、倍率の規則は変えていない**（S1〜S6 と接近戦の検算を動かさないため）。倍率も隙間で測るように変えるかは、仕様側で決めてほしい
2. **「見える」の判定**：中隊の中心どうしの視線（Sim の射撃と同じ）。射程は 400m
3. **攻撃で詰める点を探す刻み**：10m（視線の刻みと同じ。キーは `sight_seek_step_m`）。向きは目標の方を向いたまま詰める前提で、敵の矩形との隙間を見る
4. **拘束の左右の探索**：5° 刻みで、近い方（今の方角に近い方）から左右交互に調べる。同じ近さでは左（反時計回り）が先
5. **見えないまま 125m で止まった拘束**：その後も30秒ごとに左右を探す（横に見える所が開けば移る）
6. **向き直った攻撃の中隊は探さない**：向き直った向きの敵と撃ち合っていて、命令の目標から目を離している状態のため
7. **予備隊の台本の逆襲も、攻撃なので同じ規則で探す**（上の1・2の変化はこのため）
