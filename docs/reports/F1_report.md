## 3. 実装したもの

**Sim**
- 隊形の状態（`Company.Formation`：横隊・縦隊、`FormationChange`：展開中・縮合中と経過の秒数、縮合の条件が続いた秒数）。中隊長の判断は `SimulationFormation.cs` の `UpdateFormation`（刻みの終わり、守りの判断の後）。
- 縦隊の矩形：正面 50m×奥行き 200m（向きの方向に長い）。中隊の矩形を使う所（敵との隙間・接触・接近戦・押し離し・超越・露出の地図の接触の距離）は全て隊形の形になる（`RectOf`）。
- 倍率：
  - 縦隊は撃つ力 ×0.2・被弾 ×1.5・速さ ×1.25。旋回はいつも毎秒 6°（線を張った接敵中の遅い旋回を掛けない）。

- 壊走・再集結中は横隊（隊形を持たない）。
- 地図ファイルの配置の `formation`（`line`／`column`。書かなければ横隊）。
- パラメータ `formation` の節を `sim_params.json` と `docs/reference/sim_params.initial.json` に同じ値で足した：

## 5. 迷った点と、自分で決めた点

1. **縦隊の矩形と押し離し・超越**：中隊の矩形は全て隊形の形（`RectOf`）。味方の間隔（中心どうし 200m）は変えない。押し離し・超越は矩形の重なりで判定するので、縦隊どうしは横に並びやすい。仮の点に置いた矩形（物陰の候補・退路の見積もり・守りの計画の位置の検査）は、今までどおり横隊の形で見る。
2. **展開の終わりの向き**：上の 3 のとおり。展開の終わりに一度で向きを決める（旋回しない）。
3. **縮合の「60秒」**：仕様の「撃たれていない状態が 60秒続いた」を、縮合の条件全て（移動の命令で、残りの経路 400m 以上、展開の距離以内に気付いている指揮下の敵がいない、撃たれていない、接敵していない、伏せていない）が 60秒続いたとき、と読んだ。揺れ止めの 60秒も同じ数えにした。
4. **後退**：仕様の「縮合する」の条件に後退が入っているので、後退でも縮合の条件を満たせば縮合する。「接敵中に縦隊で下がることはしない」は、接敵中は縮合の条件を満たさないことで守られる。
5. **縮合の途中で敵に気付いた・撃たれた**：仕様にないので、縮合をやめて横隊のまま（矩形はまだ横隊なので、すぐ戻る）とした。
6. **展開の途中の撃つ力と被弾**：撃つ力は ×0.3（縦隊の ×0.2 の代わり。重ねない）。被弾は、矩形がまだ縦隊なので ×1.5 も掛け、さらに動いている扱いの ×3.0 も掛ける（開けた所で 4.5倍）。
7. **展開の途中に命令の続き（攻撃の目標が崩れた等）は進まない**：移り変わる間は `MoveUnderCommand` を呼ばないので、攻撃・拘束の引き直しや、目標が崩れた時の判断は展開を終えてから。
8. **中隊の詳しい表示に出す知っていること**：F1 では足していない（P2d の範囲）。

### 迷った点と、自分で決めた点（追記）

1. **移り変わる間の速さ ×0.5 は、縦隊の ×1.25 の代わり**（重ねない）。
2. **展開の距離（性格）は残した**：仕様の 3 は縮合の条件を変え、展開の条件（気付いている敵が展開の距離以内）はそのまま。縦隊のうちに、展開の距離より遠い敵に気付いても、展開しない（縮合の途中ならやめる）。
3. **`deploy_sec` は 120**：掃き出しで今の案（90）に一番近く満たす組。

### 仕様側で見てほしいこと（追記）

1. **会戦の始めの縮合**：シナリオA では、始めに赤が見えないので青が全て縦隊になる。初めの敵情（P2d の `initial_intel`）があっても、中隊長の判断は気付いている敵（視線）で決まるので変わらない。始めから横隊で行かせたいなら、地図の配置の `formation` か、縮合の条件に「本部が知っている敵」を入れる、などになる。
2. **敵が見えなくなった後の縮合**：揺れ止めの 60秒の後、また縦隊になる。前線の近くで縦隊に戻ることは仕様の「読み」に反する。例えば、一度展開したら同じ命令の間は縮合しない、など。
3. **拘束＋迂回（ステージ2）は 0.60 でちょうど線**。
