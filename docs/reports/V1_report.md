## 記録の形（`BattleRecord.ToJson()`。V2 がそのまま読む）

時刻は全て秒（会戦の初めからの経過）。数は小数第6位まで（Unity と .NET で同じ文字）。

| 項目 | 型 | 中身 |
| --- | --- | --- |
| `scenario` | 文字列 | 地図の名前（`scenario_a1`・`scenario_a2`） |
| `stage` | 整数 | ステージ（1・2） |
| `plan` | 文字列か null | 作戦の名前（通し実行が付ける。付けなければ null） |
| `seed` | 整数 | 乱数の種 |
| `end_sec` | 数 | 会戦の終わりの時刻（90分なら 5400。どちらかが全て盤上から消えればその時） |
| `objectives.primary` | 真偽 | 青の第一目標（村の奪取）。終わりの時点 |
| `objectives.secondary` | 真偽 | 青の第二目標（塹壕の敵の排除）。終わりの時点 |
| `objectives.red_holds` | 真偽 | 赤の目標（村の死守）。`primary` の裏 |
| `objectives.first_primary_sec` | 数か null | 初めて第一目標の条件を満たした時刻（村を取った時刻）。満たさなければ null |
| `objectives.trench_units` | 文字列の配列 | 塹壕に配置した赤の中隊（`["R1"]`・`["R1","R2"]`） |
| `losses.blue.initial`・`losses.blue.lost` | 整数 | 青の初めの兵力の合計と、失った兵の合計 |
| `losses.red.initial`・`losses.red.lost` | 整数 | 赤の同じもの |
| `companies[]` | 配列 | 全ての中隊（青・赤） |
| `companies[].name`・`side` | 文字列 | 中隊の名前（`B1` など）と陣営（`blue`・`red`） |
| `companies[].initial_strength`・`final_strength` | 整数 | 初めと終わりの兵力 |
| `companies[].final_state` | 文字列 | 終わりの状態（`normal`・`shaken`・`routed`・`rallying`・`surrendered`・`left_battle`） |
| `companies[].rout_sec` | 数の配列 | 指揮下から壊走した時刻（再集結して戻り、また壊走すれば複数） |
| `companies[].surrender_sec`・`left_battle_sec` | 数か null | 降伏した時刻、盤上から離脱した時刻 |
| `fire_pairs[]` | 配列 | 撃ち合った組（射手→目標ごと。青→赤も赤→青も） |
| `fire_pairs[].shooter`・`target`・`shooter_side` | 文字列 | 射手、目標、射手の陣営 |
| `fire_pairs[].first_sec`・`last_sec` | 数 | その組で最初と最後に撃った刻みの時刻（間に撃たなかった時間を含む） |
| `fire_pairs[].ticks` | 整数 | 撃った刻みの数（1刻み 0.5秒。×0.5 で撃った秒数） |
| `fire_pairs[].casualties` | 整数 | その組で倒した兵の数 |
| `paths` | オブジェクト | 青の各中隊の通り道（中隊の名前ごと） |
| `paths.B1[]` | 配列の配列 | `[秒, x, y, 状態]`。30秒ごと（0秒を含む）。盤上にいる間だけ |

### 表から読めること

1. **ステージ2 は、塹壕を素通りして村を取る勝ち方ばかり**。第二目標（塹壕の R1・R2 の排除）は、近い拘束（任せる 0.20・厳命 0.15）を除いて全て 0。「村への前進（全中隊）」だけで第一目標が 0.95 取れる。仕様の課題にある「弱い守りが素通りで破れる」形が数字で出た。V2 の問い1（抜け道）の手がかり

### 読み3 の確かめ（ステージ1「村への前進（全中隊）」の任せる・厳命）

ステージ1 の村への前進を、任せる・厳命それぞれシード 1〜20 で回した（各90分、合わせて 40回、33秒）。.NET の一時的なテストで記録の JSON と自律・独断の出来事を書き出して見た（テストはコミットしていない）。勝ち負けは通し実行の表と全て同じ（任せる 16/20、厳命 7/20、第二目標 17/20 と 14/20）。

**効いているのは、慎重な B1 の独断の後退（物陰へ）**。任せる版では 17/20 回、B1 が 27〜28分（塹壕の R1 の手前約 150m で撃たれ始めた直後）に、村の中心から約 270m の物陰まで下がる。ほかの独断は、機敏の B4 の回り込みが1回だけ。厳命版では B1 は下がれず、動揺して前進を止め、R1 の手前（村の中心から約 150m）にとどまる。

厳命版の負け 13回は、2つの形に分かれる。

**イの仕組み（シード 10 で1分ごとに見た）**
- 4個中隊に同じ点（村の中心）への前進を命じるので、行き先が味方どうしの最小間隔（`friendly_min_spacing_m` 200m）でずらされる。中心は最初に命じた B1 が取り、ほかは中心から 150〜200m の点になる
- 村のマスは中心のまわり 200m 四方（50m のマスで 4×4）しかない。間隔 200m では、村の中に入れる青は1個中隊だけで、中心から 150〜200m の点は村の外になる
- 厳命版：B1 が 28分に中心から 152m で止まる。止まった中隊は今いる位置で間隔を取るので、中心は B1 から 200m 以内になりふさがる。B4 の行き先は 150m の点に直される（29分）。B1 が 46分に立ち直って前進を再開しても、今度は B4 の行き先（150m）が中心をふさぐ。B1 も 150m の点へ行き、誰も村に入らない
- 任せる版：B1 が 28分に物陰（中心から 270m）へ下がるので、中心が空く。B4 の行き先が 30分に中心へ直され、43分に村へ入る

**見当**：差の 9回のうち、ア（4回）は「慎重な B1 が危ないところから早めに下がったので崩れずに済んだ」で、独断が戦いとして効いた形。イ（6回）は、B1 が下がったことで村の中の1つしかない場所が空いた、という行き先のずらし方による副作用。独断そのものの良さより、こちらのほうが大きい。

これは「全中隊に同じ点へ前進」という作戦の形と、間隔 200m・小さな村の組み合わせで起きる。値は変えていない（直すかどうか、たとえば止まった中隊が行き先の間隔をどう取るかは、仕様の判断）。V2 で作戦を自動で探すとき、同じ点へ複数の中隊を送る作戦は、この副作用で評価がぶれることに気をつける。

## 迷った点と、自分で決めた点

1. **塹壕に配置した中隊の決め方**：ステージごとの一覧を `MapScenario` に書いた（地図の地形から自動で決める案もあるが、意図をはっきりさせるため）。テストで、一覧の中隊が塹壕のマスにいることを確かめる
2. **第二目標の「指揮下にない」**：壊走中・再集結中・降伏・盤上から離脱、を全て「排除した」に数える。90分の時点で再集結を終えて指揮下に戻っていれば、排除していない
3. **村を取った時刻**：初めて第一目標の条件（`BlueWins`。村に指揮下の青、250m 以内に指揮下の赤なし、または赤が全て盤上から消えた）を満たした刻み。その後に奪い返されても、最初の時刻を残す。会戦の初め（刻みを進める前）は数えない
4. **撃ち合った組**：射手→目標の向きごとに1組（青→赤も赤→青も）。最初と最後の時刻の間に撃たなかった時間があっても1組。間の途切れが要るなら、V2 で必要になってから足す
5. **通り道**：青の中隊だけ、30秒ごと（0秒を含む）、盤上にいる間。状態（壊走中など）を添える
6. **記録の書き出し**：通し実行の2つの表だけ、環境変数を決めたときに書き出す。V2 は `BattleRecorder` を直接使う想定
7. **終わりの画面**：勝ち負けの見出しは今どおり残し、その下に目標ごとの達成を足した（見出しを目標だけにする案もある。遊びの手触りを見て決めてほしい）
8. **ログ**：記録はログに出さない（読み取りの口だけ）。会戦のログのハッシュは変わらない
