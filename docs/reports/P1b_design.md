### Sim の状態の読み方と補間

- Sim は今までどおり `Simulation.Companies` を公開している。View はこれを**読むだけ**にし、書き換えない（命令は `Issue` で渡す）
- **補間**：毎回 `Step()` を呼ぶ直前に、各中隊の位置と向きを控えておく（直前の刻み）。描くときは「直前の刻み」と「今の刻み」の間を、たまった時間の割合で補間する。向きは角度の差を (−180°, 180°] に丸めてから補間する
- **出来事のログ**：Sim のイベントログ（JSON Lines）を受け取る `IEventSink` を View 側に作り、`rout`・`surrender`・`encircled_start`・`rally`・`reserve_counterattack`・`entrench_complete` などを拾って下部のログに出す。Sim の変更は要らない
- **会戦の終わり**：`MapScenario.BlueWins` と、各中隊の状態・兵力から数字を出す（Sim の変更は要らない）

### 時間の進め方

- 1フレームごとに、現実の経過秒×4×倍速をためる。たまった分が 0.5 秒（1刻み）を超えるたびに `Step()` を呼ぶ。1フレームに最大16刻みまでで、それ以上たまった分は捨てる（フレームが重いときに遅れを取り戻そうとして、さらに重くならないように）
- ×4 は毎秒32刻み。60fps なら1フレームあたり約0.5刻みなので、16刻みの上限に当たるのはフレームがひどく落ちたときだけ
- 一時停止中は時間をためない。命令は一時停止中も出せて、次の刻みの最初に適用される（P1 では即時）
- 一時停止中は補間を止め、最後の刻みの状態を描く

## 2. 描画の方法

正射影の2Dカメラ。世界座標は Sim と同じメートル（x が東、y が北）。地図は 3000×2000m。

| 描くもの | 方法 |
| --- | --- |
| 地形の色分け | テクスチャ1枚（1マス 10px、600×400px）。マスごとに地形の色で塗る（色は見本の画像に合わせる：平地は薄い黄緑、森は濃い緑、村は灰茶、川は青、橋は濃い灰、浅瀬は薄い青、塹壕は茶） |
| 等高線 | 同じテクスチャに描き込む。各画素の標高を `TerrainMap.ElevationInterp` で出し、隣の画素と5m の区切りをまたぐ画素を暗くする。標高の値は Sim と同じものを使う |
| 会戦中に変わる地形 | 陣地構築で塹壕ができたら（`entrench_complete` を受けたら）、そのマスだけテクスチャを塗り直す |
| 重ねる表示 | 60×40px の半透明のテクスチャを地形の上に重ねる（視線確認、露出の地図）。切り替えるたびに作り直す |
| 駒・経路・円 | 毎フレーム作り直す動的なメッシュ1つ（頂点色、Sprites/Default のマテリアル）。駒は 200m×50m の実寸の矩形（味方は青、敵は橙）と×印、向きの矢印。経路は折れ線、目的地は小さな四角、引き金の円や退路の見積もりの矢印も同じメッシュに描く |
| 駒の文字 | 兵力・士気・状態の略号（正常・動揺・壊走・再集結・降伏）は、画面の UI として駒の位置に重ねる（下の UI と同じ仕組み） |

- 状態は色の濃さでも示す（動揺は薄く、壊走・再集結は点線の枠、降伏は灰色で×）。文字と色の両方で読めるようにする
- カメラ：矢印キーと中ボタンのドラッグで移動、ホイールで拡大縮小（地図全体〜約300m幅）

## 3. 入力の流れ

1. **中隊を選ぶ**：地図上の味方の駒をクリック（向きを考えた矩形で当たり判定）、左パネルの行をクリック、または 1〜4 キー
2. **命令を選ぶ**：右パネルのボタン、またはキー
3. **地図をクリック**：命令ごとに次のとおり

| 命令 | キー | 地図での操作 |
| --- | --- | --- |
| 前進 | Q | 目的地をクリック。押したままドラッグすると、ドラッグの方向が到着後の向き（離した位置まで矢印を出す） |
| 後退 | W | 前進と同じ |
| 保持 | E | すぐ出る（その場で保持）。地図をドラッグすれば向きを指定できる |
| 拘束 | R | 目標の敵の駒をクリック |
| 攻撃 | T | 方向を右パネル（またはキー 0：指定なし、F：正面、S：側面、B：背面）で選び、目標の敵の駒をクリック |
| 陣地構築 | Y | すぐ出る |

- Esc で命令の選択を取り消す。右クリックでも取り消す
- 命令を出したら、選んだ中隊の経路（`Company.Path`）と目的地（`MoveGoal`）を描く。攻撃では発起点が目的地になる
- その他のキー：スペースで一時停止、F1・F2・F3 で ×1・×2・×4、L で視線確認、F5〜F7 でデバッグ表示（下）
- UI の上をクリックしたときは、地図の操作にしない

## 4. UI の作り方

**IMGUI（`OnGUI`）を提案する。** uGUI でも UI Toolkit でもない第3の案なので、理由を書く。

- 全てをスクリプトで組める。uGUI はシーンやプレハブに部品を置くのが普通で、UI Toolkit は UXML・USS・PanelSettings・テーマのアセットが要る。今回は人が Unity のエディタで画面を組む工程を挟まず、作業できる場所が限られる（エディタの画面を見ながら調整できない）ので、アセットに頼らない方が壊れにくい
- 日本語は、OS のフォント（Yu Gothic UI、なければ Meiryo）から `Font.CreateDynamicFontFromOSFont` で作る。TextMeshPro の日本語フォントアセットを作る手間が要らない
- 「UI の上をクリックしたか」は、パネルの矩形で判定する
- 欠点：見た目の自由度が低く、要素が多いと遅い。P1 の画面（パネル4つとログ）なら問題ない量。P2 以降で画面が育ったら uGUI か UI Toolkit に移す前提の、試作用の作りとする

uGUI を選ぶ場合は、Canvas と部品を起動時にスクリプトで作る形にする（文字は旧 `Text` に OS のフォント）。返答で指定があれば、そちらに合わせる。

## 5. 視線確認ツール

- L キーで視線確認の状態にし、地図上の地点をクリックすると、そこから見えるマスを重ねて表示する。敵の駒をクリックしたときは、その中隊の中心から
- 計算は Sim の `LineOfSight.Check`（`Visibility.VisibleCells` 経由）だけを使う。各マスの中心へ視線を引く
- 範囲：視界距離の最大（800m×(1＋0.1×地図の最大の高低差÷10m) ≒ 1,020m）以内のマス。地図全体（2,400マス）を調べても、1マスあたり最大約100点の標高の参照なので約24万回。クリックのたびに1回計算する程度なら1フレームで終わる
- 見えるマスを緑、視界距離の内側で見えないマスを赤の半透明で塗る。理由（稜線・遮蔽・距離）で色を変える案もあるが、まずは2色にする

## 6. 調整用の切り替え

- **`terrain.moving_open_damage_mult`**：Sim の被弾倍率の計算（`TerrainDamageMult`）で、撃たれる側がその刻みに動いていて、中心のマスが平地・砲撃痕・橋・浅瀬なら、この値を掛ける。1.0 なら掛け算は値を変えないので、今の挙動と同じ（全テストと、P1a.1 と同じ17通りのログの SHA256 で確かめる）
- **デバッグ表示**（キーで切り替え）
  - F5：露出の地図（なし → 青から見た赤の射界 → 赤から見た青の射界）
  - F6：予備隊の台本の引き金の円（発動したら色を変える）
  - F7：各中隊の退路の見積もり（16方位の損害を放射状の線の長さで、最小の方位を矢印で、包囲なら赤）
- **表示用の読み取りの口**：露出の地図と退路の見積もりは、Sim の中で「見える範囲」をその場で作って10秒間使い回している。表示のために呼ぶと、この使い回しに影響して会戦の結果が変わりうる。そこで、**キャッシュに触らずに計算する読み取り専用の口**を Sim に足す（`PeekExposure(side)`、`PeekEscape(company)`）。表示を出しっぱなしにしても会戦の結果が変わらないことをテストで確かめる

**`Assets/StreamingAssets/maps/` に `maps/` の写しを置く**ことを提案する。実行時に読めるのは StreamingAssets で、`sim_params.json` と同じ扱いにそろえる。`maps/` が正本で、写しが同一であることをテストで確かめる（`sim_params.json` と同じ）。

## 判断を仰ぎたい点

1. **UI は IMGUI でよいか**（上の4）。uGUI か UI Toolkit を指定されればそれに合わせる
2. **会戦の終わり**：90分で止めて判定する。それより前に止めるのは、赤か青が全て盤上から消えたとき（赤が全て消えれば、青が残っている限り勝ち）。「村に入って赤がいない」は90分の時点の条件なので、途中では止めない。この読みでよいか
3. **移動中の被弾倍率の対象**：仕様のとおり平地・砲撃痕・橋・浅瀬だけに掛ける。塹壕のマスを移動中の中隊（被弾倍率は平地と同じ 1.0）には掛けない。森・村・塹壕を通る接近を「安い道」にする意図に沿うと思うが、塹壕のマスも開けた場所として扱うか
4. **会戦の終了後**：終了画面を出して時間を止める。地図と駒はそのまま見られるようにする
5. **攻撃の方向の「側面」**：左右は Sim が経路コストで選ぶ（指定なしの側面）。プレイヤーが左右を選ぶ操作は作らない
