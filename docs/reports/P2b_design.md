# P2b 設計報告（着手前）：段階つき命令と信号弾

対象：docs/spec.md「P2b：段階つき命令と信号弾（確定）」。返答をいただくまで実装しません。末尾に「迷った点」をまとめました。

## 1. 命令書と段階の状態の持ち方（Sim）

**命令書（`OrderSheet`）**：1〜3段の `Stage` の並び。読み取り専用で、作ったら変えない（直すときは作り直して差し替える）。

| 項目 | 内容 |
| --- | --- |
| `Stage.Order` | 今の `Order` そのもの（前進・後退・保持・拘束・攻撃・陣地構築。攻撃の方角・追撃の許可・拘束の距離もそのまま） |
| `Stage.Trigger` | 移る条件。第1段は「なし」。第2段・第3段は「完了したら」「時刻（秒）」「信号弾（赤・緑・白）」のどれか1つ |

**P2a の仕組みとの関係**
- 伝令（`Runner`）は、`Order` の代わりに `OrderSheet` を運ぶ。1つの命令書に1人
- P2a の「開始待ち」（届いてから練度の遅れの後に始める）は、命令書の第1段の開始として使い直す
- 中隊は「実行中の命令書」と「今の段の番号」を持つ。今の `CurrentOrder` は「今の段の命令」になる
- 新しい命令書が届いたら、古い命令書は残りの段ごと全て置き換える（P2a の「出した順で新しい方を優先」もそのまま）
- 1段だけの命令は、1段の命令書として同じ道を通る。`SendOrder(Order)`・`Issue(Order)`・台本の命令は、中で1段の命令書に包む

**中隊の段の状態**

| 状態 | 意味 | 次へ |
| --- | --- | --- |
| 開始待ち | 届いた（または前の段から移る）命令を、練度の遅れの後に始める | 時刻が来たら、その段の命令を始める（今の `ApplyOrders` と同じ処理） |
| 実行中 | 今の段の命令で動いている。次の段の条件を毎刻み調べる | 条件を満たしたら「開始待ち」へ（次の段） |
| 終わり | 最後の段 | 今と同じ（P2c で自律行動） |

**条件を調べる時機**
- 今の段が始まった後から調べる。前の段の開始待ちの間は調べない
- 「時刻」：その時刻を過ぎていれば満たす。今の段が始まった時点ですでに過ぎていれば、すぐ満たす
- 「信号弾」：その色がすでに上がっていれば満たす。命令書が届く前・今の段が始まる前に上がっていても満たす（迷った点1）

**「完了」の判定**（命令ごと）

| 命令 | 完了 |
| --- | --- |
| 前進・後退 | 着いた（`Arrived`。届かない目的地の手前で止まった場合も含む） |
| 攻撃 | 目標が指揮下でなくなった刻み（P1d の「確保／追撃」に移る刻み）。追撃中・確保中でも、次の段の開始待ちを始める |
| 陣地構築 | 陣地が完成した（目的地ありなら、移動して掘り終えた） |
| 保持・拘束 | 完了しない（条件に選べない） |

- 動揺で前進が保持に変わった場合（P0 からの規則）は、完了しない。時刻・信号弾の条件なら移れる（迷った点2）
- 阻まれて止まっている間（P1e.1）は、着いていないので完了しない

**ログ**：`sheet_delivered`（段の数）、`stage_advance`（何段目へ、理由：complete／time／flare_green など）、`stage_start`、`flare`（色）

## 2. 信号弾（Sim）

- `FireFlare(side, color)`：各色1回。上げた時刻を記録する。使ったら `false`
- 効くのは上げた陣営の中隊の命令書の条件だけ。判断枠を使わない。距離も時間も掛からない
- 赤の陣営は使わない（命令書を持たない。台本は1段のまま）

## 3. 伝令の経路（Sim）

- 置き場所：`SimulationRunners.cs`。経路は今の `PathFinder.Find`（A*、8近傍、50m のマス）
  - 伝令の陣営の露出の地図に、脅威の重み 3.0（慎重と同じ）を掛ける
  - 川は移動倍率 0 なので、自然に橋と浅瀬だけを渡る
  - 敵の周りを通れなくする規則（P1d の 110m）は伝令には使わない（射界のコストで避ける）
- 引き直し：10秒ごとに、往路は中隊の今の位置へ、帰路は本部へ。引き直すまでは経路の点を順にたどり、最後の点の後に中隊の位置へ進む
- 速さ：秒速 3m×今いるマスの移動倍率
- 重さ：60×40 マスの A* を、伝令1人につき 10秒に1回。判断枠は3人なので、10秒に数回の A* で、今の中隊の経路探索（30秒ごと）より軽い
- 到着予定と強制開放：発令の時点で、本部から中隊までの経路の「時間の長さ」（各区間の長さ÷（3m×移動倍率）の和）を出す
  - 到着予定＝準備＋その時間
  - 強制開放＝1.5×（準備＋その時間×2）
  - 表示の到着予定は、引き直した経路で出し直す

## 4. 到着予定（命令の下見）

- 命令書の各段を順に下見する。第1段は中隊の今の位置から、第2段以降は前の段の行き先から（攻撃は発起点、拘束は拘束点）。下見は P1e の `Preview` を広げ、中隊の位置を一時的に前の段の行き先に置いて計算し、元に戻す
- 時刻の見積もり：
  - 第1段の開始：会戦開始前は今。それ以降は、伝令の到着予定＋練度の遅れ（すでに届いた命令書なら、その段の開始時刻）
  - 各段の所要：経路の各区間の長さ÷（1.2m×マスの移動倍率）の和。旋回・横歩きなどの細かな遅れは入れない（概算）
  - 次の段の開始：「完了したら」は前の段の到着予定＋練度の遅れ。「時刻」は（指定の時刻と前の段の終わりの遅い方）＋練度の遅れ。「信号弾」は時刻が決まらないので「信号弾から 約 N分」と出す
- 表示：各段の行き先に「約 T+mm:ss」。保持には出さない

## 5. 命令書を組む画面と操作（View）

**変わること**：今は「命令を選んで地図をクリックすると、すぐ出る」。P2b では、選んで地図をクリックすると**起案中の命令書の段に書き込む**だけで、**「発令」で初めて出る**。

**右パネルの「命令書」の欄**（選んだ中隊ごと。起案は中隊ごとに1枚、選ぶ中隊を替えても残る）
- **起案中**
  - 始め方：［白紙から］［実行中の写しから（今の段から後）］。何もない状態で命令を選んで地図をクリックすると、白紙から第1段ができる
  - 段の行：「第2段　前進 (1450, 1450) 東向き　［条件：信号弾 緑 ▼］　［↑］［↓］［×］」
    - 行をクリックして「書き込む段」を選ぶ。書き込む段は枠で強調する
    - 命令のキー・ボタン（Q・W・E・R・T・Y）と地図のクリック・ドラッグは、書き込む段の命令を置き換える
  - 条件の選び方：［完了したら］［時刻］［信号弾］の切り替えと、時刻は［−1分］［+1分］（初めは今から5分後の分の切り上げ）、信号弾は［赤］［緑］［白］
  - ［段を足す］（3段まで。足した段が書き込む段になる）、［発令］（キー：**Enter**）、［起案の破棄］
  - 選べない組み合わせ：その段の行に赤い印と理由（「保持の後に『完了したら』は選べない」「第2段に条件がない」）。直すまで［発令］は押せない
  - 入れ替えで第1段になった段の条件は外す。第1段から下がった段は条件なしになり、印が出る
- **送付中**（その中隊へ向かっている伝令ごと。新しいものを下に）
  - 準備中：「準備中 あと 12秒」と命令書。［直す］で起案の欄に写して直し、［発令］で差し替える（伝令は同じ、準備の残りは数え直さない）。［取り消す］で伝令は出ず、判断枠が空く
  - 出発後：「未着 あと 95秒」と命令書（読むだけ）
- **実行中**：命令書の全段。今の段を強調し、済んだ段は薄く。今の段が開始待ちなら「開始まで N秒」

**Sim の口**：`SendSheet(sheet)`（判断枠を使う。会戦開始前は伝令なしで即座に届く）、`ReviseSheet(runnerId, sheet)`・`CancelRunner(runnerId)`（準備中だけ。それ以外は false）

**地図の下見**
- 選んだ中隊の命令書の段ごとの経路と行き先に、段の番号（①②③）と到着予定を出す
  - 実行中の命令書：今の段は濃く、後の段は薄く
  - 起案中の命令書：全て薄い破線（書き込む段だけ少し濃く）
  - 送付中の命令書：薄く
- 中隊の駒と左パネル：「2/3　次：信号弾 緑」「1/2　次：T+18:00」「2/2」

**上部バー**：信号弾の3色のボタン［赤］［緑］［白］（使ったものは消える）。キーは **F9 赤・F10 緑・F11 白**（F5〜F8 はデバッグ表示で使用中）。確認はしない（迷った点6）

**出来事の欄**：「信号弾 緑」「B2 第2段へ（信号弾 緑）」「B2 第2段へ（完了）」「B2 第3段へ（T+18:00）」

## 8. テスト（予定）

依頼文の項目のとおり。

- 3段の命令書が、完了・時刻・信号弾のそれぞれで順に進み、移る時に練度の遅れが掛かる
- 保持・拘束の後に「完了したら」を付けられない
- 新しい命令書が届くと古い残りの段が消える
- 準備中の取り消しで伝令が出ず枠が空く。準備中に直すと直した内容が届き、準備の残り時間は変わらない。出発後は取り消せない
- 入れ替えで第1段になった段の条件が外れ、条件のない第2段・第3段は発令できない（命令書の検査の関数を Sim に置いて試す）
- 信号弾は各色1回、枠を使わず全中隊に即座に届く
- 会戦開始前の段階つき命令が伝令なしで届く
- 伝令が射界を避けて回り込む（まっすぐより射界を通る時間が短い）。川を橋か浅瀬で渡る。動く中隊を追って引き直す
- 到着予定が実際の到着と大きくずれない（平地の前進で ±10%）
- P2a の検算（600m で 230秒）は、マスの中心を通る経路になるので数秒長くなる。許す幅を付けて直す
- S1〜S6 は変わらない（±15%）

## 迷った点（提案つき）

1. **信号弾が先に上がっていた場合**：命令書が届く前や、前の段が終わる前に、その色がすでに上がっていたら。**提案：上がったことは残る（ラッチ）とし、その段の条件を調べ始めた時点ですぐ満たす。** 遅れて着いた命令書も合図に合わせられる。反対の読み（条件を調べ始めた後に上がったものだけ数える）だと、遅れた中隊はその合図を取り逃がす
2. **動揺で前進が保持に変わったとき**：完了しないので「完了したら」の次の段へは移らない（時刻・信号弾なら移る）。止まった後の判断は P2c の自律行動に任せる
3. **攻撃の「完了」と追撃**：目標が崩れた刻みに完了とし、練度の遅れの間は P1d どおり確保か追撃をして、その後に次の段を始める（追撃は打ち切られる）
4. **陣地構築の「完了」**：陣地が完成した時（目的地ありでも、着いただけでは完了しない）
5. **準備中に直すときの中隊**：同じ中隊の命令書だけ直せる（宛先は変えられない。変えたいなら取り消して起案し直す）
6. **信号弾の確認**：取り返しがつかないので確認を挟む案もあるが、操作を重くしないため、確認なしでボタンとキー（F9〜F11）にする。押した直後に出来事の欄へ出す
7. **伝令の経路と敵**：伝令には敵の周りを通れなくする規則を使わず、射界のコストで避けさせる（敵の矩形の脇をかすめることはある）
8. **1段の命令の出し方**：1段の命令も「発令」で出す（仕様のとおり）。今までの「選んで地図をクリックすると出る」に慣れた手には1手増えるので、早見表で知らせる
9. **起案の置き場所**：View 側（本部の机）に持ち、Sim には送るときに渡す。会戦開始前に出した命令書は中隊に届いた後も、会戦が始まるまで「実行中の写しから」直して出し直せる（伝令なし・枠なし）
