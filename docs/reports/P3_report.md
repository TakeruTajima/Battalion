## 3. S28 が満たせない原因

**場面の作り**：
- 地図は S7・S8 の「脇を塞いだ陣地」（攻める側の幅 400m、守備の手前 150m からは正面幅だけ、両脇は水）を、赤が原点に来るようにずらしたもの。
- 平地のままだと、青の経路が露出を避けて大きく回り道をし、時刻を合わせられなかったので、この地図にした。
- (a) 時刻の合わせ方：同じシードを砲撃なしで一度回し、青が射程の 20m 手前（420m）に着いた時刻を測る。そこに残りの 270m をふつうの速さで歩く時間を足した時刻に、砲撃が止むよう指定する。
  - 止んだ時の距離の平均は 150m で、ねらいどおり。
  - その間、赤は制圧されていて（撃つ力 ×0.25）、青は伏せずに歩ける。
- 損害は「詰めるまで」（矩形の隙間 50m 以内に入るまで。入らなければ終わりまで）で比べた。仕様の括弧書き「止んでから詰めるまでの隙」に合わせた。「砲撃が止んでから 15分まで」の損害も、表と同じ値で並べてある。

**1件を追った経過**（シード1）：
- 青は 420m（射程の手前）を過ぎても、赤が砲撃で制圧されているので伏せずに進む。
- 150m を切ると、赤に撃たれている距離（拘束の半径）に入り、移動が ×0.5（0.6m/s）になる。
- 砲撃が止んで 60秒後に赤の制圧が解けた時、青はまだ 113m（矩形の隙間 63m）にいる。接近戦の距離（隙間 50m）に届いていない。
- 赤の射撃（毎分 2.4）は、動いている青のしきい値 1.5 を越える。青は 10秒で伏せて止まり、108m で撃たれ続ける。
- 20回とも、青は詰められなかった（詰めた割合 0.00）。

**読み取り**：今の規則の組み合わせでは、仕様の数字の通りに「150m で止む」と、詰め切れない。
- 150m から接近戦の距離（中心どうし 100m）までの 50m を、拘束で ×0.5 の速さだと 83秒かかる。60秒では足りない。

**参考の版**：砲撃が 130m（着弾の円の縁：半径 100m＋誤差 30m）で止むよう合わせた版も回した。
- 詰めた割合 0.90、詰めるまでの損害 12.0。(b) 26.3 の半分以下になる。
- ただし、詰めた後の接近戦では塹壕の赤に撃ち負け、青が崩れた割合は 0.90。終わりまでの損害は 48.7。
- 1個中隊で塹壕を取れないのは、S7（正面からの突撃は通らない）と同じ作り。

**判断してほしいこと**：次のどれかが要る。
- S28 の距離を 130m 前後にする。
- 砲撃の制圧が解ける時間を長くする。
- 拘束の ×0.5 を、制圧された射手からは効かないようにする。

## 4. 実装したこと

**0. 霧を既定で切る**
- `fog.enabled` を false にした（`sim_params.json` と `docs/reference/sim_params.initial.json` の両方）。true にすれば今までの霧になる。
- 射撃の手応えの短い線と楔は、霧なしでも出す（実際の射撃の線に重ねて描く）。

**1. 地図の `artillery`**
- 側ごとに `{ "batteries": 1, "rounds": 160 }` と書く。シナリオA の両ステージに、青・赤とも書いた。
- 書かない地図（教程1・2）には砲兵がない。
- `maps/` と `Assets/StreamingAssets/maps/` の両方に入れた。

**2. 青の要請**（`Assets/Sim/SimulationArtillery.cs`）
- 要請の操作：`RequestFire(side, 地点, 分, 始める時刻)`。確かめは `CheckFireRequest`（砲兵なし・弾なし・長さ・要請できない地点・間に合わない時刻・撃つ時間の重なり）。
- 要請できる地点：計画射撃点か、指揮下の味方のどれかが気付いている盤上の敵の中隊から 200m 以内。霧を入れた設定の青は、報告の駒から 200m 以内。
- 時刻：電話 30秒（判断枠を使わない）の後、準備 90秒（計画射撃点は 30秒）。時刻を指定した要請は、その時刻に初弾が落ちる。準備に間に合わない時刻は選べない。
- 誤差と観測の修正：初弾の誤差は 100m（計画射撃点は 30m）。撃ち始めて 60秒の後、狙った地点を見ている指揮下の味方がいれば 30m に直る。
- 取りやめと伸ばし：取りやめは、電話・準備・射撃のどの間でもすぐ止む。伸ばしは、撃っている間に 1分ずつ（弾があり、次の要請と重ならない時）。
- 弾：毎分 8発減り、尽きればそこで止む。
- 計画射撃点：会戦前に3箇所まで登録できる（`AddPlannedPoint`）。

**3. 効果**
- 中心が着弾の円（100m）に入った中隊は、敵味方を問わず効果を受ける。
- 損害：毎分、初めの兵力の 6.0%。倍率を掛ける：
  - 掛ける：地形・陣地構築・浅い掩体・縦隊 ×1.5。
  - 掛けない：陣地の向き、開けた所を動く ×3.0、接近戦の上限。
- 士気：損害の分（`morale.per_pct_loss`）に加えて、毎分 −6×同じ倍率。士気の内訳の「artillery」に入れる。
- 制圧：円の中にいる間と、出てから 60秒は R1 の制圧（伏せる・撃つ力 ×0.25・動けない）。しきい値は見ない。
  - `Company.Suppressed` を、小銃の制圧（`RifleSuppressed`）と砲撃の制圧（`ArtySuppressed`）のどちらかにした。
- 砲撃痕：中心が円の中のマスに、着弾の秒数を足す。累計 3分で、平地のマスを砲撃痕にする。
- 乱数は砲兵だけの流れ（`ArtilleryStream`）を使う。砲兵のない会戦では1つも引かない。

**4. 赤の砲兵**
- 守りの計画に `artillery_points` を書く（仕様の6点。`maps/scenario_a1.json`・`a2.json` の `defense_plan` に足した）。
- 赤の本部は 60秒ごとに見る。撃っていない時に、1つだけ要請する：
  1. 阻止射撃（計画射撃点へ 3分）。
  2. 陣地の前（青の位置へ 3分）。
- 誤射を避ける：着弾の中心から 250m 以内に赤がいる地点へは撃たない。

## 6. 迷った点と自分で決めた点

1. **損害の割合の基**：初めの兵力に対する割合にした。
   - 仕様の表の「平地の士気 毎分 −15（損害分を含む）で約5分」は、損害が一定の時に成り立つ。今の兵力の割合だと、士気の減りが時間とともに鈍る。
2. **誤差の散らし方**：長さはちょうど 100m（30m）で、向きを一様に散らす。初弾で決め、観測の修正で 30m の新しい向きに引き直す。
3. **観測の修正の判定**：撃ち始めて 60秒以後の各刻みで判定する。要請した側の指揮下の中隊のどれかから、狙った地点へ視線が通れば直す（視界距離を含む今の視線の判定）。
   - 仕様の「その地点の 200m 以内を直接見ている」は、狙った地点が見えることと読んだ。
4. **時刻を指定した要請の操作**：「時刻」を押すと、間に合う一番早い時刻を分で切り上げた値になる。±1分で動かす（早すぎる時刻へは下がらない）。
   - 複数の要請は、撃つ時間が重ならなければいくつでも置ける。教程の準備砲撃のように、会戦前にも置ける。
5. **赤の要請の目標の選び方**：
   - 阻止射撃：計画射撃点の順に見て、最初に当てはまる点へ撃つ。
   - 陣地の前：前線・守備の赤に一番近い青へ撃つ。
