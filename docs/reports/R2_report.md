- 同じ2個中隊でも、片方を側面へ回すと、塹壕の守りが通らなくなる。30分で一度も崩れなかった守備（S13）が、20回とも約 9分で崩れる（S12）。
- S12 では、正面の中隊が守備を正面に向かせたままにする（拘束）。そのため、北の中隊は守りのない側面を撃ち続けられる。
- S11 との違いは、向き直られるかどうか。拘束のない側面攻撃は向き直られる。

**S11 の中身**（初めの期待 0.8 に届かなかった理由。シード 1〜20 の中身を見た）
- 側面から撃たれた R は、**36秒で北へ向き直る**（P1d の向き直り）。
- 向き直った後は、撃っている A が R の正面の弧に入る。ただし塹壕は西向きのままなので、R は守られない。
- その結果、塹壕の守りのない、平地どうしの1対1になる。R の不利は2つだけ：
  - 初めに側面を突かれた衝撃（士気 −10）
  - 向き直るまでの 36秒の側面からの損害（士気の要因の「側面」は −12〜−14。ほかは正面 −47〜−51）
- 比べのために S1（平地の1対1）を同じ 30分で回すと、R が崩れるのは 0/20、A が崩れるのは 1/20。S11 の R は 12/20 が崩れ、A は 0/20。損害率の平均は、R 0.315・A 0.274（S1 は R 0.309・A 0.325）。
- まとめると、R2 で「側面を突いた塹壕は、平地の中隊と同じに崩れる」は出ている。ただ、1対1 では平地でも 30分で崩れるとは限らないので、0.8 には届かない。期待の 0.8 は、向き直った後も側面から撃たれ続ける（守りのない側面に、側面の倍率が掛かり続ける）ことを見込んだ値と読める。

仕様側の判断で、S11 の期待を直し、拘束と回り込みを合わせた S12・S13 を足した。向き直りの速さ（課題3）は、R2 には入れない。

## 3. 実装したもの

**Sim**
- **陣地の向き**を、マスごとに地図（`TerrainMap.FortificationFacing`）に持たせた。一度決まったら変えない。
  - 地図の塹壕：シナリオの定義で与える（下の4の1）
  - 陣地構築：完成したときの中隊の向き。もとからある塹壕のマスの向きは変えない
- **浅い掩体の向き**は、中隊ごとに持つ（`Company.ScrapeFacing`。掘り始めたときの向き）。
- **守りの効き方**（`TerrainDamageMult(c, from)`）：撃ってきた敵の位置 `from` が陣地の向きの正面の弧（±`fire.front_arc_deg`、60°）の外なら、守りの倍率を `terrain.fortification_off_arc_mult`（1.0）に置き換える。
  - 塹壕：×0.3 → ×1.0
  - 陣地構築の途中：進捗に応じて近づく先を 0.3 から 1.0 に替える
  - 浅い掩体：近づく先を 0.6 から 1.0 に替える
  - 村・森などは今のまま（向きを見ない）
- **射撃の損害**（`Resolve`）だけが `from` を渡す。物陰を探すなどの自律行動の判断は、今までどおり向きを見ない（下の4の3）。
- **場面**：S10〜S13（`Scenarios`）。平地の塹壕の向きは、塹壕に置いた中隊の初めの向き。
- **パラメータ**：`terrain.fortification_off_arc_mult`（1.0）と注記 `_note_fortification` を `sim_params.json` に足した。仕様側で `sim_params.initial.json` に反映済み。
- **テストだけの切り替え**：`TerrainParams.IgnoreFortificationFacing`（`sim_params.json` にはない）。`TestUtil.ParamsWithoutR1`（R1 以降の規則を止めた値）と、P0.2 のログとの比べで、R2 も止めるのに使う。

**表示**
- 中隊の詳しい表示に「陣地の向き 西（180°）　直前の射撃：正面の弧から 1・外から 1　一部効いていない」を出す。
  - 陣地がなければ「陣地なし（向きのある守りなし）」
  - 直前の刻みの射撃ごとに、射手が陣地の正面の弧にいるかで「効いている／効いていない／一部効いていない」
- 地図の、向きを持つ塹壕のマスに、正面側の辺に沿った短い線と、正面へ向けた小さな刻みを描く（構築した塹壕も含む）。

**テスト**（`R2Tests`）
- 正面の弧（±59° は守られ、±61° は守られない）、側面、背面
- 向きを変えても陣地の向きは変わらない
- 奪った塹壕は逆向き
- 村・森は向きによらない
- 陣地構築の向きは完成したときの向きで、後から変わらない。構築の途中は今の向きの正面だけで効く
- 浅い掩体の向きは、掘り始めたときの向き
- 実際の射撃の損害：側面から撃つと、正面の 1/0.3 × 1.5 倍
- シナリオA の塹壕 12マスが全て西向き
- S10〜S13 の期待：`FrontFireDoesNotBreakTheTrench`（S10）、`FlankFireBreaksTheTrenchMuchMoreOftenThanFrontFire`（S11）、`PinAndFlankBreaksTheTrenchMuchFasterThanTwoFromTheFront`（S12・S13）

## 4. 迷った点と、自分で決めた点

1. **シナリオA の塹壕の向きの決め方**：
   - 塹壕のマスを、隣り合う（8方向）マスでつながった1本ずつに分ける。
   - 会戦開始時に、その1本に中心がある中隊の向きにする。1本に複数の中隊がいれば、マスごとに一番近い中隊の向き。
   - シナリオA はどちらのステージも 12マスの1本で、ステージ1 は R1、ステージ2 は R1・R2（どれも西向き）。全て西になる。
   - 中隊のいない塹壕は「向きなし（今までどおり、向きによらず守る）」にした（シナリオA にはない）。
2. **陣地構築の途中で向きを変えた場合**：
   - 途中の守り（進捗に応じた ×0.3 への近づき）は、その刻みの中隊の向きの正面の弧で見る。
   - 塹壕のマスの向きは、完成したときの向きで決まる。途中で向き直れば、完成した塹壕はその後の向きになる。
   - 完成した後に中隊のいるマスが塹壕になれば、塹壕の向きで見る（進捗の守りは重ねない）。
3. **自律行動の判断は向きを見ない**：
   - 開けた所で撃たれ続けているか（物陰へ寄る）の判断と、物陰の候補の比べは、今までどおり守りを向きによらない値で見る。
   - 塹壕の中隊が側面から撃たれても、「開けた所で撃たれている」とはみなさない。
   - 自律行動を変えると P2c の場面が変わるので、R2 の外にした。必要なら別の段で。
4. **浅い掩体の向き**：掘り始めたときの中隊の向き。掘り終えた後に向き直っても変わらない。動いて掩体を失えば、次に掘り始めたときの向きになる。
5. **正面の弧の境目**：60° ちょうどは守られる（射撃の正面の弧の判定と同じ「以下」）。
