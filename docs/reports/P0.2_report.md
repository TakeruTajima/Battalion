## 変更内容

1. **docs の配置**：`docs/reference/` 以下（`combat_reference.py` v3、`reference_results.json` v3、`sim_params.initial.json`、`map/`、`sketch/`）と `maps/` を zip のとおりに置いた。`docs/spec.md` は仕様側が作業ツリーに置いた版をそのまま使い、zip の版では上書きしていない。`Assets/StreamingAssets/sim_params.json` も `sim_params.initial.json` と同じ内容にした
2. **退路の見積もり**（`Simulation.EstimateEscape`）
   - 16方位は東（x軸の正）から反時計回りに22.5度刻み
   - 各方位について、1秒刻みで 1.8m ずつ 500m 先まで（277歩、1歩目の位置から）進み、その時点で 400m 以内にいる指揮下（正常・動揺）の敵すべてから背面（×2、150m 以内は×1.3）を撃たれると仮定して、失う兵の割合の期待値を積算する
   - 射撃の基本の式（k・兵力・練度の射撃効率・距離倍率・背面倍率）だけを使う。射手の動揺・非正面・接近戦の補正は入れない。敵は動かないものとし、乱数は使わない
3. **包囲の判定**
   - 刻みの開始時点で士気50以下の指揮下の中隊だけが見積もる。全中隊分を、損害と士気の適用より前に、刻みの開始時点の状態で見積もる（同時解決）
   - 見積もりは5秒ごと。間の刻みは直前の結果を保持する
   - 全方位の見積もりが 0.20 以上なら包囲。判明した刻みに一度だけ絶望 −15（会戦中に1回）、包囲の間は毎分 −3。どちらにも練度の「士気の減りやすさ」を掛ける。要因別累計では「包囲」（`encircled`）に入れる
   - 包囲中に壊走したら降伏（判定は壊走した瞬間の包囲状態だけ。P0 と同じ）
4. **籠城**：`Company.Fortified` が true なら、包囲の毎分の低下に `fortified_morale_mult`（0.5）を掛ける。P0 には地形がないので常に false。P1a で地形（塹壕・村の中）から決める。絶望の −15 には掛けない
5. **壊走の方向**
   - 見積もり損害が最も少ない方位へ逃げる。壊走中も5秒ごとに見積もり直して方位を更新する
   - 同点の方位が複数あれば、600m 以内の敵の中心の平均位置から最も遠ざかる方位（その方向との内積が最大の方位。それも同じなら添字の小さい方）
   - 600m 以内に敵がいなければ、壊走中もその場に止まる（`rout.flee_from_radius_m` を引き続き使う）
6. **パラメータ**：`encirclement` の区分を v3 のキーに置き換えた。`movement.friendly_min_spacing_m` も読み込む（P1a で使う）
7. **ログ**：`encircled_start` の `reason` は `no_escape` になり、最小の見積もり損害 `escape_loss` を足した。絶望を受けた刻みに `despair`（`morale_hit`、`escape_loss`）を出す
8. **テスト**：S6 を検算に追加し、正解値で全回降伏している中隊は本実装でも全回降伏することを確かめる。次の単体テストを足した
   - 方位の並び（東から反時計回り）、手計算との一致（東 300m の敵1個から西へ逃げる：55歩×k/60×150×2÷150）
   - S6 は逃げ道なし、S3・S4 は逃げ道あり。壊走中・再集結中の敵と遠い敵は数えない
   - 同点のときは敵の平均位置から遠ざかる方位を選ぶ（東 500m の敵：参照実装なら 67.5°、本実装は真西）
   - 士気50超では見積もらない／5秒ごとに見積もり直す／絶望は一度だけ、毎分 −3、籠城で半分
   - 壊走は見積もりの方位へ逃げる／600m 以内に敵がいなければ止まる／S4 は降伏しない、S6 は降伏する

## P0.2 で判断した箇所

仕様に書かれていないか、参照実装と仕様の書き方が分かれていた点。

1. **見積もりに数える敵**：参照実装は「壊走していない敵」。本実装は指揮下（正常・動揺）の敵だけを数え、再集結中の敵も除いた。再集結中の中隊は発砲しないため（P0 の解釈10）。参照実装には再集結がないので、検算には影響しない
2. **壊走した瞬間に見積もりがない場合**：士気50超から一度の刻みで壊走した場合など、直近5秒の見積もりがなければ、壊走した刻みにその場で見積もって逃げる方向を決める。再集結中に敵が近づいて壊走に戻ったときも、その場で見積もり直す
3. **士気が一時的に50を超えた場合**：参照実装と同じく、見積もりの結果は5秒の間は保持する。50を超えている刻みは包囲ではない扱いだが、5秒以内に50以下へ戻ると直前の結果を使う
4. **同点の判定**：最小値との差が 1e-12 以下の方位を同点とした。左右対称の配置で、浮動小数点の誤差だけで方位が決まらないようにするため
5. **見積もりの時刻**：参照実装は「刻みの開始時刻」が直前の見積もりから5秒以上経っていれば見積もり直す。本実装も同じく刻みの開始時刻で判定する。ただし参照実装は時刻を 0.5/60 分ずつ足していくので、浮動小数点の誤差で見積もりの間隔が10刻みと11刻みに分かれる（最初の8回は 0, 10, 20, 31, 41, 51, 61, 72 刻み目）。本実装は刻み数から時刻を出すので、常に10刻み（5秒）ごとになる。検算の差はこの範囲に収まっている
6. **仕様の要因一覧にないログ**：`despair` イベントを足した。戦闘詳報で「退路がないと分かった瞬間」を時刻付きで並べるため
